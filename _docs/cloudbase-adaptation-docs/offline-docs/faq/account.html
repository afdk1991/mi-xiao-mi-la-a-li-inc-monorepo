账号相关

账号查询与关联​

如何查看腾讯云账号关联的小程序？​

前往 腾讯云账号中心，在「账号信息」>「登录方式」>「微信公众平台」中查看已关联的小程序。

腾讯云的云开发环境在微信开发者工具中看不到？​

问题原因：微信开发者工具中的云开发控制台使用小程序绑定的腾讯云账号登录，需要确保账号一致。

解决步骤：

  1. 确认账号是否一致：参考上文「如何查看腾讯云账号关联的小程序」，确认您在腾讯云使用的账号与小程序绑定的账号是否一致。

  2. 导入已有环境：如果账号一致，在微信开发者工具中操作：

    • 打开云开发控制台
    • 进入「设置」>「环境设置」
    • 展开环境列表，点击「管理我的环境」
    • 选择「使用已有腾讯云环境」，导入腾讯云侧创建的环境

如何将小程序绑定到已有的腾讯云账号？​

前提条件

确保小程序之前未与其他腾讯云账号关联。

前往 腾讯云账号中心，在「登录方式」>「微信公众平台」中关联您的小程序。

为什么收不到腾讯云的通知消息？​

如果在微信开发者工具内开通云开发，后续想接收腾讯云的产品信息、账号及账单通知，需要使用小程序公众号扫码登录腾讯云。

操作步骤：访问 腾讯云登录页面，选择小程序公众号扫码登录。

账号绑定规则​

一个腾讯云账号可以绑定多个小程序吗？​

不可以，一个腾讯云账号只能绑定一个小程序。

资源共享方案

如需在多个小程序间共享云开发资源，可使用微信开发者工具的 环境共享能力，将某个小程序的云开发资源授权给同主体下的其他小程序或公众号使用。

注销小程序会影响腾讯云账号吗？​

不会。腾讯云账号和小程序账号是独立的账号体系，注销小程序不会影响腾讯云账号。

注意

如果您的腾讯云账号仅关联了微信公众号作为登录方式，注销小程序后可能导致无法登录腾讯云。建议提前在 腾讯云账号中心 关联其他登录方式（如微信、邮箱、手机号等）。

账号解绑与换绑​

如何将小程序从自动创建的腾讯云账号换绑到已有账号？​

重要说明

以下操作必须在主账号下完成，子账号或协作者账号无法执行。

适用场景：腾讯云账号注册方式为微信公众平台，且仅在微信开发者工具内使用过云开发服务。

第一步：解绑小程序​

1. 使用小程序管理员账号登录腾讯云

访问 云开发控制台，选择「小程序公众号」方式扫码登录，授权需要解绑的小程序。

2. 销毁云开发环境

注意

解绑前必须先销毁所有云开发环境，否则会报错。

  • 进入 环境管理页
  • 选择需要销毁的环境，在 ... 菜单里点击「销毁」
  • 清除环境内的所有文件，完成环境销毁

3. 解绑小程序

  • 进入 账号中心
  • 在「登录方式」>「微信公众平台」处，点击「解绑」

4. 提交验证材料

  • 个人账号：扫码完成身份验证
  • 企业账号：提交营业执照等企业认证材料
提示

系统会检测账号是否有其他登录方式，需要至少绑定一种其他登录方式（如微信、邮箱、手机号等），避免解绑后无法登录。

第二步：换绑到新账号​

1. 使用目标账号登录腾讯云

使用您希望绑定的腾讯云账号登录 腾讯云控制台。

2. 绑定小程序

  • 进入 账号中心
  • 在「登录方式」>「微信公众平台」处，点击「绑定」
  • 使用拥有小程序管理员权限的微信账号扫码授权

第三步：在微信开发者工具中开通云开发​

说明

如果之前未使用过小程序云开发，需要完成以下步骤，使用已绑定的腾讯云账号开通云开发服务。

1. 下载微信开发者工具

前往 微信开发者工具下载页，选择对应系统版本下载安装。

2. 创建小程序项目

打开微信开发者工具，创建小程序项目。

重要

创建时务必勾选「不使用云服务」，否则会自动创建新的腾讯云账号。

3. 打开云开发控制台

在微信开发者工具中，点击「云开发」按钮，打开云开发控制台。

4. 授权腾讯云账号

点击「授权」，使用已绑定小程序的腾讯云主账号进行授权。

5. 开通云开发服务

系统将自动识别该小程序绑定的腾讯云账号，点击「确认」开通云开发服务并创建环境。您可根据实际需求选择付费方式。
