Agent Bucket 应用集成指南

腾讯云 COS 智能体桶（Agent Bucket）新上线了「应用管理」模块，并同步推出首个官方应用——网盘应用。

您可以把它理解成一个属于自己的「应用商店」：在控制台点几下，就能部署出一个专属的自有应用，无需写一行代码、无需管理任何云资源。

维度说明
数据归属存储在自己的存储桶中，数据完全自主
用户管理用户由自己创建和管理
配额分配存储配额由自己分配
访问域名可配置专属访问域名
代码量零代码，全程控制台操作
AI 打通提供 Skill 与 MCP 服务，可与 AI Agent 打通
部署前置条件

开始前请确保已开通 云开发 CloudBase 环境，并已开通腾讯云 COS 智能体桶资源。

下文将从能力介绍、部署步骤、部署后使用三个方面展开。

为什么要用「应用管理」​

自建应用成本高，独立维护成难题​

用 COS 做一个面向多用户的存储类产品，存储本身从来不是难点，真正困扰开发者的是存储之外的应用逻辑：

需要自己实现的能力具体工作
账号体系账密管理、安全存放、注册登录
空间与权限用户空间隔离、团队协作共享、存储配额划分
权益管理用户权益、配额调整、用量统计，需要一套后台
多客户端除 Web 页面外，PC 端与手机 App 也是刚需
服务部署后端服务、数据库、域名、HTTPS 等运维工作

这些工作单独看都不难，但把各个模块开发出来并组合成一套能交付给用户的产品，通常要一个小团队投入数周甚至数月。维护一个属于自己的网盘乃至其他应用服务，从来不是一件简单的事。

AI 时代，需要人与 Agent 共用的存储底座​

随着 AI 的飞速发展与 Agent 产品的井喷，生产办公的方式正从个人生产、团队协作转向人与 AI 配合。数据的来源不再仅来自人类，AI 产物也成为了存储的重要组成部分。

不管是独立开发者还是企业团队，都需要一个集中化的存储产品来与 AI Agent 交互——从待处理的生产资料，到 AI 产出的最终产物，再到结果的分享与二创。构建专属自己的 AI 原生存储产品，已成为当下的刚需。

「应用管理」给出的答案

针对上述问题，智能体桶将通用的应用搭建能力沉淀为官方应用：

  • 一键部署：由控制台一键创建完整应用产品，无需编写底层业务代码
  • 开箱即用：自动完成用户认证、数据库、云函数等资源搭建
  • 开放定制：上层业务逻辑、产品打通、交互重构，均可通过开放的 API / SDK 实现
  • AI 打通：提供官方 Skill，实现存储与 AI 工具的互通

本次首发上线的，是需求量大、通用性强的网盘应用场景。

网盘应用能做什么​

通过智能体桶「应用管理」部署出来的网盘应用，不只是一个简单的 Demo，而是一个功能完整的独立产品，分管理端和用户端两部分，并覆盖 Web、PC、移动三端。

管理端：开箱即用的运营后台​

管理端提供一套完整的运营能力，方便管理者统一监控及管理应用：

  • 数据看板：总览用户数、空间用量、文件趋势等关键指标
  • 用户管理：创建用户、维护账号状态
  • 空间管理：划分空间、调整存储配额

管理员不需要单独登录后台系统——登录网盘后，从侧边栏直接进「管理中心」即可。

用户端：个人与团队空间，人与 AI 存储交互新形态​

用户端提供完整的存储与协作能力：

  • 个人空间：私有的文件存储与管理
  • 团队空间：多人协作共享，权限清晰
  • 文件管理：上传、下载、组织与检索
  • 外发分享：一键生成分享链接给外部用户

同时提供开放 API 与 SDK、官方 Skill，方便开发者做后续功能打通。

三端覆盖，一个入口下载​

网盘当前已提供 Web、PC（macOS / Windows）、移动端（Android 已发布）多个终端，方便用户按需使用：

终端说明
Web浏览器访问网盘域名即可使用
PC支持 macOS / Windows 客户端
移动端支持 Android 客户端
提示

PC 端与移动端首次使用时，输入一次网盘访问域名即可。域名在控制台创建网盘应用的页面可以直接获取。

三步部署，一次搞定​

整个部署过程不需要写代码，也不涉及任何云资源的配置——您在控制台点几下，平台就会自动把网盘应用的后端资源搭好。

下图展示了从创建到交付给用户使用的完整链路，共三个阶段：

阶段操作方说明
① 选择资源与环境您在 COS 控制台或集成中心创建「网盘应用」，并指定目标 CloudBase 环境
② 一键部署平台自动创建用户认证、数据库、HTTP 云函数与超级管理员
③ 开始使用您获取访问域名，创建用户并分配配额后分发给最终用户

其中阶段 ② 完全由平台自动完成，是整个流程中最省事的一环。

第一步：选择智能体桶资源​

在 COS 控制台的智能体桶内，或腾讯云开发 CloudBase 的集成中心入口，创建「网盘应用」。

第二步：准备部署环境​

选择对应的腾讯云开发 CloudBase 环境。

提示

您可以关注「腾讯云开发 CloudBase」公众号，发送「领取兑换码」获取免费资源套餐。

第三步：确认并部署​

确认后点击「开始部署」，系统将自动完成以下资源的创建与配置：

资源说明
用户认证网盘应用的账号体系
数据库用户、空间、文件元数据等存储
HTTP 云函数网盘应用的后端服务
超级管理员管理端初始账号

等待页面提示「网盘应用部署完成」，即表示部署成功。

部署后使用​

  1. 获取访问域名：在控制台创建网盘应用的页面，可直接获取专属访问域名
  2. 登录管理端：使用部署时配置的超级管理员账号登录，从侧边栏进入「管理中心」
  3. 创建用户与分配配额：在用户管理与空间管理中创建用户、划分空间、分配存储配额
  4. 分发访问入口：将访问域名分发给用户，用户即可在 Web / PC / 移动端登录使用

开放能力​

除控制台操作外，网盘应用还提供：

  • 开放 API / SDK：用于上层业务逻辑、产品打通、交互重构等自定制场景
  • Skill 与 MCP 服务：方便开发者将网盘应用与 AI Agent 打通，实现 AI 数据的挂载和持久化存储

写在最后：存储来源正在从「人」变成「Agent」​

过去很长一段时间，云存储的使用者是人类本身。文件由人上传、命名、整理、查找、分享，所有产品设计都围绕「人的操作习惯」展开。

现在正在发生根本性的改变：AI Agent 正逐步替代人类使用和产生数据。未来的协作也不再只是「人与人」，人与 Agent、Agent 与 Agent 的协同也将成为常态。

智能体桶的价值，就是让不同的操作者——不管是人还是 Agent——使用统一的存储底座。本次发布的网盘应用，是腾讯云存储面向「人与 Agent」共用的第一个官方应用。未来，「应用管理」还会发布更多官方应用，满足不同场景、不同用户群体的诉求。
