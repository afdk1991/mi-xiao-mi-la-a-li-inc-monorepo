📚 常见问题 FAQ

如有问题或建议，请前往 CloudBase 社区提交 issue。

🏷️ 平台相关问题​

🔝 微搭体验版续费失败？​

重要提示

**微搭免费体验活动已结束！**如遇到续费失败问题，请前往 云开发平台 - 套餐用量处进行付费升级。

微搭和云开发是什么关系​

微搭属于云开发功能模块

云开发平台找不到「审批流」入口​

审批流目前只对存量和企业版及以上套餐开放。

云开发平台看不到Git入口​

请参考Git模式文档了解详情。

云开发平台是否支持认证多个小程序​

支持，请参考认证小程序至云开发平台。

云开发平台自定义短信签名​

请参考自定义短信签名文档了解详情。

云开发平台怎么绑定自定义域名​

请参考文档 应用自定义域名 进行配置。同一个应用支持绑定多个域名。

自定义域名支持其它服务商的域名吗​

支持，需要先申请腾讯云平台的SSL证书：前往申请

自定义域名ssl证书到期​

自定义域名ssl证书到期，需要手动替换一下。

云后台访问404​

检测静态托管的__auth文件夹是不是被删过

子账号配置CAM预设策略指引​

请参考子账号授权 WeDa 预设策略配置指引

📱 应用相关问题​

应用发布提示异常​

小程序应用发布异常：小程序（预览版）部署失败 Error：errCode"：-10008，"errMsg"："invalid ip: 106.54.224.183"

发布小程序提示提交审核失败_代码中含有ext.json未配置隐私接口getLocation​

"提交审核失败_代码中含有ext.json未配置隐私接口getLocation，请配置并申请权限或者承诺不使用这些接口（设置参数privacy_api_not_use为true）后再提交"，请参考位置组件配置指引配置小程序app.json文件。

发布小程序版本号问题​

小程序正式版可以自定义应用版本号。

小程序提交审核被驳回​

在应用发布版本中查看提审失败原因，并按驳回原因进行相应的操作。

发布应用提示发布额度不足​

可以通过以下方式解决：

  • 升级套餐
  • 删除之前已经发布的应用

发布H5应用，怎么隐藏顶部的云后台导航栏​

发布应用时，上架到云后台选"否"。

应用发布后，数据不显示​

  1. 由于在编辑器中，一般使用的是超级管理员权限，如果存在应用发布后数据不展示的情况，请优先检查数据模型基础权限。

  2. 请检查应用使用的数据类型是否正确，目前微搭提供的数据模型区分正式和体验数据（标准版及以上支持）

应用发布后，图片不展示​

请按以下步骤排查：

  1. 🔍 优先检查云存储权限是否放开

  2. 📖 如果云存储权限设置没问题，请参考图片组件文档常见问题说明

H5应用访问地址被微信侧封控如何解决​

被微信侧封控，可以按以下方式解决：

  • 使用应用自定义域名
  • 申请恢复

访问提示 "error": "permission_denied"​

{
    "error": "permission_denied",
    "error_code": 7,
    "error_description": "cors permission denied, please check if xx.xxx.xx in your client xxxxx-xxxxx domains"
}

ip 需要添加安全域名配置，环境配置-安全域名配置需要加上域名

该配置有缓存，预计配置后10分钟左右生效

🛠️ 数据模型相关问题​

数据模型创建成功，但是没有切换「体验/正式数据」入口​

目前体验数据只对云开发标准版及以上套餐支持

数据加载慢​

可以通过以下方式排查和解决：

  1. 先在日志面板查看是否有慢查询，存在慢查询可以按提示添加索引字段

  2. 提升套餐版本，增加QPS

MySql数据模型支持事务吗​

目前 MySQL SDK 不支持事务，如需使用事务功能，可直接使用原生 MySQL SDK 来实现。

单次查询超过 200 条数据，该怎么实现​

使用数据库查询集合的方式，单次最多查询 1000 条数据。

单条数据存储大小有限制吗​

数组或对象类型没有上限，但一条文档数据的上限是16MB​， 考虑到还有过重的网络io和序列化成本，不建议在数组中无限量增加数据

🛠️ 开发相关问题​

怎么开启debug模式​

请参考应用调试文档了解详情。

调用系统通用选项集APIs报401​

检查APIs配置的访问密钥。

发布应用后，组件功能异常​

请提供以下信息以便排查：

  • 文字简单描述组件问题表现
  • 提供预览链接
  • 因组件缺陷导致的问题，组件修复后，引导用户升级组件->重新发布应用

模块功能异常报错​

需要提供完整错误信息（在报错信息上复制即可）

工作流执行并发限制​

存在调用量限制，每小时 2000 次。

编辑器中事件执行什么情况会走失败分支​

以下情况会触发失败分支：

  • 🌐 网络状态异常
  • ⚠️ 服务内部错误
  • 💻 自定义代码主动抛出异常：throw new Error("发生了一个错误")

发布本地组件库提示 "unhandledRejection CloudBaseError: src 文件上传对象存储失败"​

  • 现象：

本地组件库执行 tcb lowcode publish 时，提示 unhandledRejection CloudBaseError: src文件上传对象存储失败

  • 解决方法：

自定义组件库Cli版本过低，请升级版本至 2.10.0，可参考 升级公告：自定义组件库Cli升级提醒

📱 小程序相关问题​

小程序后台版本管理禁用​

小程序与云开发平台进行了扫码授权绑定，小程序后台第三方绑定了微搭低代码，需要前往解除。

扫码授权失败，提示"小程序与腾讯云账号绑定不一致或未开通云开发"​

可能的原因及解决方法：

  • 提示小程序与腾讯云账号绑定不一致，请前往腾讯云账号中心检查账号关联关系

  • 提示未开通云开发，请参考该文档开通云开发中的步骤2开通云开发

:::info说明 若小程序是当天注册或微信认证，微信侧返回小程序信息存在延迟情况，可以晚点再进行扫码授权绑定 :::

小程序访问报【资源复用】未获得该环境授权​

按提示进行环境共享操作，具体步骤可以参考环境共享操作指引。

如何实现小程序跳转到另一个小程序​

有两种方式可以实现：

  • 使用小程序原生API: wx.navigateToMiniProgram

  • 使用微搭API

如何接入微信支付​

请参考微信支付接入流程

小程序下载文件提示downloadFile:fail url not in domain list​

请参考downloadFile域名配置指南配置小程序download域名

小程序页面怎么开启分享（可视化开发方式）​

可以前往页面配置，打开转发开关

小程序后台生成小程序码，从微搭复制的路径填进去报路径不存在？​

从微搭复制到页面路径后面需要再添加.html

小程序中调用退出登录方法后，页面访问异常​

在编辑器中定义以下示例的 JavaScript 方法，并在触发退出的事件中调用该方法：

export default async function ({ event, data }) {
  // 设置退出登录状态
  $w.page.dataset.state.isToLogOut = true;

  // 执行退出登录
  await $w.auth?.signOut?.();

  // 判断平台类型并执行相应操作
  $w.wedaContext.platforms.includes("MP")
    ? // 小程序端：重启并跳转到指定页面
      wx.restartMiniProgram({
        path: "替换自己的页面路径", // 请替换为实际的页面路径
      })
    : // Web 端：延时刷新页面，自动跳转到默认登录页
      setTimeout(() => {
        window.location.reload();
      }, 1000);
}
使用说明
  • 请将 "替换自己的页面路径" 替换为实际需要跳转的页面路径
  • 小程序端使用 wx.restartMiniProgram() 重启小程序
  • Web 端使用 window.location.reload() 刷新页面

使用微搭的软件化标准版开发小程序，上线后可以申请自己的软件著作权吗​

微搭只是开发工具，小程序的著作权属于小程序开发者，小程序开发者可以申请小程序的软件著作权。
