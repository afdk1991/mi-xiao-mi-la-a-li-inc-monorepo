License 续期

「微搭私有部署」的 License 具有有效期限制。当 License 即将到期或需要升级版本时，您需要及时进行续期操作以确保服务正常运行。

续期时机提醒

建议在 License 到期前 7-15 天 完成续期操作，避免因 License 过期导致的服务中断。

前置准备​

获取环境 ID​

关键步骤

续期前必须先获取当前私有化部署的环境 ID，确保续期的 License 与实际环境匹配，否则会导致服务不可用。

操作步骤：

  1. 登录您的「微搭私有化开发平台」
  2. 在开发环境中查看并记录当前的环境 ID：

续期信息确认​

在开始续期前，请确认以下信息：

确认项目说明重要性
当前 License 到期时间确定续期的紧急程度高
版本类型需求社区版/企业版功能差异高
环境 ID 准确性必须与实际部署环境一致关键
业务影响评估选择合适的续期时间窗口中

续期操作流程​

步骤 1：进入 License 管理​

前往 「微搭控制台」License 管理 页面：

步骤 2：选择续期操作​

在 License 管理页面找到对应的环境，点击 续期 或 升级 按钮：

步骤 3：配置续期参数​

进入续期界面，选择需要续期的私有化版本和时长：

版本选择指南
  • 社区版：适合个人开发者和小团队，功能基础但限时免费
  • 企业版：适合生产环境，提供更多高级功能和专业技术支持
  • 版本对比：详见 功能清单 了解具体差异

步骤 4：获取新 License​

续期成功后，返回 License 列表查看更新后的 License：

应用新 License​

获取新 License 后，需要将其应用到私有化部署环境中。请根据您的部署方式选择对应的应用方法：

集群版用户

如果您使用的是 Kubernetes 集群部署方式，请参考 集群版 License 续期指南 进行操作。

  • 命令行更新

适用场景：推荐使用，操作简单直观，适合大多数用户

操作步骤：

  1. 返回本地「微搭私有部署平台」
  2. 在授权提醒消息中，点击 上传授权 按钮：

  1. 在 License 续期界面填写新的 License，点击 开始续期：

适用场景：适合熟悉命令行操作的用户，支持批量处理和自动化部署

操作步骤：

  1. 备份并更新 License 文件：

    # 切换到 weda 部署目录
    cd /data/tencent/weda

    # 备份原 License 文件（重要）
    cp LICENSE.txt LICENSE.txt.backup.$(date +%Y%m%d_%H%M%S)

    # 编辑 License 文件
    vim LICENSE.txt
    注意事项
    • 将从控制台获取的新 License 内容完整复制到文件中
    • 确保文件内容格式正确，无多余空格或换行
    • 保存文件前请仔细检查内容完整性

  2. 执行升级校验：

    # 在 weda 目录中执行升级脚本
    ./upgrade.sh
