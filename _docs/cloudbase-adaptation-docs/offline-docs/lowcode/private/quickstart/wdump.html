平台卸载指南

本文档将指导您如何完全卸载微搭私有部署平台，包括停止服务、删除容器和清理数据。

卸载前准备​

重要提醒
  • 数据备份：卸载前请确保已备份重要数据，删除后无法恢复
  • 安装目录：默认安装目录为 /data/tencent/weda
  • 操作权限：需要 root 权限执行卸载操作

卸载步骤​

步骤 1：停止服务​

首先停止所有运行中的服务容器：

cd /data/tencent/weda
docker-compose --profile all stop

步骤 2：删除容器​

删除所有相关的 Docker 容器：

docker-compose --profile all rm

步骤 3：清理数据目录​

数据清理警告

执行以下命令将永久删除所有平台数据，包括：

  • 配置文件（configs）
  • 日志文件（logs）
  • 数据库和存储数据（storage）

此操作不可逆，请谨慎执行！

# 删除配置文件目录
rm -rf configs

# 删除日志文件目录
rm -rf logs

# 删除数据存储目录
rm -rf storage

卸载验证​

完成上述步骤后，可以通过以下方式验证卸载是否成功：

  1. 检查容器状态

    docker ps -a | grep weda

    应该没有相关容器显示

  2. 检查目录清理

    ls -la /data/tencent/weda/

    相关目录应该已被删除

  3. 检查端口占用

    netstat -tlnp | grep :80

    80端口应该不再被占用

可选操作​

清理 Docker 镜像​

如果需要完全清理相关的 Docker 镜像以释放磁盘空间：

# 查看微搭相关镜像
docker images | grep weda

# 删除不需要的镜像（请根据实际情况选择）
docker rmi <镜像ID>

清理安装目录​

如果需要完全删除安装目录：

# 谨慎操作：删除整个安装目录
rm -rf /data/tencent/weda

总结​

通过以上步骤，您已经成功完成了微搭私有部署平台的卸载：

  1. ✅ 停止了所有运行中的服务
  2. ✅ 删除了相关的 Docker 容器
  3. ✅ 清理了所有平台数据和配置
  4. ✅ 验证了卸载结果

如果将来需要重新部署，请参考 部署流程文档 进行全新安装。
