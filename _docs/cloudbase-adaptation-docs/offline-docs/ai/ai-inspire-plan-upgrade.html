混元生文模型升级指南

小程序成长计划的赠送「AI 资源包」可以使用 hy3 模型，存量模型将自动切换到 hy3。

更多模型

如需使用 DeepSeek、Kimi、MiniMax、GLM 等更多模型，可切换为资源点套餐来开通，点击查看文档。

hy3-preview 已下线

hy3-preview 模型已于 2026-08-31 下线，不再提供该模型的接入服务，请统一迁移至 hy3。详见 关于 Hy3 preview 模型下线的通知。

提示

如果您之前修改过 hunyuan-exp 提供商的 Base URL 或 API Key（即接入了自定义的提供商），升级操作请直接联系对应的提供商进行咨询。

涉及的模型​

以下模型目前位于 hunyuan-exp 提供商下，需要升级：

旧模型名称新模型名称
hunyuan-2.0-thinking-20251109hy3
hunyuan-2.0-instruct-20251111hy3
hunyuan-turbos-latesthy3
hunyuan-t1-latesthy3

各平台改造方式​

小程序（wx.cloud.extend.AI）​

版本要求

需要微信小程序基础库版本 3.15.1 及以上。

需将 createModel 的参数由 "hunyuan-exp" 改为 "cloudbase"，同时将 model 字段改为 "hy3"：

改造前：

const model = wx.cloud.extend.AI.createModel("hunyuan-exp");

const res = await model.streamText({
  data: {
    model: "hunyuan-2.0-instruct-20251111",
    messages: [{ role: "user", content: "你好" }],
  },
});

改造后：

const model = wx.cloud.extend.AI.createModel("cloudbase");

const res = await model.streamText({
  data: {
    model: "hy3",
    messages: [{ role: "user", content: "你好" }],
  },
});

Web SDK（@cloudbase/js-sdk）​

需将 provider 字段由 "hunyuan-exp" 改为 "cloudbase"，同时将 model 改为 "hy3"：

改造前：

import cloudbase from "@cloudbase/js-sdk";

const app = cloudbase.init({ env: "<ENV_ID>" });
const ai = app.ai();

const res = await ai.streamText({
  provider: "hunyuan-exp",
  model: "hunyuan-2.0-instruct-20251111",
  messages: [{ role: "user", content: "你好" }],
});

改造后：

import cloudbase from "@cloudbase/js-sdk";

const app = cloudbase.init({ env: "<ENV_ID>" });
const ai = app.ai();

const res = await ai.streamText({
  provider: "cloudbase",
  model: "hy3",
  messages: [{ role: "user", content: "你好" }],
});

Node.js SDK（@cloudbase/node-sdk）​

需将 provider 字段由 "hunyuan-exp" 改为 "cloudbase"，同时将 model 改为 "hy3"：

改造前：

const cloudbase = require("@cloudbase/node-sdk");

const app = cloudbase.init({ env: "<ENV_ID>" });
const ai = app.ai();

const res = await ai.streamText({
  provider: "hunyuan-exp",
  model: "hunyuan-2.0-instruct-20251111",
  messages: [{ role: "user", content: "你好" }],
});

改造后：

const cloudbase = require("@cloudbase/node-sdk");

const app = cloudbase.init({ env: "<ENV_ID>" });
const ai = app.ai();

const res = await ai.streamText({
  provider: "cloudbase",
  model: "hy3",
  messages: [{ role: "user", content: "你好" }],
});

OpenAI SDK（兼容模式）​

需将 baseURL 中的 hunyuan-exp 替换为 cloudbase，同时将 model 改为 "hy3"：

改造前：

import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "<YOUR_API_KEY>",
  baseURL: "https://<ENV_ID>.api.tcloudbasegateway.com/v1/ai/hunyuan-exp",
});

const res = await client.chat.completions.create({
  model: "hunyuan-2.0-instruct-20251111",
  messages: [{ role: "user", content: "你好" }],
  stream: true,
});

改造后：

import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "<YOUR_API_KEY>",
  baseURL: "https://<ENV_ID>.api.tcloudbasegateway.com/v1/ai/cloudbase",
});

const res = await client.chat.completions.create({
  model: "hy3",
  messages: [{ role: "user", content: "你好" }],
  stream: true,
});

API Key 在 云开发控制台 → 环境管理 → API Key 配置 中获取。
