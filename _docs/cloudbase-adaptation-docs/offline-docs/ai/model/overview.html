概述

云开发 AI 提供开箱即用的文本生成能力，支持 DeepSeek、混元、MiniMax、Kimi、GLM 等主流大模型，覆盖以下核心功能：

功能说明
多种调用方式小程序 SDK、wx-server-sdk、Web SDK、Node SDK、cURL、OpenAI SDK、Anthropic SDK
多轮对话携带历史消息实现连续对话
流式输出逐 token 返回，提升用户体验
深度思考调用支持推理的模型获取思考过程
多模态理解输入图片、视频、文件等让模型理解
上下文缓存缓存长 prompt 前缀，降低重复调用成本
上下文管理自动截断或压缩超长对话历史
工具调用让模型调用自定义函数/工具

接入方式​

云开发提供三种大模型接入方式：

方式说明适用套餐/场景
资源点套餐使用套餐内资源点抵扣 Token，支持 DeepSeek、MiniMax、混元、Kimi、GLM 等模型资源点套餐
体验模型免费使用平台内置混元模型小程序成长计划
自定义模型配置任意兼容 OpenAI / Anthropic 协议的模型标准版及以上

资源点套餐​

信息

Token 资源包已于 2026 年 6 月 18 日停售。如当前套餐为非资源点套餐，需先前往 云开发控制台 → 套餐管理 切换为资源点套餐。

资源点套餐内的资源点可用于抵扣大模型 Token 用量，支持 DeepSeek、MiniMax、混元、Kimi、GLM 等最新模型，详见支持的模型列表。

前往开通资源点套餐

体验模型​

体验模型仅供小程序成长计划使用。目前仅支持混元，如需使用 DeepSeek 等其他模型，请切换为资源点套餐。

目前提供以下混元模型：

模型说明
hy3混元指令模型

自定义模型​

云开发标准版及以上套餐支持配置第三方模型，配置后可在云开发 JS SDK 和小程序 SDK 中直接调用。

支持的协议

自定义模型支持兼容以下协议的大模型接口，详见云开发 LLM API 支持协议介绍：

  • Chat Completions API（OpenAI 兼容，最通用）
  • Responses API
  • Anthropic Messages API

所需参数​

参数说明
BaseURL大模型 API 的请求地址
APIKey访问大模型 API 的密钥
模型名称具体的模型标识符，如 deepseek-v4-flash、deepseek-v3 等

配置步骤​

  1. 获取 BaseURL 和 API Key

    以下提供混元、DeepSeek 的接入参考，其他模型请查阅对应服务商文档：

    模型模型提供商BaseURL模型名称计费相关
    hunyuan腾讯混元大模型https://api.hunyuan.cloud.tencent.com/v1参考 混元模型列表参考 计费文档
    DeepSeekDeepSeek 官方https://api.deepseek.com/v1参考 DeepSeek 模型列表参考 DeepSeek 文档

  2. 在平台中配置

    进入 云开发 AI+ 控制台，有两种方式：

    • 已支持的平台：直接选择对应平台，填写 API Key 即可

    • 其他模型：点击「添加模型提供商」按钮，填写 BaseURL、API Key 和模型名称

常见问题​

如何判断大模型是否兼容支持的协议？​

云开发支持 Chat Completions、Responses API、Anthropic Messages API 三种协议。绝大多数主流大模型（DeepSeek、GLM、Kimi、通义千问等）都兼容 Chat Completions 协议，通常在其 API 文档中会明确说明"兼容 OpenAI 接口"。

配置后无法正常使用大模型怎么办？​

请检查以下几点：

  • API Key 是否正确且未过期
  • BaseURL 是否准确
  • 模型名称是否与提供商文档中的一致
  • 是否已在第三方平台开启付费或完成充值

大模型支持多少并发？​

  • 使用体验模型时，一个环境支持 5 个并发。
  • 配置了自定义模型后，平台不再限制并发，实际并发上限取决于第三方模型提供商的限制。
