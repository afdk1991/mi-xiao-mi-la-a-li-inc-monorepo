配置服务号客服

快速配置让云开发 AI 对接服务号客服，实现智能客服功能。

前置条件​

  • 已注册微信公众号（服务号）
  • 已创建云开发环境（点击去创建）
  • 已创建 Agent（点击去创建）

步骤 1：获取服务号 AppId​

进入 服务号后台，在「设置与开发」>「开发接口管理」中查看 AppId。

首次进入需要先成为开发者：

成为开发者后即可查看 AppId：

步骤 2：授权服务号​

  1. 进入云开发 AI 控制台，选择「Agent」模块
  2. 在「接入指引」中找到「微信平台」
  3. 选择「服务号」，点击「立即授权」
  4. 填入上一步获取的 AppId，点击「下一步」
  5. 使用服务号管理员微信扫码完成授权

📝 说明：此授权允许云开发代理服务号客服能力，实现 AI 自动回复消息。

步骤 3：开发​

完成授权后，需要对 Agent 进行改造以支持微信平台消息格式。根据你的 Agent 类型选择对应的开发文档：

  • agent- 前缀的 Agent：请参考 微信平台适配器开发文档
  • ibot- 前缀的 Agent：请参考 ibot-前缀的Agent接入微信回调消息

步骤 4：测试​

完成开发部署后，即可测试智能客服功能：

  1. 打开你的服务号对话窗口
  2. 发送任意消息
  3. 等待 AI Agent 自动回复

优化建议​

提升回复速度​

在 Agent 提示词中添加以下设定，可显著提升回复速度：

  • 智能体以极简风格回应问题
  • 简化复杂问题的回答，提炼核心信息
  • 严格限制回复内容的长度和相关性，避免冗余
  • 不要输出 Markdown 格式，直接输出纯文本

⚠️ 注意：更改提示词后，历史对话记录可能会影响模型的输出效果。

模型选择​

  • 推荐：混元模型、DeepSeek V3（响应速度快）
  • 不推荐：DeepSeek R1 等深度思考模型（响应时间较慢）

更好的体验​

如需更丰富的对话体验（如 Markdown 渲染、多轮对话展示），可考虑在服务号菜单中嵌入 H5 页面或小程序。
