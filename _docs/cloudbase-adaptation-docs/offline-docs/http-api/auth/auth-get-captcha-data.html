获取图片验证码

POST 
/auth/v1/captcha/data

接口说明​

获取图片验证码接口，返回符合RFC 2397标准的内联图片数据URI，用于在登录、注册等场景中进行人机验证。

入参要求​

请求参数​

  • 无需传入参数，直接调用即可

前置条件​

  • 无特殊前置条件
  • 建议在用户登录失败次数过多时调用
  • 可在注册、找回密码等敏感操作时使用

出参说明​

成功响应​

  • data: 图片数据（必填，RFC 2397标准的内联图片数据URI，格式为data:image/gif;base64,xxx）
  • type: 资源类型（必填，固定值为"image"）
  • token: 验证码token（必填，用于后续验证接口）
  • expires_in: 过期时间（必填，单位为秒，默认300秒）

获取图片验证码请求示例​

POST /auth/v1/captcha/data
Content-Type: application/json

字段说明​

响应参数​

字段名类型必填说明
datastring是图片数据，RFC 2397标准的内联图片数据URI，包含协议头(data:)、MIME类型(image/gif)、编码方式(base64)和实际数据
typestring是资源类型，固定值为"image"
tokenstring是验证码token，用于后续验证接口
expires_ininteger是过期时间，单位为秒，默认300秒

使用流程​

1. 获取验证码图片​

  • 前端调用该接口获取验证码数据
  • 将返回的data字段直接作为<img src>的值渲染
  • 在本地存储中保存返回的token（建议使用localStorage）

2. 用户输入验证码​

  • 用户识别图片中的验证码内容
  • 在输入框中输入识别的验证码

3. 提交验证码验证​

  • 调用验证图片验证码接口
  • 传入token和用户输入的验证码
  • 获取captcha_token

4. 业务接口鉴权​

  • 在需要验证码保护的业务请求中附加请求头
  • 请求头格式：x-captcha-token: xxx

关键特性​

图片格式​

  • 符合RFC 2397标准的Data URI
  • 使用GIF格式
  • Base64编码
  • 可直接在HTML中使用

安全性​

  • 验证码token有效期为300秒
  • 每次获取生成新的验证码
  • 验证码使用后立即失效
  • 支持防暴力破解机制

使用场景​

登录保护​

  • 用户登录失败次数过多时要求验证码
  • 防止暴力破解密码
  • 保护账号安全

注册保护​

  • 防止批量注册
  • 防止恶意注册
  • 保护系统资源

敏感操作保护​

  • 找回密码
  • 修改密码
  • 修改绑定信息
  • 删除账号

注意事项​

前端实现​

  • 将data字段直接赋值给img标签的src属性
  • 妥善保存token用于后续验证
  • 实现刷新验证码功能
  • 验证码过期后需重新获取

安全建议​

  • 验证码应在服务端生成
  • 验证码内容应随机且不可预测
  • 限制同一IP的获取频率
  • 记录验证码获取日志

常见错误​

  • 服务器错误：重试获取
  • 网络超时：检查网络连接
  • 频率限制：等待后重试
