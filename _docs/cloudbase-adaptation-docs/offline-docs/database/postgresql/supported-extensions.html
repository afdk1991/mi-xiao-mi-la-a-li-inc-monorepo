使用建议​

  • 本文采用扩展总览加单项说明的方式组织，便于按功能查找扩展。CloudBase PostgreSQL 的扩展支持范围以当前实例查询结果为准。
  • 使用扩展前，建议先在测试环境验证权限、性能、备份恢复和跨环境迁移影响。
  • FDW、调度、审计、复制、过程语言、低层诊断等扩展通常需要更严格的权限治理。
  • 扩展提供的是数据库能力，不建议把低层诊断、复制、调度或外部数据访问能力直接暴露给前端。

扩展介绍​

address_standardizer​

  • 名称：address_standardizer
  • 版本：3.5.0
  • 访问链接：PostGIS 文档
  • 功能：地址解析和标准化，常用于地理编码前的数据清洗。
  • 使用说明：在导入用户地址、门店地址或物流地址后，可先用该扩展把自由文本地址拆解为街道、城市、邮编等结构化字段，再进入地理编码或地址匹配流程。
  • 注意事项：地址解析依赖规则和数据集，建议对目标国家或地区做样本校验；不要把解析结果直接作为唯一地址校验依据。

address_standardizer_data_us​

  • 名称：address_standardizer_data_us
  • 版本：3.5.0
  • 访问链接：PostGIS 文档
  • 功能：美国地址标准化示例数据集。
  • 使用说明：配合 address_standardizer 处理美国地址样例或美国地址标准化验证，适合演示、测试和美国地址数据清洗。
  • 注意事项：该数据集面向美国地址，不适合作为中国或其他地区地址标准化规则；跨地区业务应准备本地化规则和测试集。

age​

  • 名称：age
  • 版本：1.5.0
  • 访问链接：Apache AGE 官网
  • 功能：Apache AGE 图数据库能力，可在 PostgreSQL 中处理图数据。
  • 使用说明：用于在 PostgreSQL 中建模图结构，例如用户关系、知识图谱、依赖关系和路径查询。适合需要图遍历和关系推理的场景。
  • 注意事项：图查询模型与传统关系模型不同，引入前应确认查询语言、索引方式和备份恢复流程；复杂图遍历可能带来较高计算成本。

amcheck​

  • 名称：amcheck
  • 版本：1.4
  • 访问链接：PostgreSQL 文档
  • 功能：检查索引和关系完整性，适合低层数据一致性诊断。
  • 使用说明：在怀疑索引损坏、关系页异常或需要做低层一致性巡检时使用，通过校验函数检查 B-tree 等结构。
  • 注意事项：该扩展偏底层诊断，通常由 DBA 或运维人员使用；校验大对象可能消耗 IO，建议在低峰期执行。

autoinc​

  • 名称：autoinc
  • 版本：1.0
  • 访问链接：PostgreSQL 文档
  • 功能：通过触发器自动维护自增字段。
  • 使用说明：用于旧表或兼容场景中通过触发器为字段生成递增值。新表优先使用 identity、serial 或序列。
  • 注意事项：触发器自增容易隐藏写入逻辑，新项目不建议优先使用；并发写入场景应确认唯一性和事务行为。

bloom​

  • 名称：bloom
  • 版本：1.0
  • 访问链接：PostgreSQL 文档
  • 功能：Bloom 索引访问方法，适合多列等值过滤的签名索引。
  • 使用说明：当查询经常按多个列组合做等值过滤，且不适合建立大量组合 B-tree 索引时，可考虑 Bloom 索引。
  • 注意事项：Bloom 索引存在误判，需要回表复查；它不适合范围查询，也不一定替代精确 B-tree 组合索引。

bool_plperl​

  • 名称：bool_plperl
  • 版本：1.0
  • 访问链接：PostgreSQL 文档
  • 功能：在 bool 与 PL/Perl 之间做类型转换。
  • 使用说明：在 PL/Perl 函数需要处理 PostgreSQL boolean 类型时使用，让过程语言函数能正确读写 bool 值。
  • 注意事项：过程语言扩展会扩大数据库内可执行逻辑范围，应限制函数创建权限并避免在前端可调用函数中执行不受控逻辑。

btree_gin​

  • 名称：btree_gin
  • 版本：1.3
  • 访问链接：PostgreSQL 文档
  • 功能：为常见 B-tree 数据类型提供 GIN 索引支持。
  • 使用说明：在一个 GIN 索引中组合普通标量字段与数组、全文检索或 JSONB 字段时使用，减少多索引组合成本。
  • 注意事项：GIN 索引写入成本较高；如果只是普通等值或范围查询，优先使用 B-tree。

btree_gist​

  • 名称：btree_gist
  • 版本：1.7
  • 访问链接：PostgreSQL 文档
  • 功能：为常见 B-tree 数据类型提供 GiST 索引支持。
  • 使用说明：在 GiST 索引或排他约束中使用普通标量类型，例如时间区间冲突检测、范围约束和空间数据组合约束。
  • 注意事项：GiST 索引适合特定操作符族；普通排序和等值查询仍优先考虑 B-tree。

chkpass​

  • 名称：chkpass
  • 版本：1.0
  • 访问链接：PostgreSQL 历史文档
  • 功能：自动加密密码的数据类型。
  • 使用说明：用于兼容旧系统中数据库内密码字段的自动加密存储。新应用通常应使用专门的认证服务和成熟密码哈希方案。
  • 注意事项：该扩展已不适合作为现代认证体系的首选；不要自行设计登录密码存储方案。

citext​

  • 名称：citext
  • 版本：1.6
  • 访问链接：PostgreSQL 文档
  • 功能：大小写不敏感的文本类型。
  • 使用说明：用于邮箱、用户名、标签等大小写不敏感字段，避免每次查询都写 lower(column) 比较。
  • 注意事项：使用 citext 前要确认唯一性语义，例如邮箱是否需要大小写不敏感唯一约束；排序和本地化规则仍需测试。

cos_fdw​

  • 名称：cos_fdw
  • 版本：1.0
  • 访问链接：腾讯云文档
  • 功能：访问腾讯云 COS 平面文件的外部数据封装器。
  • 使用说明：用于把 COS 中的结构化文件映射为外部表，适合低频数据导入、分析或临时查询。
  • 注意事项：FDW 查询受外部存储、网络和文件格式影响，不建议承载高频在线交易查询；注意 COS 访问凭据管理。

count_distinct​

  • 名称：count_distinct
  • 版本：3.0.2
  • 访问链接：PGXN
  • 功能：COUNT(DISTINCT ...) 的替代聚合实现，可配合 HashAggregate 使用。
  • 使用说明：在大规模聚合去重统计中用于优化 count distinct 的执行方式，适合分析类查询。
  • 注意事项：效果依赖数据分布和执行计划，上线前应对比 EXPLAIN ANALYZE；不要盲目替换所有 COUNT(DISTINCT)。

cube​

  • 名称：cube
  • 版本：1.5
  • 访问链接：PostgreSQL 文档
  • 功能：多维立方体数据类型。
  • 使用说明：用于多维点、范围和相似度计算，常与 GiST 索引配合处理简单向量或多维数据。
  • 注意事项：复杂向量检索优先考虑 vector/vectorscale；cube 更适合较低维的几何或多维数值场景。

dblink​

  • 名称：dblink
  • 版本：1.2
  • 访问链接：PostgreSQL 文档
  • 功能：从当前数据库连接并查询其他 PostgreSQL 数据库。
  • 使用说明：用于跨 PostgreSQL 数据库执行查询或迁移少量数据，可在函数或 SQL 中拉取远端结果。
  • 注意事项：连接信息和凭据需要严格保护；跨库查询不适合高频业务路径，网络波动会直接影响查询稳定性。

  • 名称：decoderbufs
  • 版本：0.1.0
  • 访问链接：GitHub

  • 使用说明：用于逻辑复制或变更数据捕获，将 WAL 变化编码为 Protocol Buffer 供下游消费。
  • 注意事项：需要理解复制槽、WAL 保留和消费延迟；下游长期不消费可能导致 WAL 积压。

  • 注意事项：全文检索字典需要和 text search configuration 配套配置；修改分词策略后应重建或刷新相关索引。
