查询数据

通过 HTTP RESTful API 对 PostgreSQL 数据库进行查询操作。具体接口详情请参考 HTTP API/PostgreSQL 数据库

💡 提示：PostgreSQL 数据库的 HTTP API 基于 PostgREST 协议，查询语法与 PostgREST 完全兼容。

基础语法​

GET https://<envId>.api.tcloudbasegateway.com/v1/rdb/rest/:table
Authorization: Bearer <access_token>
Content-Type: application/json

💡 提示：access_token 请参考 获取 AccessToken

⚠️ 注意：REST API 目前只支持 public schema，:table 必须是 public schema 下的表或视图；auth、storage 等其他 schema 无法通过 REST API 访问。

基础查询​

# 查询 film表 所有数据
curl -X GET 'https://<envId>.api.tcloudbasegateway.com/v1/rdb/rest/film' \
-H 'Authorization: Bearer <access_token>'

💡 注意：返回的数据是所有字段数据，默认为/table?select=*

请求返回示例
HTTP/1.1 200 OK
Header:
    content-length: 1037
    content-type: application/json; charset=utf-8
Body:
[
    {
        "_openid": "1977683311217119233",
        "director": "陈凯歌",
        "duration": 171,
        "id": 1,
        "release_year": 1993,
        "title": "霸王别姬"
    },
    // ... 共 15 条数据
]

条件查询​

  • 具体操作符参考：操作符
  • 具体逻辑运算符参考：逻辑运算符
# 查询导演为 Christopher Nolan 的电影
curl -X GET 'https://<envId>.api.tcloudbasegateway.com/v1/rdb/rest/film?director=eq.Christopher Nolan' \
-H 'Authorization: Bearer <access_token>'

# 查询 2000 年后上映的电影，电影时长不超过 120 分钟
curl -X GET 'https://<envId>.api.tcloudbasegateway.com/v1/rdb/rest/film?release_year=gte.2000&duration=lt.120' \
-H 'Authorization: Bearer <access_token>'

# 查询 2000 年后上映的电影，导演是 Christopher Nolan 或者 姜文
curl -X GET 'https://<envId>.api.tcloudbasegateway.com/v1/rdb/rest/film?or=(director.eq.Christopher Nolan, director.eq.姜文)' \
-H 'Authorization: Bearer <access_token>'

计数查询​

# 查询 2000 年后的电影和总数
curl -X GET 'https://<envId>.api.tcloudbasegateway.com/v1/rdb/rest/film?select=*&release_year=gte.2000' \
-H 'Authorization: Bearer <access_token>' \
-H 'Prefer: count=exact'

Request

  • 指定 Header Prefer: count=exact 时，返回符合条件的数据总数

Response

  • content-range: 0-9/10 表示本次查询返回的数据范围，共计 10 条数据，0 表示无偏移，9 表示最后一条数据的索引，10 表示总数

强制返回对象格式​

当前数据返回都是以数组的形式返回，如果需要强制返回对象格式，可以指定 Header Accept: application/vnd.pgrst.object+json

⚠️ 注意：当明确只有一条数据返回时才能使用此方式，可以加上 limit=1 用来限制返回的数据条数

curl -i -X GET 'https://<envId>.api.tcloudbasegateway.com/v1/rdb/rest/film?select=*&id=eq.1&limit=1' \
-H 'Authorization: Bearer <access_token>' \
-H 'Accept: application/vnd.pgrst.object+json'
请求返回示例
HTTP/1.1 200 OK
Header:
    content-length: 121
    content-type: application/vnd.pgrst.object+json
Body:
{
    "director": "陈凯歌",
    "duration": 171,
    "id": 1,
    "release_year": 1993,
    "title": "霸王别姬",
    "_openid": "1977683311217119233"
}

字面量查询​

PostgreSQL 允许创建带有空格等特殊字符的表和字段，此时 url 请求就需要做字面量处理(使用双引号标记)避免和特殊字符、关键字冲突。

假设有如下表结构：

  • 表名： my_table
  • 字段名： full_name、email_address
curl -i -X GET 'https://<envId>.api.tcloudbasegateway.com/v1/rdb/rest/my_table?select=full_name,email_address' \
-H 'Content-Type: application/json' \
-H 'Authorization: Bearer <access_token>'
请求返回示例
HTTP/1.1 200 OK
Header:
    content-length: 61
    content-type: application/json; charset=utf-8
Body:
[
    {
        "email_address": "john@example.com",
        "full_name": "John Doe"
    }
]

💡 提示：如果表名或字段名包含空格等特殊字符（如 my table、full name），需要使用双引号包裹，例如 ?select="full name","email address"

操作符​

比较操作符​

操作符说明示例
eq等于?id=eq.1
neq不等于?id=neq.1
gt大于?age=gt.18
gte大于等于?age=gte.18
lt小于?age=lt.35
lte小于等于?age=lte.35
like模糊匹配?name=like.%value%
ilike模糊匹配（不区分大小写）?name=ilike.%value%
match正则匹配（POSIX）?name=match.^A
imatch正则匹配（POSIX，不区分大小写）?name=imatch.^a
in在列表中?id=in.(1,2,3)
is判断空值/布尔?age=is.null

数组与 JSON 操作符​

操作符说明示例
cs包含?tags=cs.{sci-fi,action}
cd被包含?tags=cd.{sci-fi,action,drama}
ov重叠?tags=ov.{action,comedy}

范围操作符​

操作符说明示例
sl严格左侧?range=sl.(0,5)
sr严格右侧?range=sr.(5,10)
nxr不超出右侧?range=nxr.(0,10)
nxl不超出左侧?range=nxl.(0,10)
adj相邻?range=adj.(0,5)

全文检索操作符​

操作符说明示例
fts全文检索（to_tsquery）?description=fts.PostgreSQL
plfts全文检索（plainto_tsquery）?description=plfts.PostgreSQL database
phfts全文检索（phraseto_tsquery）?description=phfts.PostgreSQL database
wfts全文检索（websearch_to_tsquery）?description=wfts.PostgreSQL or database

💡 提示：全文检索操作符支持指定语言配置，格式为 fts(language).value，例如 ?description=fts(english).PostgreSQL

支持的逻辑运算符​

运算符说明PostgreSQL 等效操作符示例
and逻辑与AND/table?id=eq.1&age=gt.18 以及 /table?select=*&and=(age.gt.18,age.lt.35)
or逻辑或OR/table?select=*&or=(id.eq.1,name.like.%value%)
not逻辑非NOT/table?select=*&age=not.eq.18&gender=not.is.null&isTrue=not.is.true
