创建及管理轻量应用服务器

本文档将指导您如何在云开发平台中快速创建和配置轻量应用服务器实例。

前置条件​

重要提示
  • 计费模式要求：云服务器使用资源点进行计费，需要将当前环境的计费模式切换为资源点模式后才能使用
  • 环境状态：确保云开发环境处于正常运行状态
  • 权限要求：需要拥有环境的管理员或开发者权限

如何切换为资源点模式​

  1. 进入 云开发控制台
  2. 选择目标环境，点击「设置」
  3. 在「计费模式」中选择「资源点模式」
  4. 确认切换后即可使用云服务器能力

创建步骤​

步骤 1：进入创建页面​

  1. 登录 云开发控制台
  2. 在左侧导航栏中，选择「云函数/云托管」展开子菜单
  3. 点击「轻量应用服务器」
  4. 点击页面右上角的「新建实例」按钮

步骤 2：选择镜像类型​

在创建实例时，您可以根据业务需求选择不同的镜像类型：

镜像类型说明适用场景预装内容
使用应用模板预装常用应用和运行环境快速搭建网站、博客、论坛等WordPress、Node.js、宝塔面板等
操作系统镜像纯净的 Linux 操作系统需要完全自定义环境的场景仅操作系统（CentOS、Ubuntu 等）
使用容器镜像预装 Docker 运行环境容器化应用部署Docker + 操作系统

镜像类型详解​

1. 应用镜像（推荐新手使用）

提供开箱即用的应用环境，无需手动安装配置，创建后即可使用。

常见应用镜像包括：

  • WordPress：适合搭建博客、企业官网
  • 宝塔 Linux 面板：可视化服务器管理工具
  • Node.js：适合部署 Node.js 应用
  • LAMP/LNMP：PHP 开发环境
  • Dify：Dify Agent 开发平台
  • 更多应用：可在创建时查看完整列表

2. 系统镜像

提供纯净的操作系统，适合有一定 Linux 基础的开发者。

支持的操作系统：

  • CentOS：企业级稳定版本（推荐）
  • Ubuntu：社区活跃，软件包丰富
  • Debian：稳定性好，适合生产环境
  • 其他系统：根据实际需求选择

适用于：

  • 需要从零开始搭建环境
  • 对系统版本有特殊要求
  • 需要安装特定软件或服务

3. 容器镜像

预装 Docker 运行环境，可以立即运行容器化应用。

适用于：

  • 已有 Docker 镜像的应用
  • 使用容器编排（如 Docker Compose）
  • 需要隔离运行多个应用

步骤 3：配置实例规格​

根据您的应用需求选择合适的配置：

配置项说明建议
CPU 核数处理器核心数量轻量应用选择 1-2 核，中等流量选择 2-4 核
内存大小可用内存容量建议至少 1GB，数据库应用建议 2GB 以上
系统盘操作系统和应用存储空间一般 40-80GB 足够
流量包每月公网流量配额根据预期访问量选择，可后续调整
选型建议
  • 个人博客/小型网站：1核1GB，40GB 系统盘
  • 中小型 Web 应用：2核2GB，60GB 系统盘
  • 数据库/高负载应用：4核4GB 或更高配置

步骤 4：完成创建​

  1. 确认配置信息和预估的资源点
  2. 点击「确定」开始创建实例
  3. 等待 1-3 分钟，实例创建完成

创建后的操作​

实例创建成功后，您可以通过“管理”操作，前往轻量服务器控制台进行服务器管理：

  1. 查看实例信息：在实例列表中查看公网 IP、运行状态等
  2. 登录服务器：通过 SSH 或控制台登录，详见 登录轻量应用服务器
  3. 查看监控：查询服务器的监控数据
  4. 配置防火墙：配置防火墙规则，根据需求放通或封禁端口

更多功能可以通过控制台了解详情。

常见问题​

Q1：创建实例时提示"环境未开启资源点模式"？

需要先将环境切换为资源点计费模式：

  1. 进入云开发控制台
  2. 进入「套餐用量」
  3. 选择「资源点模式」并确认切换
Q2：应该选择哪种镜像类型？

根据您的需求选择：

  • 新手或快速搭建：选择应用镜像（如 WordPress、宝塔面板）
  • 有 Linux 基础，需要自定义环境：选择系统镜像
  • 已有或熟悉 Docker 镜像：选择容器镜像
Q3：实例规格如何选择？

根据应用类型选择：

  • 静态网站/个人博客：1核1GB
  • 动态网站/小型应用：1核2GB 或 2核2GB
  • 数据库应用：至少 2核4GB
  • 高并发应用：4核8GB 或更高

如果不确定，可以先选择较低配置，后续根据实际使用情况升级。

Q4：创建后可以更换镜像吗？

创建后不支持直接更换镜像，但可以：

  • 重装系统：在控制台选择"重装系统"，可以更换为其他镜像（会清空数据）
  • 手动安装：在现有系统上手动安装所需软件
  • 重新创建：删除当前实例，创建新实例
Q5：创建后如何查看登录用户名和密码？

创建时采用的自动设置密码，在创建后，可以通过腾讯云控制台的站内信查看设置的密码，也可以通过管理页面重设密码：

  • 查看初始密码：通过腾讯云站内信，可以查询到创建时采用自定设置密码的情况下，设置的默认密码。
  • 重设密码：通过管理实例操作，进入实例详情页；在详情页的右上角通过重设密码操作，重新设定新的登录密码。
