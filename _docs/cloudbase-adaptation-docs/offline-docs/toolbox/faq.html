常见问题

云后台的管理员有哪些权限？​

管理员的权限包括：用户管理、权限控制、应用管理、审批管理、通知策略、首页管理、审计日志。

内部成员有什么权限？​

内部成员是指管理员通过页面添加的用户，不包括自助注册的用户。

内部成员的默认权限是数据应用和我的应用，可以查看自己权限范围的数据，还有可以使用应用。

外部用户有什么权限？​

外部用户可以使用云后台的个人中心、我的消息、我的审批。

如何修改内部成员的权限？​

可以让管理员登录云后台，在侧边栏找到权限控制，点击系统角色，找到「默认内部成员」，点击角色权限，就可以修改数据模型、自定义应用的权限。

数据管理怎么用？​

云后台支持微信云开发的数据库，管理员登录后可以看到数据库，数据库升级为数据模型之后，可以分享给内部成员使用。

数据管理支持查询、增加、修改、删除，支持导入导出，支持强类型检查，支持权限控制。

我的应用怎么用？​

你可以添加 6 个常用应用在侧边栏，可以按照分组查看管理员提供的自定义应用。

多人协作管理数据？​

管理员可以在「用户管理」中的「内部成员管理」页面，新建用户，设置用户名密码和手机号后，可以邀请成员登录云后台。

如果要修改内部成员的权限，可以在「权限控制」中「系统角色」页面找到「默认内部用户」，在里面调整权限。

无权限怎么审批？​

如果内部成员无权限修改数据，则点击修改按钮会报错，提示内部成员可以申请权限，点击申请后，管理员会收到消息提醒。

管理员可以登录云后台，在「权限控制」中「系统角色」里找到「默认内部用户」，然后调整角色权限。

云后台和应用的关系​

云后台的应用主要包括以下几类：

  1. 系统内置的模块：例如 CMS（内容管理系统），这类模块为开发者提供了内容创建、发布和管理等功能。

  2. 云模板安装的应用：云模板是一种预先配置好的应用模板，开发者可以通过安装云模板快速搭建应用，无需从零开始开发。

  3. 微搭开发的应用：微搭是腾讯云提供的一种低代码开发平台，开发者可以通过微搭快速构建和部署应用，利用云开发提供的云函数、数据库、存储等服务。

云后台和应用之间的关系是相辅相成的。云后台提供了应用运行所需的基础设施和资源，而应用则利用这些资源来实现具体的功能，服务用户。

解决云后台（cloud-admin路径）404错误​

当访问云后台（cloud-admin路径）出现404错误时，通常是由于用户删除了自己静态托管里面的 index.html 文件。以下是解决此问题的步骤：

修复步骤​

  1. 下载 index.html 文件

    访问以下链接下载 index.html 文件：

    https://weda-cloud-1258344699.cos.ap-shanghai.myqcloud.com/workbench/templates/index.html

    可以右键点击上述链接，选择“另存为”将文件保存到本地。

  2. 编辑 index.html 文件

    打开下载的 index.html 文件，将 window.WedaPortalConfig = {envId： '{{ envId }}'} {{ envId }} 替换成自己真实的环境ID。另存为 index.html 文件，注意添加 .html 的后缀。

  3. 上传 index.html 文件

    访问云开发控制台，进入静态网站托管/文件管理，选择正确的环境，检查是否有 cloud-admin 目录。如果没有，新建一个名为 cloud-admin 的文件夹，将修改过的 index.html 文件上传到 cloud-admin 目录下。

通过以上步骤，您应该能够解决云后台（cloud-admin路径）404错误。
