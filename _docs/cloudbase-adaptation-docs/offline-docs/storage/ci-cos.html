能力概览

CloudBase 云存储基于腾讯云数据万象（Cloud Infinite，CI）服务，为您提供丰富的数据处理和内容安全能力，包括图片处理、文档转换、内容审核、智能检索等功能，帮助您构建安全、高效、智能的应用。

如何使用​

在 云开发平台-云存储 页面，点击「高级能力」，即可查看数据万象的各项能力介绍，并根据指引快速开始使用。

计费说明​

内容审核、数据处理和智能检索由 COS 数据万象（CI）服务提供，按实际使用量计费。

💰 计费方式说明

当前计费方式： 由数据万象服务独立计费，费用单独结算，不包含在 CloudBase 云存储套餐中。

未来计划： 后续将支持 CloudBase 统一计费，届时可在 CloudBase 控制台统一管理和查看所有费用。

主要计费项：

  • 内容审核：按审核次数计费，不同类型价格不同
  • 图片处理：基础处理免费，高级处理按调用次数计费
  • 文档处理：按转换页数和预览次数计费

详细价格请参考：数据万象计费说明

核心能力​

📋 内容审核​

基于 AI 识别技术，自动检测文件中的违规内容，保障业务安全。

审核类型说明
图片审核检测图片中的涉黄、涉政、涉暴、违法、广告等违规内容
视频审核检测视频画面和音频中的违规内容
音频审核检测音频中的涉黄、涉政、辱骂、违法、广告等内容
文本审核检测文本中的敏感词汇和违规内容
文档审核检测 PDF、Word、Excel、PPT 等文档中的违规内容

应用场景： UGC 内容审核、社交平台、电商平台、直播平台

👉 查看内容审核详细配置 →

🖼️ 数据处理​

提供丰富的文件处理能力，实时处理无需下载，优化用户体验和节省带宽成本。

图片处理​

功能类型主要能力
基础处理缩放、裁剪、旋转、格式转换、质量调整
极智压缩TPG、HEIF、AVIF 等高压缩率格式
高级压缩智能压缩、有损/无损压缩
图片水印文字水印、图片水印、盲水印
AI 处理智能裁剪、去除背景、人像美颜

文档处理​

功能说明支持格式
文档转 HTML将文档转为 HTML 在线预览Word、Excel、PPT、PDF、TXT 等
文档转图片将文档每页转为图片格式Word、Excel、PPT、PDF 等

应用场景： 缩略图生成、自适应终端、图片优化、在线文档查看、知识库系统

🔍 智能检索​

智能检索（MetaInsight）是腾讯云数据万象（CI）提供的 AI 能力，为云存储中的图片、视频、文档等多媒体文件提供智能内容分析和检索功能。整合标量检索（元数据精确匹配）和向量检索（AI 语义匹配），帮助您快速定位和管理海量多媒体资源。

检索类型说明应用场景
基础信息检索基于文件元数据检索，如文件名、大小、类型、创建时间等文件管理、数据统计
图片检索支持以图搜图、以文搜图，基于图片内容的语义检索网盘相册、商品检索推荐
文档检索文档内容的语义检索，支持关键词搜索文档内容知识库、文档管理系统
人脸检索识别图片中的人脸特征，按人脸搜索包含同一人物的照片安防监控、考勤系统、智能相册
多模态混合检索结合文字、图片、元数据等多种方式进行综合检索复杂业务场景

应用场景： 图片资源管理、智能相册、电商平台商品搜索、媒体资产管理、内容创作素材库
