CloudBase 开发文档

CloudBase 是面向 AI Coding 的后端一体化平台，内置数据库、存储、身份认证、云函数与云托管等服务，支持快速构建小程序、Web 应用、移动 App、管理后台与 AI 应用，让你专注产品与业务逻辑。

产品能力

数据库提供 Postgres 关系型数据库与文档型数据库，支持实时订阅、备份恢复与细粒度权限控制，满足从原型到生产的全链路数据需求。身份认证内置邮箱、手机号、OAuth、微信登录等多种身份方式，小程序场景免鉴权云调用，配合安全规则实现行级数据访问控制。云存储上传、管理和分发任意文件，支持图片处理、权限策略与 CDN 加速，与数据库深度集成实现基于用户身份的访问控制。云函数 & 云托管云函数提供 Serverless 函数运行时，支持多种语言与 HTTP/事件触发；云托管运行任意语言的容器化服务，支持自动扩缩容与灰度发布，两种计算形态按需选择。静态托管一键部署前端站点，自动 HTTPS 与全球 CDN 加速，支持自定义域名、History 路由和版本回滚。AI 能力提供统一的大模型接入和 Agent 开发能力，帮助开发者在小程序、Web、公众号、企微客服等场景快速接入 AI 能力。
