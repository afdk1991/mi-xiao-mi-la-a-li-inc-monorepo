2026-06​

【CloudBase AI 开发工具】：PostgreSQL 数据库支持、插件生态、环境管理与认证​

插件生态发布​

CloudBase 插件正式上线，支持通过插件市场一键安装至主流 AI 编程助手：

  • Codex / Claude Code：通过 marketplace 添加 CloudBase 插件市场，一键安装 查看安装指南 →
  • WorkBuddy：内置 CloudBase 连接器，对话界面一键启用

身份认证增强​

新增 API Key 认证方式，支持项目级凭证存储，适用于云端 IDE、CI/CD 等自动化场景。

PostgreSQL 数据库支持​

新增 PostgreSQL MCP 工具集和 schema-first 开发工作流，支持完整的 PG 数据库操作能力。

环境管理自助化​

支持通过工具查询套餐、创建环境、变更套餐（升降配）和续费。

详情参考：CloudBase AI 开发工具文档 · 完整更新日志 →

2026-05-28​

【集成中心】：第三方服务一站式接入​

CloudBase 推出 集成中心（Integration Center），将微信支付、微信公众号等第三方服务封装为开箱即用的「集成」。开发者无需自行管理凭证、处理验签解密、维护回调域名，在控制台填写一次配置即可生成对应的云函数与回调链路。查看功能介绍 →

已支持的集成类型：

  • 微信支付：小程序支付 / JSAPI 网页支付 / Native 扫码支付
  • 微信公众号：公众号开放服务（网页授权、用户消息、模板消息、自定义菜单等）

核心价值：

  • 凭证统一托管：API 密钥、证书、私钥由平台管理，不进入业务代码
  • 回调代收代验：自动接收第三方异步通知，验签解密后以明文转发给业务函数
  • 一键部署函数：创建集成时自动生成 HTTP 云函数模板，业务侧仅需补齐业务逻辑

详情请参考：集成中心文档 · 使用流程 · 常见问题

2026-03-30​

【平台能力】：云开发环境可作为云资源进行ICP备案​

过去云开发环境不支持作为备案云资源进行域名备案。

本功能上线后，个人版及以上套餐的环境，若剩余有效期在6个月以上，且开启了固定IP，则可以直接在备案控制台拉取到满足条件的云开发环境，无需额外购买云服务作为备案云资源。

流程介绍​

  1. 前往备案管理
  2. 若不满足备案条件，按页面指引进行操作即可。
  3. 若满足备案条件。点击页面上方的“去备案”按钮，即可前往备案控制台进行备案。
  1. 在备案页面可拉取到符合条件的云开发环境作为备案云资源。
  1. 进入备案申请流程，按ICP备案文档指引操作即可。

2026-03-11​

【CLI / MCP / Skills】：支持设备码登录（Device Code Flow）​

CloudBase CLI、MCP Server 和 AI Skills 现已支持 设备码登录（Device Code Flow），适用于无浏览器环境或远端服务器场景（如云端 IDE、SSH 终端、云端 OpenClaw 等），无需本地浏览器即可完成身份授权。

设备码登录：远端开发场景的身份认证方案​

传统登录方式的痛点：CLI 登录依赖本地浏览器跳转完成 OAuth 授权，在远端服务器、容器环境或云端 IDE 中无法直接使用。

设备码登录的优势：通过设备码（Device Code）解耦授权设备与登录设备，用户只需在任意浏览器中访问授权页面并输入设备码，即可完成远端环境的身份授权。

AI Agent 集成场景​

在 AI 开发工具（如 Cursor、WindSurf、CodeBuddy 等）中使用 CloudBase Skills 时，Agent 会自动触发设备码登录流程，授权完成后即可调用云开发的全部能力，实现从开发到部署的全链路自动化。

示例：在 OpenClaw 中通过 AI Agent 完成全流程​

以 OpenClaw 云端开发环境为例，展示从指令下发到部署上线的完整流程：

步骤角色操作
1用户向 Agent 发出指令：使用 CloudBase Skills，写一个 TodoList 网页，并部署上线
2Agent自动搜索并安装 CloudBase Skills，触发设备码登录
3Agent返回授权链接和设备码（如 FSN9-9B5D），等待用户完成授权
4用户在任意浏览器中打开授权链接，输入设备码完成登录
5Agent检测到授权完成，自动继续执行：创建项目 → 编写代码 → 调用 CloudBase API → 部署上线

  • 内容审核：图片/视频/文本安全审核，自动识别违规内容

详情请参考：云存储文档

2026-01-27​

【HTTP 云函数】：单实例多并发 + WebSocket 实时通信​

HTTP 云函数现已支持 单实例多并发 模式和 WebSocket/SSE 实时通信，Web 服务性能与成本优化，实时应用开发体验全面升级。查看开发文档 →

单实例多并发：降低冷启动，提升并发性能​

一个函数实例可同时处理多个请求，无需为每个请求启动新实例。相比普通云函数的「单实例单请求」模式，显著降低冷启动频率和资源消耗。

WebSocket 支持：双向实时通信能力​

原生支持 WebSocket 协议，提供全双工通信能力。适用于实时聊天、协作编辑、游戏服务器等需要双向通信的场景。WebSocket 使用指南 →

2026-01-16​

【计费模式】：资源点计费模式上线​

云开发平台推出 资源点计费模式，替代传统的"套餐额度+加购资源"固定额度方式，实现按实际用量灵活扣费，计费更精准合理。覆盖个人版、标准版、企业版和企业高级版全套现网套餐。查看资源点计费文档 →

灵活用量：告别固定额度限制​

传统模式的痛点：套餐额度固定，资源用不完造成浪费，用量超额又需要频繁加购，难以适配业务波动。

资源点模式的优势：所有资源用量按统一标准换算为资源点扣除，用多少扣多少，灵活适配各类业务场景。

⚠️ 重要提示

微搭/云开发已停售旧套餐需要先转化为现网套餐（个人版、标准版、企业版、企业高级版），才能转换为资源点计费环境

【文档型数据库】：支持连接自有MongoDB数据库​

CloudBase 新增 Mongo连接器 功能，支持将你已有的 MongoDB 数据库接入平台，无需数据迁移即可复用现有资源，配置时间不超过 5 分钟。

接入自有数据库后，您可以：

  • 无缝集成：直接管理现有数据库中的数据，无需数据迁移
  • 数据模型：基于现有数据表快速生成数据模型，自动化数据管理
  • SDK 支持：使用云开发 Web SDK / Node SDK / 小程序 SDK 统一访问
  • 安全可控：数据保留在您的数据库中，完全掌控数据安全

2026-01-09​

【HTTP网关】：访问提示中间页​

原有的“默认域名有效期续期”机制已正式下线，不再需要频繁进行手动续期。

新增 访问提示中间页，通过软性安全提醒替代硬性续期机制，确保测试环境安全合规。

当访客通过云开发「默认域名」（如 *.tcloudbaseapp.com、*.run.tcloudbase.com、*.app.tcloudbase.com）访问 Web 应用时，系统会自动跳转至 访问提示中间页，告知访客当前环境仅供开发测试使用，内容未经合规审核。

机制升级：从硬性续期到软性提醒​

旧机制的痛点：默认域名需要定期续期，一旦忘记续期，域名将无法访问，导致开发测试中断。

新机制的优势：取消续期要求，改为访问提示中间页。只要不触发流量异常的风控阈值，默认域名可持续使用于开发测试场景。

详情请参考：访问提示中间页

2025-12-24​

【接入指引】：主流框架快速接入 + AI 开发工具 MCP 连接​

CloudBase 新增 接入指引模块，提供 React、Vue、微信小程序等主流框架的快速接入方案，以及 Cursor、WindSurf 等 AI 开发工具的 MCP 连接指引

主流框架快速接入：从零到部署一步到位

传统接入方式需要开发者自行查阅多份文档、手动配置 SDK、编写样板代码，学习成本高且容易出错。现在只需在接入指引中选择你的技术栈，即可获得完整的项目模板和配置方案。

AI 开发工具 MCP 连接：智能编码体验升级

为了让开发者更高效地使用 AI 辅助开发，CloudBase 提供了主流 AI 开发工具的 MCP（Model Context Protocol）连接指引，让 AI 助手能够直接调用云开发能力。

后续更新： CloudBase AI 开发工具接入能力持续扩展，现已支持 20+ AI 开发工具（新增 WorkBuddy、Codex、Claude Code 等），并支持 插件一键安装，无需手动配置 MCP。

2025-12-18​

【身份认证】：内置邮件服务 + 短信速率限制​

CloudBase身份认证新增 零配置邮件服务，配置时间从 15 分钟降至 1 分钟。同时上线短信速率限制，有效防止资源盗刷。

内置邮件服务：告别 SMTP 配置​

传统邮件登录需要开发者自行申请第三方邮件服务、配置 SMTP 参数，流程繁琐且易出错。现在只需在控制台点击「开启邮件代发」，即可完成配置。

详情请参考：身份认证/邮箱验证码登录

短信速率限制：防止资源盗刷​

针对短信验证码被恶意请求导致的费用激增问题，新增单用户每日短信上限配置，默认 30 条/天。

配置步骤：

  1. 进入 云开发平台 / 身份认证 / 登录方式
  2. 找到「短信验证码」卡片，点击「编辑」
  3. 设置每日发送上限（建议 10-100 条，根据业务场景调整）
  4. 保存配置

详情请参考：身份认证/短信验证码登录

⚠️ 重要提示

为保护资源安全，系统已为所有环境启用默认速率限制（30 条/天）。如果你的业务场景需要更高配额（如电商平台的订单通知），请前往控制台手动调整，避免影响正常业务。

【云存储、静态托管】：支持查看 COS 存储桶​

CloudBase云存储与静态网站托管新增 查看 COS 存储桶 功能，支持使用 COS 高级能力，管理体验全面升级。

一键跳转 COS 控制台：管理更高效​

传统方式需要自行拼接访问路由才能查看底层COS桶，现在只需在「云存储」或「静态网站托管」页面点击「查看 COS 存储桶」，即可直接跳转到对应的 COS 存储桶管理页面，使用更多高级存储能力，如内容审核、数据处理、访问日志等。
