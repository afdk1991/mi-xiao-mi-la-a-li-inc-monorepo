更新日志

v5.8.8

  • [add] 新增 PlatformService（app.platform）：支持平台版套餐服务，含在售套餐查询（describePlatformPackageList）、已购平台版资源查询（describePlatforms）、平台版环境创建/启停/删除（createPlatformEnv / modifyPlatformEnv / destroyPlatformEnv）、计费周期查询（describePlatformAccountCircle）、资源点用量汇总与明细（describePlatformCreditsUsage / describePlatformCreditsUsageDetail）、环境用量排行与单环境用量（describePlatformEnvCreditsRanking / describePlatformEnvUsage），并提供平台版 HTTP 访问服务路由管理能力

v5.2.0

  • [add] 新增 AiModelService（app.aiModel）：支持 AI 模型分组管理，含创建（createAIModel）、更新（updateAIModel）、删除（deleteAIModel）、查询已配置分组列表（describeAIModels）、查询托管类型模型列表（describeManagedAIModelList）共 5 个 API；支持接入 OpenAI 兼容网关（DeepSeek、混元、Moonshot 等），自定义分组名不允许以 cloudbase 为前缀

v5.1.0

  • [add] EnvService 新增登录配置 API：getLoginConfig（查询登录策略配置）/ modifyLoginConfig（修改登录策略配置）
  • [add] EnvService 新增客户端管理 API：describeClient（查询应用客户端详情）/ modifyClient（修改应用客户端配置）
  • [add] EnvService 新增身份认证源 API：getProviders（获取三方认证源列表）/ addProvider（添加身份认证源）/ modifyProvider（修改身份认证源）/ deleteProvider（删除第三方认证源）
  • [add] EnvService 新增 API Key 管理：createApiKey（创建 API Key）/ describeApiKeyList（查询 API Key 列表）/ deleteApiKey（删除 API Key）

v5.0.0

  • [add] 新增 CloudAppService（app.cloudAppService）：支持 Web 应用统一部署（static-hosting），提供应用创建/查询/删除、版本管理、代码上传等完整 API
  • [add] 新增 LogService（app.log）：支持直接查询 CLS 日志（searchClsLog）、检查日志服务状态（checkLogServiceEnabled）、开通日志服务（createLogService），支持 module/eventType/logType 三层日志过滤
  • [add] 新增 PermissionService（app.permission）：支持资源权限管理（modifyResourcePermission / describeResourcePermission）和角色管理（createRole / describeRoleList / modifyRole / deleteRoles）
  • [add] 新增 MysqlService（app.mysql）：支持云开发托管 MySQL（Serverless CynosDB）完整管理，含实例生命周期、SQL 执行（runSql）、账号权限、备份恢复、回档、监控日志等共 30 个 API
  • [add] 新增 DocsService（app.docs）：提供 CloudBase 官方文档站的检索与读取能力，支持模块列举（listModules）、文档浏览（listModuleDocs）、统一查找（findByName）、全文搜索（searchDocs）、内容读取（readDoc）
  • [add] StorageService 新增文件/目录复制（copyFile / copyDirectory）、移动（moveFile / moveDirectory）、搜索（searchFiles）、列举当前目录（listCurrentDirectory）共 6 个方法
  • [add] DatabaseService 新增原生命令执行（runCommands）、数据回档四件套（describeRestoreTables / describeRestoreTime / describeRestoreTask / restoreTables）共 5 个方法
  • [add] EnvService 新增环境管理 API：describeEnvs / createEnv / destroyEnvWithParams / describeBaasPackageList / modifyEnvPlan / renewEnv / calculatePackageCreatePrice / calculatePackageRenewPrice / calculatePackageModifyPrice / describeBillingInfo / describeEnvAccountCircle / describeCreditsUsageDetail 共 12 个方法
  • [breakchange] app.cloudApp getter 已废弃，请迁移至 app.cloudBaseRun（CloudBaseRun/TCBR 服务）。新的 app.cloudAppService 是 CloudApp 统一部署服务的访问入口，与旧 app.cloudApp 不同，请勿混淆。
