环境管理

平台版接口说明

方法名带 Platform 前缀的接口用于管理平台版套餐资源，通过 app.platform 访问（如 app.platform.createPlatformEnv），其余接口通过 app.env 访问。平台版是账号维度的套餐方案，详见平台版概述。

listEnvs​

1. 接口描述​

接口功能：获取所有环境信息

接口声明：listEnvs(): Promise<Object>

2. 输入参数​

无

3. 返回结果​

字段必填类型说明
RequestId是String请求唯一标识
EnvList是Array<EnvItem>环境数组

EnvItem​

字段必填类型说明
EnvId是String环境 ID
Source是String环境来源。miniapp 微信小程序 / qcloud 腾讯云
Alias是String环境别名
Status是String环境状态。NORMAL 正常 / UNAVAILABLE 不可用
CreateTime是String创建时间
UpdateTime是String更新时间
Region是String地域，如 ap-shanghai
PackageId是String环境套餐 ID
PackageName是String套餐中文名称
PackageType否String套餐类型。空 / baas / tcbr
EnvType否String环境类型。baas / run / hosting / weda
PayMode否String付费方式。prepayment 预付费 / postpaid 后付费
IsAutoDegrade否Boolean是否到期自动降为免费版
IsDefault否Boolean是否为默认环境
EnvChannel否String环境渠道
Databases否Array数据库资源详情
Storages否Array存储资源详情
Functions否Array函数资源详情
LogServices否Array日志资源详情
StaticStorages否StaticStorageInfo[]静态资源信息（含静态托管域名）
Tags否Array<{Key, Value}>环境标签
EnvPreferences否Record<string, any>用户环境配置

StaticStorageInfo​

静态 CDN 资源信息。

字段类型说明
StaticDomainString静态托管 CDN 域名，如 xxx.tcloudbaseapp.com
DefaultDirNameString静态 CDN 默认文件夹，当前为根目录
StatusString资源状态。process / online / offline / init
RegionStringCOS 所属区域

4. 示例代码​

import CloudBase from '@cloudbase/manager-node'

const { env } = new CloudBase({
  secretId: 'Your SecretId',
  secretKey: 'Your SecretKey',
  envId: 'Your envId' // 云开发环境ID，可在腾讯云云开发控制台获取
})

async function test() {
  const res = await env.listEnvs()
  const { EnvList } = res
  for (let envItem of EnvList) {
    console.log(envItem.EnvId, envItem.Alias)
    // 获取静态托管域名
    const staticDomain = envItem.StaticStorages?.[0]?.StaticDomain
    if (staticDomain) {
      console.log('静态托管域名:', staticDomain)
    }
  }
}

test()

createBillingDeal​

1. 接口描述​

接口功能：创建环境计费订单

接口声明：createBillingDeal(params: CreateBillingDealParams): Promise<Object>

2. 输入参数​

字段必填类型说明
DealType是String下单操作类型，可取值：purchase（购买）、renew（续费）、modify（变配）
ProductType是String购买的产品类型，可取值：tcb-baas（baas 套餐）、tcb-promotion（大促包）、tcb-package（资源包）
PackageId是String目标下单产品/套餐 ID
CreateAndPay否Boolean是否自动支付
TimeSpan否Number购买时长
TimeUnit否String购买时长单位，可取值：d（天）、m（月）、y（年）、p（一次性）
ResourceId否String资源唯一标识符
Source否String来源，可取值：qcloud、miniapp
Alias否String资源别名
EnvId否String环境 ID
EnableExcess否Boolean开启超限按量计费
ModifyPackageId否String变配目标产品/套餐 ID
Extension否String附加信息（JSON 字符串）
AutoVoucher否Boolean是否自动选择代金券支付
ResourceTypes否String[]资源类型，新购环境时需要发货的资源，可取值：flexdb、cos、cdn、scf

3. 返回结果​

字段必填类型说明
RequestId是String请求 ID
EnvId是String环境 ID
TranId是String订单交易 ID

4. 示例代码​

import CloudBase from '@cloudbase/manager-node'

const { env } = new CloudBase({
  secretId: 'Your SecretId',
  secretKey: 'Your SecretKey',
  envId: 'Your envId' // 云开发环境ID，可在腾讯云云开发控制台获取
})

async function test() {
  const res = await env.createBillingDeal({
    DealType: 'purchase',
    ProductType: 'tcb-baas',
    PackageId: 'baas_personal',
    CreateAndPay: false,
    TimeSpan: 1,
    TimeUnit: 'm',
    Alias: 'test',
    EnvId: 'test-12345'
  })
  console.log(res.TranId) // 订单交易ID
}

Enabled否Boolean是否启用外部存储，建议显式传 true
BucketName是String共享桶名称
Region是String共享桶所在地域，例如 ap-shanghai
BasePath是String环境在共享桶内的目录前缀，同一共享桶内各环境需唯一

外部存储目前只支持腾讯云对象存储 COS，BucketName 填写 COS 存储桶名称，无需指定存储提供商。

版本提示

自 v5.8.8 起支持此接口

2. 输入参数​

字段必填类型说明
EnvId否String环境 ID，不传使用当前环境
Status否String环境状态：ENABLE（启用）/ DISABLE（禁用）
Storage否PlatformEnvResource云存储资源状态变更
FlexDB否PlatformEnvResourceFlexDB（文档型数据库）资源状态变更

PlatformEnvResource​

字段必填类型说明
Status否String资源状态：ENABLE（正常）/ DISABLE（彻底禁用）/ READONLY（只读），不传则不更新

3. 返回结果​

字段类型说明
StatusString环境最终状态，如 manualLimited
RequestIdString请求唯一标识

4. 示例代码​

const CloudBase = require('@cloudbase/manager-node')

async function test() {

StartTimeString当前计费周期开始时间
EndTimeString当前计费周期结束时间
HistoryTimeCircleTime[]历史周期列表，依次为上个、上上个周期
ExpiredBoolean套餐当前是否过期
RequestIdString请求唯一标识

CircleTime​

字段类型说明
StartTimeString周期开始时间
EndTimeString周期结束时间

4. 示例代码​

const CloudBase = require('@cloudbase/manager-node')

    WithHistoryCircle: true
  })

4. 示例代码​

const CloudBase = require('@cloudbase/manager-node')
const app = new CloudBase({ secretId: 'Your SecretId', secretKey: 'Your SecretKey', envId: 'your-env-id' })

async function test() {
  const res = await app.platform.describePlatformEnvUsage({
    EnvId: 'your-env-id',
    StartDate: '2026-09-01',
    EndDate: '2026-09-20',
    ResourceTypes: ['Storage', 'Function']
  })
  console.log('资源点总量:', res.TotalCredits)
  res.Resources?.forEach(r => {
    console.log(r.ResourceType, r.TotalCredits)
  })
}
