管理资源配额

本文介绍云开发环境的计费与配额管理，包括超限按量开关、续费、变配、套餐查询、用量查询与销毁环境，帮助您控制成本、保障线上业务不中断。

环境的创建与套餐选择请参考 开通并创建第一个环境。

超限按量开关​

关键提醒：如果购买环境时未传入 EnableOverrun: "TRUE"，请务必补充开启。未开启超限按量时，当套餐内资源用量耗尽，环境将直接停服，数据库、云函数、云存储等所有服务不可用，线上用户的请求会失败。

开启方式有两种：

  1. 购买时开启（推荐）：在 CreateEnv 请求中传入 EnableOverrun: "TRUE"，一步到位。
  2. 购买后开启：通过修改环境附加信息的接口开启或关闭超限转按量功能，传入 EnvId 与 EnableOverrun（取值 TRUE / FALSE）。若使用管理面 SDK，可在 createBillingDeal 中传入 EnableExcess: true，详见 管理面 SDK - env 接口。

开启超限按量后，超出套餐额度的部分将自动转为按量计费，业务不受影响。强烈建议所有生产环境开启此功能。

续费环境​

环境到期前，调用 RenewEnv 接口进行续费，接口会自动下单并支付。

关键参数：

参数必选类型说明
EnvId是String环境 ID
Period否Integer续费周期，单位：月，默认 1
AutoVoucher否Boolean是否自动使用代金券，默认 false

提示：建议在到期前至少 3 天续费，避免环境因欠费被停服。该接口会自动从腾讯云账户余额中扣款。

变更套餐（变配）​

当业务规模变化时，可通过 ModifyEnvPlan 接口升级或调整环境套餐。

关键参数：

参数必选类型说明
EnvId是String环境 ID
PackageId是String目标套餐 ID，通过 查询可售卖套餐 获取
AutoVoucher否Boolean是否自动使用代金券

注意：变配涉及费用差额结算，请确保账户余额充足。套餐升配后立即生效。

查询可售卖套餐​

通过 DescribeEnvPlans 接口查询当前可售卖的套餐列表，获取套餐 ID（PackageId）、价格、资源配额等详细信息。变配时通过此接口获取目标套餐 ID。

关键参数：

参数必选类型说明
PackageId否String套餐英文标识，不指定则返回所有可售卖套餐。示例：baas_integration

返回的 PlanList 为 PlanInfo 结构数组，主要字段：

字段类型说明
PackageIdString套餐英文标识
PackageTitleString套餐名称
PackageTypeString套餐类型
PackageDescriptionString套餐描述
UnitPriceString单价
ResourceLimitString资源限制（JSON 字符串，含 QPS、资源点等）
BillTagsString计费标签信息（JSON 字符串）

查询环境计费周期​

在查询资源用量前，先通过 DescribeEnvAccountCircle 获取环境的计费周期起止日期，确保用量统计与计费周期对齐。

关键参数：

参数必选类型说明
EnvId是String环境 ID
WithHistoryCircle否Booleanfalse 仅返回当前计费周期（默认）；true 额外返回历史周期

返回的 StartTime 和 EndTime 可直接作为 DescribeCreditsUsage 与 DescribeCreditsUsageDetail 接口的 StartDate / EndDate 参数，确保用量查询与计费周期精确对齐。

查询资源用量​

用量汇总​

通过 DescribeCreditsUsage 接口查询环境的整体资源点消耗汇总，包括套餐额度抵扣、资源包抵扣和超限按量部分。

关键参数：

参数必选类型说明
EnvId是String环境 ID
StartDate是String开始日期，格式：YYYY-MM-DD，建议从 查询环境计费周期 获取
EndDate是String结束日期，格式：YYYY-MM-DD

提示：返回中的 ReportValue > 0 表示已超出套餐额度，正在产生超限按量费用，建议适时升级套餐或加购资源包。

用量明细​

通过 DescribeCreditsUsageDetail 接口查询各模块（数据库、云函数、云存储等）的资源点用量明细，与用量汇总配合使用，可实现多层次用量分析。

关键参数：

参数必选类型说明
EnvId是String环境 ID
Modules是Array of String要查询的模块列表，可取值：EKS（云托管）、Database（数据库）、SCF（云函数）、COS（云存储）、AI（AI 服务）、HOSTING（静态托管）、Auth（身份认证）、Other（其他）
StartDate是String开始日期，格式：YYYY-MM-DD
EndDate是String结束日期，格式：YYYY-MM-DD
NeedUsageDetails是Boolean是否需要每日用量明细。true 返回明细，false 只返回汇总

提示：建议定期查询资源用量，及时了解各模块消耗情况，合理规划套餐资源。

销毁环境​

通过 DestroyEnv 接口销毁云开发环境。环境销毁遵循腾讯云包年包月预付费产品生命周期，分为两步：

  1. 资源退费：调用接口后根据当前环境剩余有效期自动退还相关费用（代金券不退），退款后环境进入隔离期。
  2. 环境删除：环境进入隔离期后 15 天自动删除，也可通过指定 IsForce=true 强制删除隔离期环境。

关键参数：

参数必选类型说明
EnvId是String环境 ID
IsForce否Boolean针对预付费环境，删除隔离中的环境时传 true；正常环境调用会触发退款流程进入隔离期。默认 false
BypassCheck否Boolean是否绕过资源检查（如资源包等额外资源）。为 true 时不检查资源是否有数据直接删除。默认 false

常见错误码：

错误码描述
ResourceUnavailable.InvoiceAmountLack当前发票余额不足，无法退费
ResourceUnavailable.ResourceOverdue资源过期

警告：环境退费后进入隔离期，所有资源均无法访问；环境被彻底删除后，所有数据均无法找回，请谨慎操作。销毁操作不可逆，建议在操作前做好数据备份。如需了解环境的当前状态，可先通过 DescribeEnvs 查询。

常见问题​

Q1：如何查看环境的到期时间？​

调用 DescribeBillingInfo 接口，传入环境 ID，可获取计费状态、到期时间等信息。

Q2：购买环境后多久可以使用？​

一般情况下环境会在 1-3 分钟内创建完成。可通过 DescribeEnvs 接口查询环境状态，当 Status 为 NORMAL 时表示环境已就绪。

Q3：套餐到期后环境会被删除吗？​

套餐到期后，环境会先进入停服状态（资源保留），超过保留期后才会被彻底销毁。建议在到期前及时续费。

Q4：是否支持从其他套餐变配到集成版？​

支持。通过 ModifyEnvPlan 接口，将 PackageId 设置为集成版套餐 ID 即可。变配涉及的差价将自动从账户余额中扣除。

Q5：不开启超限按量开关会怎样？​

套餐内资源用量耗尽后环境将直接停服，所有服务（数据库、云函数、云存储等）不可用，线上用户的请求会失败。建议在购买环境时直接在 CreateEnv 请求中传入 EnableOverrun: "TRUE" 一步到位；如果购买时未设置，也可通过 超限按量开关 章节的方式后续开启。开启后，超出套餐的用量将按量计费，业务不受影响。

Q6：集成版套餐的资源点如何计算？​

资源点是云开发的统一计量单位，涵盖数据库读写、云函数调用、云存储流量等。具体额度以 DescribeEnvPlans 返回的 ResourceLimit 中 Credits.MaxSize 字段为准。资源点换算规则详见 资源点价格文档。
