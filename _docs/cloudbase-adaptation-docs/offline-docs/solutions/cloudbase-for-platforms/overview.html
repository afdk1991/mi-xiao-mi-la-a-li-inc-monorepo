CloudBase 平台集成方案概述

集成版套餐已停止售卖

集成版套餐已不再售卖，无法为新账号加白使用。如有需求，请购买平台版套餐：平台版按账号维度计费，一份套餐即可覆盖账号下所有环境。购买与开通流程见购买与初始化。

存量集成版环境不受影响，可继续使用；平台版与集成版的完整差异，见平台版与集成版对比。

CloudBase 平台集成方案是面向 AI Coding、Vibe Coding、Agent 等平台的解决方案，让任意平台可以代替用户来配置和管理后端。您的用户不必理解数据库、云函数等底层概念，即可获得一个可用的应用后端。

用户、您的平台、CloudBase 三方的关系如下：

用户只需向 Agent 描述需求；平台后端负责创建环境、下发凭证；Agent 拿到 API Key 后直连环境，自行创建数据库、部署云函数，无需再经过平台后端。

本文档面向平台方 / 企业集成方，以"环境"为核心管理单元，讲解如何通过腾讯云 API 将云开发接入您的产品。

适用场景​

  • AI Coding / Vibe Coding 平台：如 Lovable、Bolt.new、Vercel v0、腾讯吐司，为每个客户/租户提供可隔离的后端能力，通过 API 而非仅控制台来管理
  • SaaS 与多租户系统：为每个租户提供独立的数据库、云函数、静态托管等资源
  • 企业内部业务平台：为员工分配隔离的 AI 开发环境

核心概念​

CloudBase 平台集成方案围绕三层概念展开：腾讯云账号 → CloudBase 环境 → 环境内资源。

概念说明
腾讯云账号统一账号模式下的管理主体。使用一个腾讯云账号（主账号或具备云开发权限的子用户），即可创建多个环境，所有环境的资源与计费均归属该账号，便于统一管理、统一出账
CloudBase 环境一个租户的一整套后端资源，通常一租户一环境，环境之间资源与数据相互隔离
环境内资源环境包含的数据库、云函数、静态托管等资源，可按需开通与配置

账号、环境与资源的层级关系：

集成版套餐​

集成版套餐曾面向平台型客户提供，专为企业级应用打造。创建环境时使用套餐 ID baas_integration，具有以下特点：

  • 更低的订阅单价：相比基础版套餐，集成版套餐价格更优惠
  • 资源点统一计量：所有云开发资源统一折算为「资源点」进行计量和抵扣，用量更透明
  • 超限按量保障：环境开启超限按量后，套餐额度用尽时自动转为按量计费，业务不中断
  • 灵活的计费管理：支持续费、变配（升 / 降级套餐）等运维操作

除集成版外，云开发还提供多种套餐规格，满足从个人开发者到大型企业的不同需求。各类云开发资源（数据库、云函数、存储等）与资源点的换算关系，详见 资源点价格文档。

接入步骤​

前三个章节是平台接入的主线流程，按顺序完成，即可让用户通过 Agent 直接操作云开发环境：

章节内容解决什么问题
开通并创建第一个环境通过 API 开通云开发服务并创建第一个环境打通"从无到有"的第一步
获取环境 API Key为每个用户环境签发 API Key让每个用户拥有隔离的访问凭证
使用 API Key 对接环境对接客户端 Agent 与云端 Agent让 Agent 直接操作云资源

API Key 下发给用户后，用户的 Agent 即可自行创建数据库、部署云函数、配置域名等。以下章节面向平台侧自行管理环境的场景（如代用户托管全部资源、控制成本），属于可选进阶内容：

建议的实现顺序​

如需平台自行管理资源，建议按以下顺序实现：

  1. 环境创建与计费：完成单租户环境的创建与计费开通，并支持用量查询。
  2. 部署后端：部署 HTTP 云函数，对外提供 API 或 WebSocket 能力。
  3. HTTP 网关与域名：配置路由与自定义域名，实现对外暴露与访问控制。
  4. 数据库与权限：为租户开通数据库、建表，配置权限与安全规则。
  5. 监控与日志：通过监控曲线与 CLS 日志进行排障与用量分析。
