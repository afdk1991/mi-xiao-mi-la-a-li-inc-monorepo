CloudBase 平台版概述

CloudBase 平台版是面向平台型客户的账号维度套餐方案，让任意平台可以在一个腾讯云账号（UIN） 下创建和管理海量（10w+）隔离环境，每个环境服务于一个租户/用户，环境之间资源与数据相互隔离。

平台版以账号为基本计费和管理单位：购买一份平台版套餐，即可覆盖账号下所有环境，环境创建、资源使用统一从账号套餐中计量扣减，收入与套餐订阅挂钩，不再依赖客户创建的环境数量。

用户、您的平台、CloudBase 三方的关系如下：

您的平台在 CloudBase 购买平台版套餐后，为每位用户重复以下流程：用户向平台请求获取环境，平台调用云开发创建环境、创建 API Key，并将环境 ID 和 API Key 返回给用户；用户携带 API Key 直连 CloudBase 操作自己的环境，无需再经过平台后端。

本文档面向平台方 / 企业集成方，讲解如何通过腾讯云 API 将平台版接入您的产品。

适用场景​

  • AI Coding / Vibe Coding 平台：为每个客户/租户提供可隔离的后端能力，通过 API 而非仅控制台来管理
  • SaaS 与多租户系统：为每个租户提供独立的数据库、云函数、静态托管等资源
  • 企业内部业务平台：为员工分配隔离的 AI 开发环境
  • 大规模环境管理：单账号下需要创建数千乃至 10w+ 环境，要求环境创建快速、成本可控

核心概念​

CloudBase 平台版围绕三层概念展开：腾讯云账号 → 平台版套餐 → CloudBase 环境 → 环境内资源。

概念说明
腾讯云账号平台版的管理与计费主体。使用一个腾讯云账号（主账号或具备云开发权限的子用户），购买一份平台版套餐后即可创建多个环境
平台版套餐账号维度的套餐方案。购买后账号下所有环境的资源使用统一从套餐资源点中计量扣减，环境到期时间与账号套餐到期时间保持一致
CloudBase 环境一个租户的一整套后端资源，通常一租户一环境，环境之间资源与数据相互隔离
环境内资源环境包含的数据库、云函数、静态托管等资源，可按需开通与配置

账号、套餐、环境与资源的层级关系：

平台版套餐​

平台版套餐是面向平台型客户的专属账号级套餐，专为海量环境、统一计费的场景打造，具有以下特点：

  • 账号维度计费：一份套餐覆盖账号下所有环境，收入与套餐订阅挂钩，成本可预测
  • 资源点统一计量：所有云开发资源统一折算为「资源点」进行计量和抵扣，用量更透明
  • 超限按量保障：套餐额度用尽时，可开通按量付费兜底，业务不中断
  • 完整的生命周期管理：支持续费、变配、超限停服、到期隔离（14 天数据保留）、销毁等账号级运维操作，关键事件多渠道通知
购买方式

平台版目前白名单开放中，如您需要使用，请联系我们或提交腾讯云工单申请购买资格，详见购买与初始化。

云开发提供多种套餐规格，满足从个人开发者到大型企业的不同需求。各类云开发资源（数据库、云函数、存储等）与资源点的换算关系，详见 资源点价格文档。

数据隔离与安全​

平台版为海量环境场景设计，所有环境均运行在统一的、安全的云开发基础设施之上，具有以下特点：

  • 环境间相互隔离：每个环境拥有独立的数据库、云函数、静态托管等资源，环境之间数据与资源互不可见、互不影响
  • 凭证最小权限：环境 API Key 仅授予该环境自身数据范围的访问权限，即使泄露也无法访问其他环境的数据
  • 统一的账号级管控：环境创建、暂停、启动、删除等操作统一纳入账号级管理，便于平台统一治理

接入步骤​

前三个章节是平台接入的主线流程，按顺序完成，即可让用户通过 Agent 直接操作云开发环境：

章节内容解决什么问题
购买与初始化购买平台版套餐打通"从无到有"的第一步
创建环境按需创建或预创建环境为您的用户准备独立环境
API Key 管理为每个用户环境签发 API Key让每个用户拥有隔离的访问凭证
使用 API Key 对接环境对接客户端 Agent 与云端 Agent让 Agent 直接操作云资源

建议的实现顺序​

如需平台自行管理资源，建议按以下顺序实现：

  1. 套餐购买与环境创建：完成平台版套餐购买与环境创建，并支持环境维度用量查询。
  2. 部署后端：部署 HTTP 云函数，对外提供 API 或 WebSocket 能力。
  3. HTTP 网关与域名：配置路由与自定义域名，实现对外暴露与访问控制。
  4. 数据库与权限：为租户开通数据库、建表，配置权限与安全规则。
  5. 监控与日志：通过环境维度用量查询与 CLS 日志进行排障与成本分析。
