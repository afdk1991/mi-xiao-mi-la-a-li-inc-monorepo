购买与初始化

本文面向平台接入方，介绍如何购买平台版套餐。购买完成后，即可调用云开发接口按需或预创建环境，为您的用户提供独立环境，详见 创建环境。

平台版以账号（UIN）为计费和管理单位：购买一份平台版套餐后，账号下的环境创建、资源使用统一从套餐资源点中计量扣减，无需为每个环境单独购买套餐。

购买流程​

平台版目前白名单开放，请按以下步骤完成购买：

  1. 联系云开发团队开通平台版购买资格：通过联系我们或提交腾讯云工单申请
  2. 前往云开发购买页选择平台版套餐，完成下单支付
  3. 前往控制台完成开通与授权：套餐发货成功后，前往云开发控制台。首次使用云开发时，控制台会引导您开通云开发服务、为云开发服务角色完成授权，请按控制台引导完成操作；完成开通与授权后，即可调用接口创建环境

套餐状态​

平台版套餐在生命周期内会经历以下状态：

状态说明
发货中购买成功后，底层资源自动准备中，准备完成后自动转为「正常」
正常套餐可用，可正常创建与使用环境
已隔离套餐已到期且未续费，服务停用
超限停服套餐未到期，但资源点已耗尽，服务停用
已销毁隔离满 14 天后，环境与数据全部删除

状态流转如下：

  • 发货中 → 正常：购买成功后，底层资源自动准备，完成后套餐转为正常
  • 正常 → 超限停服：套餐未到期，但资源点耗尽，服务停用
  • 正常 → 已隔离：套餐到期且未续费，服务停用
  • 超限停服 → 正常：开启按量付费后，套餐恢复可用
  • 超限停服 → 已隔离：套餐到期且未续费，转为隔离
  • 已隔离 → 正常：续费后套餐恢复可用
  • 已隔离 → 已销毁：隔离满 14 天后自动销毁，数据无法恢复

数据与可用性：平台版为账号维度套餐，套餐状态影响账号下所有环境。已隔离或超限停服时，所有环境的数据仍在，但服务不可使用；已销毁后，所有环境的数据全部删除。

前置条件​

购买平台版后，正式接入前请确认已满足以下条件：

  • 已购买平台版套餐
  • 已具备云开发管理权限的 CAM 密钥（SecretId / SecretKey）
  • 已了解账号下的环境个数上限（底层云资源已由平台版统一管理，无需自行关注）

下一步​

购买完成后，请按顺序完成以下步骤：

  1. → 创建环境：按需创建或预创建，为您的用户准备独立环境
  2. → API Key 管理：为每个用户环境签发 API Key
