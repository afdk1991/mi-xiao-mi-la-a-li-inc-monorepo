小程序 Skill

小程序 AI 开发模式是微信提供的一种开发范式，让开发者将小程序功能封装为 SKILL（包含业务说明、原子接口和原子组件），供用户在对话中通过自然语言直接调用。用户可以用"帮我点一杯拿铁"、"挂明天下午的号"这样的聊天方式完成操作，无需逐页点击。

以下精选了来自 awesome-miniprogram-skills 仓库的开箱即用 Skill，覆盖点餐、出行、医疗、购物等场景。每个 Skill 都是一个完整的独立分包，含原子接口和原子组件，可通过 mp-skills CLI 一键安装到你的小程序项目中。

生活缴费生活服务
查询当前用户的所有待缴账单，支持水费、电费、燃气费、话费、物业费等类型在线缴费，汇总总金额和逾期数量。用户提到缴费、查账单、欠费等场景时自动触发。
3 个原子接口·查看源码
npx mp-skills add TencentCloudBase/awesome-miniprogram-skills -s bill-skill
医院挂号医疗
搜索医院列表并查看指定科室的可挂号时段，完成在线预约挂号。支持按医院名、科室名或区域关键词搜索。用户需要选择医院、搜索科室或查看可用时段时自动触发。
4 个原子接口·查看源码
npx mp-skills add TencentCloudBase/awesome-miniprogram-skills -s hospital-skill
图片编辑AI 能力
基于用户提供的原图和编辑需求描述，通过 AI 重新生成实现图片编辑效果。支持风格转换、内容修改、背景替换等编辑操作。调用后返回原图和编辑后的图片对比。
1 个原子接口·查看源码
npx mp-skills add TencentCloudBase/awesome-miniprogram-skills -s image-edit-skill
图片生成AI 能力
根据文字描述通过 AI 生成图片。AI 可自动润色 prompt 以提升生成质量，支持多种视觉风格。用户表达图片生成需求或指定了图片内容时自动触发。
1 个原子接口·查看源码
npx mp-skills add TencentCloudBase/awesome-miniprogram-skills -s image-gen-skill
外卖点餐点餐
搜索附近餐厅列表，查看指定餐厅的菜单与菜品列表，完成在线下单。支持按餐厅名、品类或区域关键词搜索。用户需要点餐、搜索餐厅、比较不同餐厅时自动触发。
4 个原子接口·查看源码
npx mp-skills add TencentCloudBase/awesome-miniprogram-skills -s order-skill
聚会安排生活服务
创建聚会活动，收集聚会名称、日期、时间等基本信息。获取聚会场地推荐（餐厅、娱乐场所等），发送邀请并查看活动详情。信息不完整时可引导用户补充。
4 个原子接口·查看源码
npx mp-skills add TencentCloudBase/awesome-miniprogram-skills -s party-skill
微信支付支付
创建支付订单并调起微信支付，返回小程序调起支付的参数（prepay_id、签名等）。支持查询订单支付状态。需在业务 Skill 完成下单流程、生成业务订单号后调用。
2 个原子接口·查看源码
npx mp-skills add TencentCloudBase/awesome-miniprogram-skills -s payment-skill
排队取号生活服务
查询可排队门店列表，查看单个门店当前排队状态和预计等待时间。支持在线取号，实时更新排队进度。用户需要选择门店、查看排队快慢时自动触发。
4 个原子接口·查看源码
npx mp-skills add TencentCloudBase/awesome-miniprogram-skills -s queue-skill
潮玩购物购物
搜索或推荐潮玩商品（盲盒、手办、模型等），查看商品详情和库存信息。无关键词时返回精选推荐商品；有关键词时按名称、分类、标签搜索。
4 个原子接口·查看源码
npx mp-skills add TencentCloudBase/awesome-miniprogram-skills -s shopping-skill
出行打车出行
预估行程价格与时长，支持快车、专车、拼车等多种车型对比。用户确认后可呼叫出租车，实时更新叫车状态和预计等待时间。可查看行程详情和历史记录。
4 个原子接口·查看源码
npx mp-skills add TencentCloudBase/awesome-miniprogram-skills -s taxi-skill
文本生成AI 能力
AI 文本生成服务，支持写作、翻译、代码生成、内容总结、问答等多种场景。根据用户输入的 prompt 智能生成文本内容。用户表达文本内容需求时自动触发。
1 个原子接口·查看源码

待办管理效率工具
查询当前用户的待办列表，支持新增待办事项、标记完成和按状态筛选。使用微信云数据库直接存取，不经过云函数。用户查看待办、新增或修改操作后自动刷新列表。
4 个原子接口·查看源码
npx mp-skills add TencentCloudBase/awesome-miniprogram-skills -s todolist-skill
旅行规划出行
搜索热门旅行目的地，查看指定目的地的行程规划方案（含交通方案、住宿推荐、景点安排）。提供当地天气资讯和旅行攻略。用户规划旅行或查看目的地信息时自动触发。
4 个原子接口·查看源码
npx mp-skills add TencentCloudBase/awesome-miniprogram-skills -s travel-skill
喝水记录效率工具
记录用户每次喝水量，返回当天累计饮水量、目标进度和本次记录结果。支持查看最近若干天的饮水记录汇总和今日明细。帮助用户养成健康饮水习惯。
