Model Usage Ranking

To help you understand how the built-in models on the CloudBase AI platform are actually used, we update the share of token usage of each model periodically.

This issue covers September 21 – September 27, 2026 (Beijing Time), a full calendar week, and the metric is the total token volume of all text models on the platform (input + output tokens, including cache hits).
