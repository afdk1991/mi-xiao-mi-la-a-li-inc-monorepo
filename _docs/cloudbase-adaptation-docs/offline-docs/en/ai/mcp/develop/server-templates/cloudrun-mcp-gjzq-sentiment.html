Guojin Securities A-share Sentiment Pulse Index MCP Service

In the AIGC era, quantifying market sentiment has become a crucial reference for investment decisions. The Guojin Securities A-share Sentiment Pulse Index MCP Server, leveraging big data and AI technology and targeting developers and investors, provides a real-time sentiment index for the Shanghai and Shenzhen A-share markets, updated every 5 minutes, to support diverse scenarios such as intelligent investment research, market monitoring, and strategy assistance.

Suitable for various AI scenarios such as market monitoring, intelligent investment advisory, strategy backtesting, and sentiment analysis.

Go to CloudBase Platform to create MCP Server

Environment Variables​

  • API_KEY: Service access key, default value is gjzqtest. If you require commercial cooperation, please contact the official to obtain a dedicated key.

Index Description​

  • Sentiment Index > 75: The market is highly euphoric, investor sentiment is positive, with a risk of short-term correction.
  • Sentiment Index < 25: Market sentiment is sluggish, investor confidence is insufficient, with potential for short-term rebound.
  • The higher the value: the more optimistic the market and the higher the enthusiasm.
  • The lower the value: the more pessimistic and cautious the market.

⚠️ This index is for reference only and does not constitute investment advice.

Application Example​

  • Robo-advisor: Combines with the Sentiment Pulse Index to assist in determining market turning points and optimize asset allocation.
  • Market Monitoring: Real-time monitoring of market sentiment fluctuations, alerting to extreme sentiment risks.
  • Strategy Backtesting: Uses the Sentiment Index as a factor to enrich quantitative strategy dimensions.
