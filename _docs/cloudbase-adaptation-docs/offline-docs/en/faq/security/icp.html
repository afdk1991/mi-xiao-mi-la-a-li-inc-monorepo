ICP Filing

This document describes how to use Tencent CloudBase resources for ICP filing, and provides guidance on completing ICP filing for custom domains bound to CloudBase.

Can CloudBase Resources Be Used for ICP Filing?​

Yes. CloudBase environments can be used directly as cloud resources for ICP filing without the need to purchase additional cloud servers or other services.

Prerequisites​

To use a CloudBase environment for ICP filing, the following three conditions must be met simultaneously:

  1. Plan Version: Must be a Personal Plan or above (the free trial environment is not supported).
  2. Remaining Validity: The remaining validity of the CloudBase environment must be 6 months or more.
  3. Fixed IP: The environment must have CloudRun Fixed IP enabled.

Filing Process​

  1. Go to the CloudBase Console, and access the Filing Management page of the corresponding environment (if this entry is not visible, ensure that the prerequisites above are met).
  2. Click Go to File. The system will guide you to the Tencent Cloud ICP Filing Console.
  3. Retrieve the eligible CloudBase environment in the ICP Filing Console, and submit the ICP filing application as prompted.

How to Complete ICP Filing for a Custom Domain Bound to CloudBase?​

If you need to bind a custom domain to CloudBase and the domain has not been filed yet, follow the steps below to complete the filing and binding:

Step 1: Prepare Tencent Cloud Resources Supporting ICP Filing​

In addition to CloudBase environments, you can also purchase other Tencent Cloud products to obtain filing authorization:

  • CloudBase environment (meeting the conditions: Personal Plan or above, validity > 6 months, Fixed IP enabled)
  • Lighthouse (Lightweight Application Server) (monthly subscription of 3 months or more)
  • CVM (Cloud Virtual Machine) (monthly subscription with public bandwidth, 3 months or more)

Step 2: Complete the ICP Filing Process​

  1. Log in to the Tencent Cloud ICP Filing Console.
  2. Select your filing resource (e.g., CloudBase environment), and fill in the entity information and website/app information.
  3. Upload the required qualification materials and complete real-name verification (such as facial recognition).
  4. Submit for preliminary review. Once Tencent Cloud approves it, the system will submit it to the respective provincial Communications Administration for review.
  5. Wait for Communications Administration review. Once approved, you will receive an ICP filing number. This usually takes 1 to 20 working days, depending on the province.

Step 3: Bind the Filed Domain in CloudBase​

  1. Once the filing is approved, return to the CloudBase Console.
  2. In the left navigation pane, select HTTP Gateway.
  3. Add your custom domain and configure the CNAME resolution to the address provided by CloudBase.
Tip

In addition to managing domains centrally in the HTTP Gateway, you can also add a filed custom domain directly from the detail page of a specific cloud function / cloud run / static hosting application. The two entry points are equivalent — all added domains are listed and managed in the HTTP Gateway.

FAQ​

1. Does the CloudBase environment need to maintain more than 6 months of validity after successful ICP filing?​

No, the environment does not need to maintain more than 6 months of validity after successful filing. However, if you need to modify filing information (such as updating entity details or adding new domains) in the future, the environment must meet the "remaining validity > 6 months" requirement again at that time.

2. Can the filing server (CVM/Lighthouse) be shut down or released after successful ICP filing?​

After successful filing, the cloud server (CVM) or Lighthouse used for filing does not need to be running continuously (it can be shut down or released), but it is recommended to keep the minimum configuration for future filing modifications. Note that if the server resource used for filing is completely released or deleted, the Communications Administration may deregister your filing during regular inspections due to the "lack of associated Tencent Cloud resources".

3. How many websites can be filed per CloudBase environment?​

According to Tencent Cloud's filing rules, an eligible cloud resource (such as a CloudBase environment on a Personal Plan or above with Fixed IP enabled) can apply for up to 5 website filing service codes (each website can contain multiple domains).

4. If my domain already has an ICP filing number from another service provider, can I bind it directly to CloudBase?​

No. If your domain has completed ICP filing with another service provider (such as Alibaba Cloud, Huawei Cloud, etc.), binding it directly to Tencent CloudBase will be blocked or prompted as unfiled. You must first apply for a Filing Transfer (Add Association to Tencent Cloud) in Tencent Cloud. Once the filing information is transferred to Tencent Cloud, you can bind and access it normally.
