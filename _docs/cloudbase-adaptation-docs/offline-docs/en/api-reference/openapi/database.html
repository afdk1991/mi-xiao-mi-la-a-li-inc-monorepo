getDocument​

1. API Description​

Feature: query a single document

2. Request URL​

GET https://tcb-api.tencentcloudapi.com/api/v2/envs/{envId}/databases/{collectionName}/documents/{docId}?limit={limit}&skip={skip}&fields={fields}&sort={sort}&transactionId={transactionId}
URL query parameters​
FieldTypeRequiredDescription
limitStringNoLimit the number of documents returned
skipStringNoNumber of documents to skip
fieldsStringNoe.g. {key1: 1, key2: 0} — keep key1, drop key2
sortStringNoe.g. {key1: 1, key2: -1} — sort ascending by key1, then descending by key2
transactionIdStringNoIf present, indicates a document operation inside a transaction

3. Request body​

None

4. Response body​

FieldTypeRequiredDescription
statusCodeNumberYesStatus code, 200
bodyObjectYesResponse body, structure shown below
body​
FieldTypeRequiredDescription
requestIdStringNoRequest ID
dataObjectNoResult
codeStringNoError code
messageStringNoError message
data​
FieldTypeRequiredDescription
offsetnumberYesOffset
limitnumberYesLimit
listArray<String>YesDocument array; each element is an EJSON-serialized string

URL query parameters​
FieldTypeRequiredDescription
transactionIdStringNoIf present, indicates a document operation inside a transaction

3. Request body​

FieldTypeRequiredDescription
dataStringYesEJSON-serialized replacement document string

4. Response body​

FieldTypeRequiredDescription
statusCodeNumberYesStatus code, 200
bodyObjectYesResponse body, structure shown below
body​
FieldTypeRequiredDescription
requestIdStringNoRequest ID
dataObjectNoResult
codeStringNoError code
messageStringNoError message
data​
FieldTypeRequiredDescription
updatedNumberYesNumber of documents updated successfully
matchedNumberYesNumber of documents matched
upsert_idStringYesPresent when a new doc is inserted via upsert; otherwise null

5. Example​

// Node example
const request = require("request"); // request library, install via npm
const envId = "testEnv"; // environment ID
const collectionName = "testCollection"; // collection name
const docId = "testDocId"; // document ID
const unExistDocId = "testUnExistDocId"; // non-existent document ID
const { EJSON } = require("bson"); // bson library, install via npm

request(
  {
    url: `https://tcb-api.tencentcloudapi.com/api/v2/envs/${envId}/databases/${collectionName}/documents/${docId}`, // replace update
    // url: `https://tcb-api.tencentcloudapi.com/api/v2/envs/${envId}/databases/${collectionName}/documents/${unExistDocId}`, // insert the current document
    method: "PUT",
    headers: {
      "X-CloudBase-Authorization": "your authorization",
      "X-CloudBase-SessionToken": "your token",
      "X-CloudBase-TimeStamp": "the timestamp",
    },
    body: {
      data: EJSON.stringify(
        {
          name: "new Name", // update the name field
        },
        { relaxed: false },
      ),
    },
    json: true,
  },
  (err, response, body) => {
    console.log(err);
    console.log(response.statusCode);
    console.log(response.body.data.updated); // present on replacement update
    console.log(response.body.data.upsert_id); // present when the document is inserted because it didn't exist
  },
);

Query Command​

$eq​

Matches values that equal the given value.

Syntax: { <field>: { $eq: <value> } }

// Node example
const request = require("request"); // request library, install via npm
const envId = "testEnv"; // environment ID
const collectionName = "testCollection"; // collection name
const { EJSON } = require("bson"); // bson library, install via npm

request(
  {
    url: `https://tcb-api.tencentcloudapi.com/api/v2/envs/${envId}/databases/${collectionName}/documents:find`,
    method: "POST",
    headers: {
      "X-CloudBase-Authorization": "your authorization",
      "X-CloudBase-SessionToken": "your token",
      "X-CloudBase-TimeStamp": "the timestamp",
    },
    body: {
      query: EJSON.stringify(
        {
          name: {
            $eq: "luke", // find documents where the name field equals "luke"
          },
        },
        { relaxed: false },
      ),
    },
    json: true,
  },
  (err, response, body) => {
    console.log(err);
    console.log(response.statusCode);

    const data = response.body.data.list.map((item) => EJSON.parse(item)); // EJSON deserialization
    console.log(data);
  },
);
