WeDa Environment Dependencies

Network​

The entire WeDa system is built and operates on the internet, relying on internet connectivity to access relevant network resources. The design-time state (including development and operations capabilities such as console and editor) and runtime state (accessible running WeDa applications) interact with the following backend resources. When in a limited network environment (e.g., an intranet unable to access the public internet), network policies must be configured to unblock the corresponding domain names.

Runtime Resource Hosting Domain​

  • Static Hosting Domain: ${env-id}-${Tencent Cloud Account APPID}.tcloudbaseapp.com
  • Cloud Storage Domain: ${bucket-name}-${Tencent Cloud account APPID}.tcb.qcloud.la
  1. Tencent Cloud account APPID can be viewed in the account information of the Tencent Cloud console.
  2. Cloud storage bucket name can be obtained on the Cloud Storage page of the CloudBase platform.
