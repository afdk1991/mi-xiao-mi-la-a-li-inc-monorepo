INVALID_THIRDAPP_STATUS

遇到错误？使用 AI 工具协助排查

错误原因​

绑定第三方小程序状态异常，第三方应用的状态不正常。

解决方案​

  1. 检查第三方小程序的状态
  2. 确认小程序是否正常发布
  3. 验证小程序的授权状态
  4. 重新进行第三方应用绑定
  5. 联系第三方应用开发者确认状态
