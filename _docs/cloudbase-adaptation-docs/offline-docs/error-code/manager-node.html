SDK（manager-node）错误码

@cloudbase/manager-node 在部署、构建、数据库迁移等流程中抛出的错误码。其 source 为 manager-node。

共 48 个错误码。每个错误码下的条目即失败时展示给你的文案（占位符 … 表示随场景变化的具体值）。

  • 构建参数 … 可能包含敏感信息；cloud 构建禁止通过 buildArgs 传递密钥
  • 构建参数 … 的值必须是无 NUL 字符的字符串
  • 构建参数名不合法：…

  • Dockerfile 路径不合法，需为构建上下文内的安全相对路径

IMAGE_TYPE_INVALID​

  • 您还没有开启静态网站服务，请先到云开发控制台开启静态网站服务！
  • 静态网站文件不为空，无法销毁！
