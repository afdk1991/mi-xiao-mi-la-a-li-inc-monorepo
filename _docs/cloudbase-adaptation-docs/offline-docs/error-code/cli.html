CLI 本地错误码

tcb 命令在本地校验、构建、部署流程中抛出的错误码。其 source 为 cli，与云 API 返回的平台码分属不同来源层 —— 同一个码名（如 INVALID_PARAM）在不同来源层含义不同，请以 (code, source) 二元组定位。

共 69 个错误码。每个错误码下的条目即失败时展示给你的文案（占位符 … 表示随场景变化的具体值）。

API_BLOCKED​

  • 该操作被禁止：{{reason}}

API_ERROR​

  • Agent 创建失败：{{msg}}
  • Agent 更新失败：{{msg}}
  • Git 模板下载失败: {{error}}

AUTH_FAILED​

  • 当前登录方式为永久密钥（tcb login --key），tcb secrets get 仅支持临时密钥输出。
  • 无有效身份信息，请使用 cloudbase login 登录
  • 未找到有效的凭证，请先执行 tcb login 完成登录

BIND_FAILED​

  • 绑定失败：{{error}}

BUILD_FAILED​

  • [{{name}}] 构建失败：在 {{root}} 执行「{{cmd}}」失败 {{detail}}

BUILD_OUTPUT_NOT_FOUND​

  • [{{name}}] 未找到有效构建产物：{{dir}}（目录不存在或为空） hosting 声明式部署不再自动执行本地构建，请先执行 {{cmd}} 完成构建后再执行 tcb deploy

BUILD_TIMEOUT​

  • 构建超时

CACHE_PURGE_NOT_SUPPORTED​

  • 域名 [{{domain}}] 的接入方式为 {{accessType}}，未接入 CDN 或 EdgeOne，不支持缓存刷新

CERT_NOT_FOUND​

  • 未找到域名 [{{domain}}] 相关的可用 SSL 证书

CLOUD_API_ERROR​

  • 云托管部署失败
  • 云托管部署已被取消
  • 套餐变更失败：{{message}}。建议检查账户状态或运行 {{cmd}} 重新登录后重试

CONFIG_CONFLICT​

  • 代码部署模式下不应该配置 imageConfig
  • 镜像部署模式下必须配置 imageConfig

CONFIG_NOT_FOUND​

  • AI 配置未找到，请运行 tcb ai --setup 进行配置
  • 未找到 integrations 配置，请在 cloudbaserc.json 中配置 integrations 字段

DELETE_FAILED​

  • 集成实例删除失败

DELETE_FILE_FAILED​

  • 该错误码由本地流程判定失败时抛出，具体原因见报错文案。

DEPENDENCY_NOT_INSTALLED​

  • [{{name}}] 未检测到 node_modules。构建前请先在 {{root}} 目录自行安装依赖（如 npm install），构建过程不会代为安装依赖

DEPLOY_FAILED​

  • 部署失败: {{message}}

DEPLOY_INPUT_MISSING​

  • 部署参数不完整，请补充：{{fields}}

DEPLOY_PARTIAL_FAILED​

  • 部分文件上传失败
  • 部分文件上传失败，进程退出

DOMAIN_NOT_FOUND​

  • 未在环境中找到域名 [{{domain}}]，无法自动识别缓存类型

DOWNLOAD_FILE_FAILED​

  • 该错误码由本地流程判定失败时抛出，具体原因见报错文案。

DRY_RUN_FAILED​

  • 该错误码由本地流程判定失败时抛出，具体原因见报错文案。

EMPTY_BODY​

  • 服务端未返回文件内容（status={{status}}）

ENV_NOT_PG​

FETCH_TEMPLATE_FAILED​

FILE_EXISTS​

GET_ENV_DETAIL_FAILED​

GET_TEMPLATE_FAILED​

  • 获取集成加解密密钥失败：七彩石配置拉取请求异常，请检查网络连接或代理设置

  • 触发器配置不能为空

METADATA_FILE_INVALID​

METADATA_READ_FAILED​

NETWORK_ERROR​

NOT_FOUND​

  • 云函数 [{{name}}] 的版本 [{{version}}] 不存在！ 可用版本：{{available}}
  • 集成 [{{keyId}}] 不存在

OPERATION_CANCELLED​
