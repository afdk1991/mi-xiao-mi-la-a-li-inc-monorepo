## 三、验证失败 / 环境受限项目（3 个）

### 6. MIXMLAAL ❌ 依赖版本错误

**项目定位**：多栈全栈后台管理系统（13 个子应用）

**失败原因**：`mixmlaal-apps/mixmlaal-api-node` 依赖中指定 `vant@^4.10.3`，但 npm registry 中不存在该版本号。

**错误信息**：
```
npm error code ETARGET
npm error notarget No matching version found for vant@^4.10.3.
```

**修复建议**：
1. 检查 `mixmlaal-api-node/package.json` 中 vant 的版本号
2. 降级为存在的版本（如 `vant@^4.9.0` 或 `vant@^4.8.0`）
3. 或切换到淘宝镜像源后重试

---

### 7. zhinenglux ❌ 原生模块编译失败

**项目定位**：智能路小程序（Taro 4 + NestJS）

**失败原因**：`better-sqlite3` 原生模块需要 `node-gyp` 编译构建工具，但系统未安装。

**错误信息**：
```
.../node_modules/better-sqlite3 install: 'node-gyp' is not recognized as an internal or external command
.../node_modules/better-sqlite3 install: Failed
```

**修复建议**：
1. 安装 Windows 构建工具：`npm install -g windows-build-tools` 或安装 Visual Studio Build Tools
2. 或使用预编译二进制版本（如果可用）
3. 或移除 better-sqlite3 依赖（如果只是开发模式可选）

---

### 8. manju/Flutter 客户端 ❌ Windows 环境限制

**项目定位**：漫剧视频跨平台客户端（Flutter）

**失败原因**：Windows 系统未开启"开发者模式"，导致 Flutter symlink 支持不可用，分析服务器崩溃。

**错误信息**：
```
Building with plugins requires symlink support.
Please enable Developer Mode in your system settings.
Run: start ms-settings:developers
```

**修复建议**：
1. 打开 Windows 设置 → 更新和安全 → 开发者选项 → 开启开发者模式
2. 或运行命令：`start ms-settings:developers`
