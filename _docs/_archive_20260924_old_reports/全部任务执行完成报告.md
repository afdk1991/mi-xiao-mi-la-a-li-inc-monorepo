## ⚠️ 需要你手动完成

### API 密钥轮换（必须在控制台操作）

由于之前密钥曾以明文文件形式存放，建议轮换：

#### Cloudflare R2 密钥轮换：



1. 打开 [https://dash.cloudflare.com/profile/api-tokens](https://dash.cloudflare.com/profile/api-tokens)

2. 删除旧令牌（以 `cfat_eUkG8bu3...` 开头）

3. 创建新令牌，选择 "Edit R2 Storage" 模板

4. 进入 R2 → 管理 API 令牌 → 删除旧 Access Key / Secret

5. 创建新 Access Key

6. 更新 Windows 用户环境变量：

* `CLOUDFLARE_API_TOKEN`

* `CLOUDFLARE_R2_ACCESS_KEY_ID`

* `CLOUDFLARE_R2_SECRET_ACCESS_KEY`

#### 阿里云百炼密钥轮换：



1. 打开 [https://bailian.console.aliyun.com/?apiKey=1#/api-key](https://bailian.console.aliyun.com/?apiKey=1#/api-key)

2. 删除旧密钥（以 `sk-7d3c98af...` 开头）

3. 创建新 API Key

4. 更新环境变量 `ALIYUN_LLM_API_KEY`
