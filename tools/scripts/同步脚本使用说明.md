# 自动同步脚本使用说明

## 快速开始

### 手动同步单个项目
```powershell
cd D:\网站全栈项目\scripts
.\sync-to-github.ps1 -Project 项目003
```

### 同步全部项目
```powershell
.\sync-to-github.ps1
```

### 同步并部署到 EdgeOne
```powershell
.\sync-to-github.ps1 -Project 项目003 -Deploy
```

### 仅查看将要执行的操作（不实际执行）
```powershell
.\sync-to-github.ps1 -DryRun
```

---

## 参数说明

| 参数 | 说明 |
|------|------|
| `-Project` | 指定项目名称（D盘目录名），不填则同步全部 |
| `-SkipTest` | 跳过测试步骤 |
| `-SkipPush` | 跳过 git push（仅同步文件到 E盘） |
| `-Deploy` | 同步后触发 EdgeOne Makers 部署 |
| `-DryRun` | 试运行，仅显示操作不执行 |

## 同步流程

```
D盘开发工作区
    ↓
运行测试（可选）
    ↓
robocopy 同步源代码 → E盘 GitHub 镜像
（自动排除 node_modules、dist、.env 等）
    ↓
git add / commit / push → GitHub
    ↓
触发 EdgeOne 部署（可选，仅项目003）
```

---

## 定时任务（可选）

### 每天自动同步
```powershell
# 创建每天晚上 10 点自动同步的任务
$action = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-ExecutionPolicy Bypass -File D:\网站全栈项目\scripts\sync-to-github.ps1"
$trigger = New-ScheduledTaskTrigger -Daily -At 22:00
Register-ScheduledTask -TaskName "GitHub自动同步" -Action $action -Trigger $trigger -Description "每天自动同步D盘代码到GitHub"
```

### 每小时自动同步
```powershell
$action = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-ExecutionPolicy Bypass -File D:\网站全栈项目\scripts\sync-to-github.ps1"
$trigger = New-ScheduledTaskTrigger -Once -At (Get-Date) -RepetitionInterval (New-TimeSpan -Hours 1)
Register-ScheduledTask -TaskName "GitHub每小时同步" -Action $action -Trigger $trigger
```

## 排除规则

同步时自动排除以下内容（不复制到 E盘）：

**目录**：
- node_modules、dist、build、out、release
- .git、.cache、.next、.nuxt
- .trae、.workbuddy、.gocache、.gopath
- __pycache__、vendor、venv

**文件**：
- *.log、.env、.env.local、*.bak、*.zip

---

## 注意事项

1. **首次使用**：建议先运行 `-DryRun` 确认操作正确
2. **EdgeOne 部署**：仅项目003（邮箱聚合）支持自动部署
3. **大文件**：模型文件、数据库文件不会同步，需要单独备份
4. **冲突处理**：E盘是镜像，以 D盘为准，E盘变更会被覆盖
