# 统一样式变量清单（Design Tokens v4 · 中文内容社区版）

> 适用：全站所有页面与可复用组件。所有颜色 / 字号 / 间距 / 圆角 / 阴影一律引用本表变量，禁止裸写魔法数字。
> 来源：`assets/style.css` → `01 设计令牌`。暗色主题仅重写令牌值，组件样式零改动即可整体换肤。

## 8. 响应式断点

| 断点 | 目标设备 | 主要变化 |
|---|---|---|
| `≤1280px` | 小桌面 | 版心收敛 1160px、详情侧栏 280px |
| `≤1080px` | 平板横屏 | 详情两栏堆叠为单列、侧栏卡并排、页脚 2 列 |
| `≤900px` | 平板竖屏 | 导航字号与搜索框收窄、栅格间距收紧 |
| `≤768px` | **移动端** | 导航折叠为抽屉（≥44px 点击区）、栅格单列、工具条输入占满、表格滑动提示、`--tap` 提升到 40px |
| `≤560px` | 小屏手机 | 页脚单列、按钮全宽、搜索条上下堆叠、注意事项卡纵向排列 |
| `≤400px` | 超小屏 | gutter 12px、卡片 padding 12px、搜索框 100px |

补充能力：
- `prefers-reduced-motion: reduce` —— 关闭过渡与滚动渐显
- `prefers-color-scheme: dark` + `[data-theme]` —— 双主题
- `@media print` —— 隐藏导航/页脚/交互件，卡片避免跨页断裂

## 9. 使用约定

1. **禁止裸写**：颜色、间距、字号、圆角必须引用变量，便于整体换肤与统一调整。
2. **间距只用 `--sp-*` 阶梯**，不使用 7px / 15px 之类的中间值。
3. **最小可读字号 12px**；移动端可点击区域高度 ≥ 40px，导航项 ≥ 44px。
4. **静止态不用投影**，仅悬浮 / 弹窗使用（社区风格的克制原则）。
5. **交互态**（hover / focus / active / disabled / loading）统一写在样式表 `08 交互状态` 区，不散落在组件内。
6. **新增组件**时先在令牌层取值；若需新语义色，先在 `01 设计令牌` 定义变量再使用。
7. **暗色适配只需重写令牌**，不要为暗色单独写组件规则。
