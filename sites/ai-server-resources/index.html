转载前三步自查

STEP 01

确认许可类型

打开原文或仓库，找到 LICENSE / 版权声明，判断属于 MIT / Apache / CC / GFDL / 自定义 / 默认版权中的哪一类。

宽松 → 保留许可声明即可商用 ｜ 默认版权 → 必须取得书面授权
STEP 02

分清代码与文档

同一项目里代码、文档、模型权重、数据集常是四套不同许可，必须分别核对，不能互相推定。

示例 MDN 文档为 CC BY-SA，代码示例却是 CC0
STEP 03

按模板署名

依据许可选择对应署名模板，保留作者、原文链接、许可名称与改动说明，并排除商标与 Logo 的使用。
