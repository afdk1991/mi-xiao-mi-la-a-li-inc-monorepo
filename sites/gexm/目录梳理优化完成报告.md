**建议执行以下命令释放空间**:

```powershell
Remove-Item 'f:\gexm\_archive\legacy\runtimes' -Force -Recurse
```

### 4.2 .gitignore 已完整覆盖归档目录

`_archive/` 已加入 .gitignore,所有归档文件不参与版本控制,可随时删除而不影响 git 历史。

清理过程中发现 `enable-debug.php` 曾修改 `wp-config.php` 启用 `WP_DEBUG`。生产环境请确认 `wp-config.php` 中:

```php

```
