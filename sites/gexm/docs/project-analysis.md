## 二、已存在但存在问题的功能

### 2.1 桌面应用缺失资源

**严重程度**：🔴 高

| 缺失文件 | 路径 | 用途 |
|----------|------|------|
| icon.png | `packages/desktop/src/assets/icon.png` | 窗口图标 |
| tray.png | `packages/desktop/src/assets/tray.png` | 系统托盘图标 |
| icon.ico | `packages/desktop/src/assets/icon.ico` | Windows 安装包图标 |
| icon.icns | `packages/desktop/src/assets/icon.icns` | macOS 应用图标 |

**影响**：Electron 应用无法启动，会因缺少图标资源而崩溃。

### 2.2 uni-h5-vue 框架 Bug

**严重程度**：🟡 中

| Bug 类型 | 表现 | 影响 |
|----------|------|------|
| 响应式错误 | `Cannot assign to read only property '_'` | 控制台报错，不影响功能 |
| 调度器错误 | `Unhandled error during execution of scheduler flush` | 控制台报错，不影响功能 |
| 视图更新错误 | `Cannot read properties of null (reading 'offsetWidth')` | 控制台报错，不影响功能 |

**现状**：已在 App.vue 中添加错误过滤器拦截。

### 2.3 共享模块未集成

**严重程度**：🟡 中

| 问题 | 说明 |
|------|------|
| 语言不一致 | shared 使用 TypeScript，app/server 使用 JavaScript |
| 未被引用 | 任何包都未导入 shared 模块 |
| 违背设计 | monorepo 的核心价值是代码复用，目前未实现 |

### 2.4 支付系统为模拟实现

## 五、开发需求优先级排序

### P0 - 紧急需求（必须完成）

1. **桌面应用资源补充** - 添加图标资源，使 Electron 应用可运行
2. **真实支付集成** - 接入支付宝/微信支付
3. **管理后台** - 基础商品和订单管理功能
4. **CI/CD 流水线** - 自动化构建和测试

### P1 - 重要需求（建议完成）

5. **登录验证码** - 防止暴力破解
6. **共享模块集成** - 统一类型定义和工具函数
7. **图片优化** - 压缩和 CDN 加速
8. **离线支持** - 移动端离线数据缓存
9. **短信验证** - 用户注册验证

### P2 - 建议需求（按需完成）

10. **双因素认证** - 安全增强
11. **性能监控** - 应用性能追踪
12. **数据统计** - 管理后台统计功能
13. **推送通知** - APP/小程序推送
14. **安全审计日志** - 敏感操作记录

### P3 - 可选需求（未来规划）

15. **国际化支持** - 多语言
16. **分享功能** - 社交分享
17. **语音输入** - 对话语音输入
