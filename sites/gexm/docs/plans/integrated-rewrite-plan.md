# laal.top项目重写计划（整合版）

## 1. 项目概述
- 当前项目：基于WordPress的综合性网站
- 目标架构：前后端分离（Laravel 11.x + Vue.js 3 + TypeScript）
- API认证：Laravel Sanctum（替代Passport，因环境限制）
- 部署方式：Docker容器化

## 2. 技术栈

### 后端技术栈
- **框架**：Laravel 11.x (PHP 8.3)
- **数据库**：MySQL 8.0 + Redis 7.x (缓存)
- **认证**：Laravel Sanctum 4.0（替代Passport，因环境限制）
- **API**：RESTful API + GraphQL支持
- **任务队列**：Laravel Queue + Redis驱动
- **搜索**：Elasticsearch
- **权限管理**：spatie/laravel-permission

### 前端技术栈
- **框架**：Vue.js 3 + TypeScript
- **状态管理**：Pinia
- **路由**：Vue Router
- **UI组件库**：Element Plus
- **HTTP客户端**：Axios
- **构建工具**：Vite
- **样式方案**：SCSS + Tailwind CSS

## 3. 项目现状分析
- 当前项目是基于WordPress的网站
- 已制定新架构方案：Laravel 11.x + Vue.js 3 + TypeScript
- 后端已有基础Laravel框架和模块化结构
- 前端已有Vue 3 + Vite基础结构
- 使用Docker部署
- 已安装Laravel Sanctum 4.0

## 4. 重写目标
- 实现现代化的前后端分离架构
- 提高系统性能和安全性
- 支持模块化扩展
- 确保数据平滑迁移
- 提供更好的用户体验

## 5. 重写步骤

### 5.1 项目初始化和环境搭建

#### 5.1.1 后端环境搭建

- 配置数据库连接 (MySQL + Redis)
- 安装必要的依赖包
- 配置 Laravel Sanctum 认证（替代Passport）
  - 修改`config/auth.php`，将API guard的驱动改为`sanctum`
  - 配置CORS，允许前端访问API
  - 设置Sanctum的token过期时间
- 搭建 Docker 开发环境

#### 5.1.2 前端环境搭建
