# MixM Laal 网站重写架构方案

## 1. 技术栈选择

### 后端技术栈
- **框架**：Laravel 11.x (PHP 8.3)
- **数据库**：MySQL 8.0 + Redis 7.x (缓存)
- **认证**：Laravel Passport (API认证) + 多因素认证
- **API**：RESTful API + GraphQL支持
- **任务队列**：Laravel Queue + Redis驱动
- **搜索**：Elasticsearch

### 前端技术栈
- **框架**：Vue.js 3 + TypeScript
- **状态管理**：Pinia
- **路由**：Vue Router
- **UI组件库**：Element Plus
- **HTTP客户端**：Axios
- **构建工具**：Vite
- **样式方案**：SCSS + Tailwind CSS

## 2. 项目架构设计

### 目录结构
```
/backend/                # Laravel后端
  /app/
    /Modules/            # 模块化设计
      /Core/             # 核心功能
      /User/             # 用户模块
      /Content/          # 内容管理
      /Social/           # 社交功能
      /Ecommerce/        # 电商功能
      /Forum/            # 论坛功能
      /Video/            # 视频功能
      /Community/        # 社区功能
      /Bottle/           # 漂流瓶功能
      /Crawler/          # 采集功能
    /Http/
    /Models/
    /Services/
  /config/
  /database/
  /resources/

/frontend/               # Vue.js前端
  /src/
    /components/
    /views/
    /router/
    /store/
    /services/
    /assets/
  /public/
  /index.html

/docker/                 # Docker配置
/docs/                   # 项目文档
```
