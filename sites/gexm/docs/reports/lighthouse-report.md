| 指标 | 数值 | 分数 | 状态 | 说明 |

### 2.2 辅助性能指标

| 指标 | 数值 | 分数 | 状态 |
|------|------|------|------|
| **Max Potential FID** | 140.5ms | 0.87 | ✅ 良好 |
| **Time to Interactive** | 16.8s | 0 | ❌ 极差 |

### 2.3 性能问题诊断

**主要问题**：

| 问题 | 严重程度 | 影响 |
|------|----------|------|
| 首屏加载时间过长 | **极高** | 用户等待超过16秒才能看到内容 |
| 最大内容绘制时间过长 | **极高** | 主要内容31.8秒后才显示 |
| 速度指数极差 | **高** | 页面整体加载感知速度极慢 |

**根本原因分析**：
- 开发模式下Vite按需编译，首次点击未编译页面会先编译后加载
- Sass编译警告导致编译速度下降
- 后端API连接失败导致前端等待响应

## 三、可访问性指标

### 3.1 总体评分：54/100

### 3.2 主要问题

| 问题 | 严重程度 | 数量 |
|------|----------|------|
| 按钮无可访问名称 | 高 | 多个 |
| 表单元素无关联标签 | 高 | 多个 |
| 链接无可辨识名称 | 中 | 多个 |
| 图片缺少alt属性 | 中 | 多个 |

### 3.3 改进建议

1. 为所有按钮添加 `aria-label` 或可见文本
2. 为表单元素添加 `<label>` 或 `aria-label`
3. 为图片添加 `alt` 属性描述
4. 确保链接具有可辨识的文本内容

## 七、测试方法说明

### 7.1 测试命令

```bash
npx --yes lighthouse http://localhost:5173/ \
  --output=json \
  --output-path=./docs/lighthouse-home.json \
  --only-categories=performance,accessibility,best-practices,seo \
  --chrome-flags="--headless"
```

### 7.2 测试限制

**注意事项**：
- 本次测试在开发模式下运行，生产模式性能会显著提升
- Vite开发服务器按需编译，首次加载较慢
- 测试环境为本地localhost，未考虑网络延迟

**生产环境测试建议**：
```bash
# 构建生产版本后测试
npm run build:h5
# 使用静态服务器托管dist目录
npx serve dist
# 运行Lighthouse测试
npx lighthouse http://localhost:3000/
```
