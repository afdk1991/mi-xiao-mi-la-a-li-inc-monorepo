# MixM Laal 主题设计规范

## 项目概述

本文档为UI/UX设计师提供MixM Laal WordPress主题的设计规范和指南，确保设计的一致性和可实现性。

## 设计资产组织

### 文件夹结构

所有设计资产应按照以下结构组织并上传至服务器：

```
/www/wwwroot/api.laal.top/design/
├── psd_files/         # Photoshop源文件
├── png_files/         # 导出的PNG预览图
├── assets/icons/      # 图标资源
├── assets/fonts/      # 字体文件
└── assets/colors/     # 配色方案文档
```

### 文件命名规范

- 使用小写字母和连字符(-)，例如：`homepage-design.psd`
- 版本控制：添加版本号，例如：`homepage-design-v2.psd`
- 页面类型：明确指出页面类型，例如：`single-post-design.psd`

## 响应式设计规范

### 断点设置

| 断点 | 设备类型 | 宽度范围 | 布局调整 |
|------|---------|---------|----------|
| 移动端 | 手机 | < 768px | 单列布局，隐藏侧边栏 |
| 平板 | 平板 | 768px - 1024px | 双列布局（条件允许时） |
| 桌面端 | 小型桌面 | 1025px - 1280px | 标准三列布局 |
| 大屏 | 大型桌面 | > 1280px | 宽屏三列布局，内容区域更宽 |

### 关键元素响应式调整

1. **导航菜单**：
   - 桌面端：水平导航栏
   - 平板端：水平导航栏（可能简化）
   - 移动端：汉堡菜单，垂直下拉

2. **内容布局**：
   - 桌面端：侧边栏+主内容区
   - 平板端：条件显示侧边栏
   - 移动端：单列内容，侧边栏移至底部

3. **图片尺寸**：
   - 确保所有图片都经过响应式处理
   - 提供不同尺寸的图片版本

## 设计稿要求

### 必须包含的页面

1. **首页**：完整的首页设计，包括顶部导航、横幅区域、特色内容、文章列表、侧边栏、页脚
2. **文章详情页**：文章内容布局、评论区、相关文章推荐
3. **页面模板**：标准页面布局，无侧边栏选项
4. **归档页面**：文章列表、筛选功能
5. **搜索结果页**：搜索结果列表、筛选功能
6. **404页面**：错误页面设计

### 设计稿交付要求

1. **格式**：提供PSD源文件和PNG预览图
2. **图层组织**：清晰的图层命名和分组
3. **响应式设计**：提供至少三种尺寸的设计稿（移动端、平板、桌面端）
4. **交互细节**：标注关键交互状态（悬停、点击、激活等）
5. **组件库**：提供常用UI组件的设计（按钮、表单、卡片等）

## 图标规范

### 图标风格

- 使用线性图标，线条粗细一致（2px）
- 保持简约、现代的设计风格
- 所有图标保持视觉一致性

### 图标尺寸

| 场景 | 尺寸 | 推荐格式 |
|------|------|----------|
| 导航图标 | 24x24px | SVG |
| 按钮图标 | 16x16px | SVG |
| 功能图标 | 32x32px | SVG |
| 社交图标 | 24x24px | SVG |

## 动画与交互规范

### 动画原则

- 保持简洁，避免过度使用
- 确保动画流畅，不影响性能
- 所有动画应具有目的性

### 交互反馈

- 按钮点击：轻微缩放或颜色变化
- 悬停效果：颜色变化、阴影增强
- 页面过渡：平滑的淡入淡出或滑动效果
- 加载状态：提供适当的加载指示器

## 设计可实现性考虑

### 性能优化

- 避免过多的大型图片
- 考虑CSS动画优于JavaScript动画
- 确保设计在移动设备上不会过于复杂

### WordPress兼容性

- 考虑WordPress默认功能的布局需求
- 预留足够空间给小工具和动态内容
- 确保设计与常用WordPress插件兼容

## 协作流程

1. **设计初稿**：完成设计初稿后，与前端工程师沟通可实现性
2. **设计调整**：根据反馈调整设计
3. **设计定稿**：确认最终设计并上传至服务器
4. **开发跟进**：定期查看前端实现效果，提供必要的设计支持
