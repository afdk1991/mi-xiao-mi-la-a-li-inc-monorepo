# 设计系统文档

## 1. 设计系统概述

### 1.1 设计系统定义
设计系统是一套完整的设计规范和组件库，用于确保产品在不同平台、不同设备上的视觉统一性和一致性。它包括颜色、排版、间距、图标、组件等设计元素，以及使用这些元素的规则和指南。

### 1.2 设计系统目标
- 确保视觉一致性：所有页面和组件使用统一的设计语言
- 提高设计效率：设计师可以直接使用预定义的设计元素
- 提高开发效率：开发人员可以直接使用预定义的组件和样式
- 改善用户体验：用户可以在不同页面和功能之间获得一致的体验
- 便于维护和更新：可以集中管理和更新设计规范

### 1.3 设计系统范围
本设计系统适用于网站的所有页面和组件，包括：
- 首页
- 文章列表页
- 文章详情页
- 论坛页
- 商城页
- 后台管理页
- 所有UI组件

## 2. 颜色系统

- **一致性**：所有页面和组件使用统一的颜色方案
- **可访问性**：确保颜色对比度符合WCAG标准
- **层次结构**：使用不同的颜色强度和饱和度来区分元素的重要程度
- **品牌识别**：颜色方案应反映品牌的个性和价值观

### 2.7 颜色使用规则
1. **主色调使用规则**：
   - 主色调用于按钮、链接、强调文本等重要元素
   - 主色调的不同亮度变体用于不同状态（默认、悬停、激活、禁用）
   - 主色调的使用应保持克制，避免过度使用

2. **辅助色使用规则**：
   - 成功色用于成功提示、操作结果等
   - 警告色用于警告提示、需要注意的信息等
   - 错误色用于错误提示、危险操作等
   - 信息色用于信息提示、普通通知等

3. **中性色使用规则**：
   - 中性色用于文本、背景、边框等基础元素
   - 不同深度的中性色用于创建层次感
   - 中性色的使用应保持一致，避免随意使用不同的灰色

4. **颜色对比度规则**：
   - 文本与背景的对比度至少达到WCAG AA级标准（4.5:1）
   - 大文本（18pt以上或14pt加粗）的对比度至少达到WCAG AA级标准（3:1）
   - 确保所有用户都能清晰地看到内容

### 3.7 排版使用规则
1. **标题使用规则**：
   - 每个页面只能有一个H1标题
   - 标题应清晰地反映页面内容
   - 标题层级应保持一致，避免跳过层级
   - 标题应简洁明了，避免过长

2. **正文使用规则**：
   - 正文文本应使用16px以上的字体大小
   - 段落之间应保持适当的间距
   - 长文本应使用适当的行高，提高可读性
   - 重点内容应使用强调样式（加粗、颜色）

3. **链接使用规则**：
   - 链接应使用主色调
   - 链接应带有下划线或其他视觉标识
   - 悬停状态应有明显的视觉变化
   - 已访问链接应与未访问链接有区分

## 4. 间距系统

### 4.1 间距单位
使用4px作为基础间距单位，所有间距都应是4px的倍数，确保间距的一致性和可预测性。

### 4.2 间距值
| 间距名称 | 像素值 | 用途 |
|---------|-------|------|
| 微型间距 | 4px | 小元素之间的间距、内边距 |
| 小间距 | 8px | 元素之间的小间距、内边距 |
| 中间距 | 16px | 元素之间的中等间距、内边距 |
| 大间距 | 24px | 区块之间的间距、大元素的内边距 |
| 超大间距 | 32px | 页面主要区块之间的间距 |
| 极大间距 | 48px | 首页横幅、重要区块之间的间距 |

### 4.3 间距使用规则
1. **外边距使用规则**：
   - 区块之间使用大间距或超大间距
   - 元素之间使用小间距或中间距
   - 小元素之间使用微型间距
   - 保持一致的间距模式

2. **内边距使用规则**：
   - 卡片、面板使用中间距或大间距
   - 按钮、输入框使用小间距或中间距
   - 标签、徽章使用微型间距或小间距
   - 保持一致的内边距模式

3. **网格系统**：
   - 使用12列网格系统
   - 列宽为60px，间距为24px
   - 最大容器宽度为1200px
   - 响应式设计中根据屏幕尺寸调整列数和间距

5. **可访问性**：为图标添加适当的alt文本或aria标签

## 7. 响应式设计指南

### 7.1 断点设计
| 断点名称 | 屏幕宽度 | 布局变化 |
|---------|---------|----------|
| 移动端 | < 576px | 单列布局，隐藏侧边栏，汉堡菜单 |
| 平板端 | 576px - 768px | 双列布局，简化侧边栏 |
| 桌面端 | 768px - 1200px | 三列布局，完整侧边栏 |
| 大屏桌面 | > 1200px | 固定宽度布局，最大宽度1200px |

### 7.2 响应式设计原则
1. **移动优先**：从移动端开始设计，然后扩展到桌面端
2. **内容优先级**：在小屏幕上只显示最重要的内容
3. **灵活布局**：使用弹性布局和网格系统，适应不同屏幕尺寸
4. **可触摸元素**：确保按钮和链接足够大，适合触摸操作
5. **优化图片**：根据屏幕尺寸加载不同大小的图片
6. **简化导航**：在小屏幕上使用汉堡菜单或折叠菜单
7. **保持可读性**：确保文本在所有屏幕尺寸上都易于阅读

### 7.3 响应式设计规则
1. **字体大小响应式**：在小屏幕上适当减小字体大小
2. **间距响应式**：在小屏幕上适当减小间距
3. **布局响应式**：根据屏幕尺寸调整列数和布局
4. **组件响应式**：根据屏幕尺寸调整组件大小和样式
5. **图片响应式**：使用响应式图片，确保在所有设备上都能正确显示
6. **导航响应式**：在小屏幕上使用汉堡菜单，简化导航

## 8. 可访问性指南

### 8.1 可访问性原则
1. **感知性**：信息和用户界面组件必须以可感知的方式呈现给用户
2. **可操作性**：用户界面组件和导航必须是可操作的
3. **可理解性**：信息和用户界面操作必须是可理解的
4. **鲁棒性**：内容必须足够健壮，能被各种用户代理可靠地解释

### 8.2 可访问性标准
遵循WCAG 2.1 AA级标准，确保网站对所有用户都可访问。

### 8.3 可访问性实现
1. **颜色对比度**：确保文本与背景的对比度至少达到4.5:1
2. **键盘导航**：确保所有功能都可以通过键盘访问
3. **语义化HTML**：使用正确的HTML元素，确保屏幕阅读器能够理解内容
4. **alt文本**：为所有图片添加描述性的alt文本
5. **ARIA属性**：为复杂组件添加适当的ARIA属性
6. **焦点管理**：确保焦点顺序合理，焦点状态可见
7. **表单标签**：为所有表单字段添加明确的标签
8. **错误处理**：提供清晰的错误提示和修复建议
9. **字体大小**：允许用户调整字体大小
10. **语言属性**：为页面添加正确的语言属性
