# 08 · 主题更名改动清单（ZibStyle → slStyle）

**执行日期**：2026-08-29
**性质**：破坏性改动（目录重命名 + 文本域 + 数据库）
**结论**：✅ 已执行完毕，回归全绿
**回滚点**：`backups/2026-08-29-theme-rename/`（主题目录 31 文件 + `wp_options` 全量导出）

---

## 1. 为什么改

主题原名 **ZibStyle** 与商业中文主题品牌 **Zibll（子比主题）** 名称近似，且描述/注释中明示
「参考 Zibll 设计风格」。经核查代码确系原创（不侵犯著作权），但构成**商标淡化**与
**搭便车（不正当竞争）** 风险——该风险**独立于开源许可**，GPL 不授予商标权
（GPLv3 §7(e) 明确不授予商标许可）。详见 `05-许可证与商用合规分析.md` 3.2(b) 与 5.3 节。

新名 **slStyle** 为中性自造词，不含 "Zib" 词根。

| 函数前缀 | `zibstyle_*` | `slstyle_*` | 如 `slstyle_setup`、`slstyle_breadcrumbs` |
| 版本常量 | `ZIBSTYLE_VERSION` | `SLSTYLE_VERSION` | `functions.php` / `inc/customizer.php` / 子主题共用 |

| body/main class | `zibll-home` | `slstyle-home` | `front-page.php:16`（`<main>` 上） |
| Theme URI | `example.com/zibstyle(-child)` | `example.com/slstyle(-child)` | 占位地址 |

**保持不变**（中性、无商标风险，避免无谓扩散）：
- 子主题 CSS 类前缀 `zsc-*`（dashboard 组件）
- 子主题目录内的页面模板名 `page-dashboard.php`

## 4. 数据库变更

| option_name | 原值 | 新值 | 为什么必须改 |
|---|---|---|---|
| `template` | `zibstyle` | `slstyle` | 父主题定位；不改则主题失效 |
| `stylesheet` | `zibstyle-child` | `slstyle-child` | 启用主题定位；不改则站点回退默认主题 |
| `current_theme` | `ZibStyle Child` | `slStyle Child` | 后台显示名 |
| `theme_mods_zibstyle` | — | `theme_mods_slstyle` | **保住自定义器设置**（主色、菜单分配等），否则丢失 |
| `theme_mods_zibstyle-child` | — | `theme_mods_slstyle-child` | 同上 |

变更方式：容器内 `wp-load.php` + `update_option()` / `$wpdb->update()`，
末尾 `wp_cache_flush()`。未使用裸 SQL 直写，避免绕过对象缓存。

**所以 5 与 8 应尽量连续执行**。

## 6. 回滚方案

**方案 A — 完整回滚（推荐，约 2 分钟）**

```bash
# 1) 删新目录、还原旧目录
rm -rf public/wp-content/themes/slstyle public/wp-content/themes/slstyle-child
cp -r backups/2026-08-29-theme-rename/zibstyle      public/wp-content/themes/
cp -r backups/2026-08-29-theme-rename/zibstyle-child public/wp-content/themes/

# 2) 还原数据库（容器内执行）
require "/var/www/html/wp-load.php";
update_option("template","zibstyle");
update_option("stylesheet","zibstyle-child");
update_option("current_theme","ZibStyle Child");
global $wpdb;
$wpdb->query("UPDATE {$wpdb->options} SET option_name=REPLACE(option_name,\"theme_mods_slstyle\",\"theme_mods_zibstyle\") WHERE option_name LIKE \"theme_mods_slstyle%\"");
wp_cache_flush();'

# 3) 还原脚本断言
sed -i -e 's/slstyle-child/zibstyle-child/g' -e 's/slstyle/zibstyle/g' scripts/verify-site.php scripts/wp-bootstrap.php
```

**方案 B — 仅还原数据库**（主题文件已确认无误、只是 option 写错时）：
`docker exec wp004-mysql mysql -uwp004 -p wp004 < backups/2026-08-29-theme-rename/wp_options-backup.sql`

**验证回滚成功**：`docker exec wp004-php php -r 'require "/var/www/html/wp-load.php"; echo get_option("stylesheet");'`
应输出 `zibstyle-child`。
