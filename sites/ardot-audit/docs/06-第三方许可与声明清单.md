## 0. 一句话结论

**自用（把站点跑起来对外提供商业服务）：本文无需执行任何动作。**
**分发（把主题/插件/整站打包交付或出售）：需完成第 5 节清单，缺 3 项文本。**

GPL 的义务触发点是 **分发（distribution / conveying）**，不是运行。GPLv2 §0 明文：
*"the act of running the Program is not restricted"*，且 GPLv2 不像 AGPL 有网络使用条款，
所以 SaaS 模式不触发任何开源义务。

## 4. Redis → Valkey 变更记录（本轮执行）

### 4.1 为什么换

- Redis 自 **7.4** 起把许可证从 BSD-3-Clause 改为 **RSALv2 / SSPLv1 双许可**，两者均**非 OSI 认证、非 FSF 认可**。
- compose 里写的是 `redis:7-alpine`——**浮动标签**，会解析到 7.4.x。实测运行的就是 **7.4.11**，即已跨过许可变更线。
- 原状等于把一个非开源依赖悄悄带进了交付栈，且官方镜像内**不随附任何 LICENSE 文件**，第三方审计时无法举证。

### 4.2 换成什么

`valkey/valkey:8.1-alpine`。Valkey 是 Redis 7.2.4 的 Linux Foundation 分叉，BSD-3-Clause，
由 AWS / Google / Oracle / Broadcom 等共同支持。

### 4.3 实测验证（全部通过）

| 验证项 | 结果 |
|---|---|
| 镜像拉取 | ✅ `valkey/valkey:8.1-alpine`，Valkey 8.1.9 |
| 容器健康 | ✅ `Up`，`valkey-cli ping` → `PONG` |
| SET/GET 冒烟 | ✅ `set wp004:lic "ok"` → `OK`，`get` → `ok` |
| **phpredis 扩展直连** | ✅ 连接 OK / ping `true` / 读写正常 / 识别出 server `8.1.9` |

最后一条是关键的：**phpredis 扩展零改动直连 Valkey**，证明 RESP 协议层确实是 drop-in。

### 4.4 ⚠️ 踩到的真坑：drop-in 只在协议层成立

首次启动时容器**反复重启**，日志：

```
1:M # Can't handle RDB format version 12
1:M # Error reading the RDB base file appendonly.aof.1.base.rdb, AOF loading aborted
```

**原因**：Valkey 从 **Redis 7.2.4** 分叉，而 Redis **7.4 引入了 RDB v12 格式**
（以及新的 multi-part AOF 目录结构 `appendonlydir/`）。Valkey 8.1 读不了 RDB v12。

**结论（重要，容易被营销话术误导）**：
> Valkey 是协议层 drop-in，但**不是持久化文件格式层 drop-in**。
> 从 Redis 7.4 迁移到 Valkey 时，存量 RDB/AOF **必须走一次数据迁移**（`DUMP`/`RESTORE`
> 或 `redis-cli --rdb` 导出后再导入），**不能直接挂载旧数据卷**。

**本项目处置**：该卷只有缓存数据，站点根本没在用（无 `object-cache.php`、
`wp-config.php` 无 Redis 配置、业务代码零引用），故直接删除 `wp004_redis-data` 重建。
**若你的生产环境有 Redis 7.4 存量缓存要迁移，请勿照抄此操作。**

## 6. 关键法律判断的两条边界

**注 5 · HTTP 调用下游微服务不构成衍生作品**
本项目 `saas-aggregator` 通过 REST 调用外部微服务（gateway-go / ai-python / node-api）。
依 GPLv2 §2 的 mere aggregation（聚合）原则，**进程间通过 HTTP/JSON 通信不构成衍生作品**。
→ 下游微服务的许可证**不影响**本项目的 GPL 合规，无需为它们的许可证做开源披露。

**注 6 · GPL 不授予商标权**
GPLv2 §7 明确：许可证不授予任何商标或服务标记的使用权。
→ 商标风险（slStyle 命名、WordPress 品牌、MySQL 商标）**是独立于开源合规的另一条线**，
   需要单独处理，GPL 合规做对了也不等于商标没问题。
