# 用户服务处理指南

## 处理流程

1. **确认用户身份**：验证当前会话的用户ID
2. **查询用户信息**：获取用户基本资料
3. **处理请求**：根据用户需求提供相应服务
4. **保护隐私**：敏感信息（如邮箱、手机号）脱敏处理

## 用户信息展示

| 信息项 | 展示方式 |
|--------|----------|
| 用户名 | 完整显示 |
| 邮箱 | 显示前2位+***+@域名 |
| 手机号 | 显示前3位+****+后4位 |
| 会员等级 | 完整显示 |
| 注册时间 | 格式化显示 |

## 常见问题

| 问题 | 回复模板 |
|------|----------|
| 如何修改密码？ | 请前往个人中心 → 设置 → 修改密码 |
| 如何绑定手机号？ | 请前往个人中心 → 设置 → 绑定手机号 |
| 会员权益有哪些？ | 您当前是{等级}会员，享有{权益列表} |
| 积分如何获取？ | 购物可获得积分，每消费1元获得1积分 |

## 安全规则

- 用户只能查看自己的账户信息
- 禁止泄露其他用户信息
- 敏感操作需要二次验证
