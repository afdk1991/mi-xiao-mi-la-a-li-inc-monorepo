# 版本更新日志模板

## [版本号] - 发布日期

### 🆕 新增功能
- 功能描述1
- 功能描述2

### ⚡ 优化改进
- 优化描述1
- 优化描述2

### 🐛 问题修复
- 修复问题1
- 修复问题2

### 🔒 安全更新
- 安全修复描述

### 📦 其他变更
- 其他变更描述

---

## 更新日志格式说明

1. **版本号**：遵循语义化版本 (SemVer)，格式：`主版本.次版本.修订号`
   - 主版本：破坏性兼容的变更
   - 次版本：向后兼容的新功能
   - 修订号：向后兼容的问题修复

2. **发布日期**：ISO 8601 格式 `YYYY-MM-DD`

3. **分类标签**：
   - 🆕 新增功能 (Features)
   - ⚡ 优化改进 (Improvements)
   - 🐛 问题修复 (Bug Fixes)
   - 🔒 安全更新 (Security)
   - 📦 其他变更 (Changes)

4. **每条记录格式**：
   - 使用动词过去式描述（如：新增、修复、优化）
   - 简洁明了，一行一条
   - 涉及issue或PR可附带编号

### 示例

```markdown
# Changelog

## [2.1.0] - 2024-06-15

### 🆕 新增功能
- 支持深色模式切换
- 新增批量导出功能 (#123)

### ⚡ 优化改进
- 提升应用启动速度30%
- 优化内存占用

### 🐛 问题修复
- 修复登录窗口偶发闪退问题 (#456)
- 修复特定分辨率下界面错位 (#789)

## [2.0.0] - 2024-01-01

### 🆕 新增功能
- 完全重写用户界面
- 支持插件扩展系统
```

### 发布notes.json格式

服务端需提供 `notes.json` 格式：

```json
{
  "version": "2.1.0",
  "releaseDate": "2024-06-15T10:00:00Z",
  "releaseNotes": "<h2>更新内容</h2>...",
  "type": "minor",
  "urgent": false,
  "minVersion": "1.5.0"
}
```
