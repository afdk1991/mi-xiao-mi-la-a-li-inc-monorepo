## 二、P0 问题修复清单

### 2.1 安全类 P0（4/4 已修复）

#### ① wp-config.php SALT 密钥硬编码 fallback

- **文件**：`wp-config.php`
- **问题**：8 个 WordPress SALT 密钥使用硬编码 fallback 值，泄露到代码仓库
- **修复**：改为环境变量优先 → 开发环境动态生成（`bin2hex(random_bytes(32))`）→ 生产环境 fail-fast
- **状态**：✅ 已修复

#### ② 敏感 AJAX 操作使用 wp_ajax_nopriv_* 钩子

- **文件**：
  - `wp-content/themes/mixm-laal/inc/reward-functions.php:144` - 打赏支付
  - `wp-content/themes/mixm-laal/inc/poll-functions.php:1588` - 投票
- **问题**：允许未登录用户触发支付/投票敏感操作
- **修复**：移除 `wp_ajax_nopriv_process_reward` 和 `wp_ajax_nopriv_mixm_laal_cast_vote` 钩子
- **状态**：✅ 已修复

#### ③ unserialize() PHP 对象注入风险

- **文件**：`wp-content/themes/mixm-laal/inc/performance-functions.php:834`
- **问题**：Redis 缓存反序列化未限制 allowed_classes，存在 PHP 对象注入风险
- **修复**：添加 `array('allowed_classes' => false)` 参数阻止对象反序列化
- **状态**：✅ 已修复

#### ④ 加密密钥明文存储于 wp_options

- **文件**：`wp-content/themes/mixm-laal/inc/api-security.php:1520`
- **问题**：API 加密密钥通过 `get_option()` 明文存储在数据库
- **修复**：优先使用环境变量 `MIXM_API_ENCRYPTION_KEY`，回退到 wp_options（开发环境兼容）
- **状态**：✅ 已修复

### 2.2 配置类 P0（8/8 已修复）

#### ① docker-compose.yml 使用未定义的环境变量

- **文件**：`.env`
- **问题**：`docker-compose.yml` 使用 `${REDIS_PASSWORD:?}` 和 `${POSTGRES_PASSWORD:?}` 但 .env 未定义
- **修复**：在 .env 中添加 REDIS_PASSWORD、POSTGRES_PASSWORD、POSTGRES_DB、POSTGRES_USER 等变量
- **状态**：✅ 已修复

#### ② WordPress SALT 密钥环境变量占位

- **文件**：`.env`
- **问题**：wp-config.php 期望从环境变量读取 SALT 密钥，但 .env 未提供
- **修复**：在 .env 中添加 8 个 SALT 密钥占位（开发环境留空使用动态生成）
- **状态**：✅ 已修复

#### ③ CI/CD 引用不存在的 npm scripts

- **文件**：`package.json` + `.github/workflows/ci-cd.yml`
- **问题**：CI/CD 引用 `build:all`、`test:e2e`、`lint:security` 脚本但 package.json 未定义
- **修复**：在 package.json 中添加 `build:all`、`test:e2e`、`lint:security`、`build:pc`、`build:sdk`、`test:server`、`test:sdk` 脚本
- **状态**：✅ 已修复

#### ④ CI/CD 硬编码测试数据库密码

- **文件**：`.github/workflows/ci-cd.yml`
- **问题**：E2E 测试中硬编码 `e2e_test_pg_password_2024`、JWT_SECRET、REDIS_PASSWORD
- **修复**：改用 GitHub Actions secrets `${{ secrets.E2E_POSTGRES_PASSWORD }}` 和 `${{ secrets.E2E_JWT_SECRET }}`
- **状态**：✅ 已修复

#### ⑤ Dockerfile WordPress 版本不一致

- **文件**：`docker/wordpress/Dockerfile`
