# 登录系统设计规范文档

> 适用范围：`packages/pc` 管理后台登录子系统
> 版本：1.0.0 | 日期：2026-07-14

---

## 一、设计理念与目标

### 1.1 设计理念

本登录系统遵循 **"信任、效率、包容"** 三大设计原则：

- **信任**：通过品牌视觉一致性、安全状态反馈（锁定提示、密码强度）建立用户信任感
- **效率**：最少操作步骤完成核心任务，内联校验即时反馈，减少往返提交
- **包容**：WCAG 2.1 AA 级可访问性，支持键盘导航、屏幕阅读器、减弱动效偏好

### 1.2 设计目标

| 目标维度 | 指标 |
|---------|------|
| 首屏渲染 (FCP) | < 2 秒 |
| 动画流畅度 | 60fps（CSS transform/opacity） |
| 可访问性 | WCAG 2.1 AA 级 |
| 响应式断点 | 桌面 ≥1200px / 平板 768-1199px / 移动 ≤767px |
| 第三方登录 | ≥ 2 种（当前集成 7 种 OAuth Provider） |
| 验证码方案 | 图形验证码（Canvas）+ 短信验证码 + 邮箱验证码 |
| 单元测试覆盖率 | ≥ 80%（关键模块） |

## 二、排版系统规范

### 2.1 栅格系统

| 断点 | 范围 | 布局策略 |
|------|------|---------|
| 桌面 | ≥1200px | 分屏布局：品牌展示区 40% + 表单区 60% |
| 平板 | 768-1199px | 居中卡片，最大宽度 480px，隐藏品牌区 |
| 移动 | ≤767px | 全宽卡片，最小内边距，验证码输入纵向堆叠 |

### 2.2 间距系统（Spacing Scale）

采用 4px 基准的线性间距令牌：

```scss
--gexm-spacing-xs: 4px;   // 行内元素微间距
--gexm-spacing-sm: 8px;   // 表单元素紧凑间距
--gexm-spacing-md: 16px;  // 标准模块间距
--gexm-spacing-lg: 24px;  // 区块间距
--gexm-spacing-xl: 40px;  // 页面级留白
```

### 2.3 字体规范

| 层级 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| 页面标题 | 28px (桌面) / 20px (移动) | 700 | 1.3 | 登录/注册主标题 |
| 品牌名称 | 32px (桌面) / 22px (移动) | 800 | 1.2 | Logo 文字 |
| 区块标题 | 16px | 600 | 1.5 | 分组标题、Tab 标签 |
| 正文 | 14px | 400 | 1.6 | 输入框、按钮文字 |
| 辅助文字 | 12px | 400 | 1.5 | 错误提示、协议链接 |

字体族：系统默认无衬线字体栈

### 2.4 圆角系统

```scss
--gexm-radius-sm: 8px;   // 小组件（输入框、按钮）
--gexm-radius-md: 12px;  // 中型容器（卡片、Logo 容器）
--gexm-radius-lg: 20px;  // 大型容器（主卡片）
```

## 四、组件库规范

### 4.1 输入框（Input）

- 尺寸：`large`（高度 40px）
- 圆角：`--gexm-radius-sm` (8px)
- 状态：默认 → 聚焦 → 错误

### 4.2 按钮（Button）

| 类型 | 视觉 | 用途 |
|------|------|------|
| Primary | 渐变背景，白色文字 | 主操作 |
| Default | 白色背景，主色边框 | 次要操作 |
| Text | 无背景，主色文字 | 链接型操作 |

### 4.3 密码强度指示器

四段式进度条，6 维度评分：

| 等级 | 条件 | 颜色 |
|------|------|------|
| 0 | 长度 < 8 | `#f56c6c` |
| 1 | 评分 ≤ 2 | `#f56c6c` |
| 2 | 评分 ≤ 3 | `#e6a23c` |
| 3 | 评分 ≤ 4 | `#67c23a` |
| 4 | 评分 ≥ 5 | `#52c41a` |

### 4.4 图形验证码（CaptchaCanvas）

- 画布尺寸：120×40px
- 字符集：4 位字母数字（排除 O/0/I/1）
- 视觉干扰：随机旋转、颜色、噪点线、圆点

### 4.5 第三方登录面板

- 支持：Google、微信、QQ、微博、Twitter、Alipay、Apple
- 定位：`position: fixed` + JS 动态计算

## 五、交互模式规范

### 5.1 表单校验模式

- 即时反馈：输入时清除错误，失焦时校验
- 错误展示：红色文字 + 抖动动画
- 提交校验：全量校验，任一失败阻止提交

### 5.2 加载状态反馈

| 场景 | 反馈方式 |
|------|---------|
| 登录提交 | 按钮旋转图标 + 禁用 |
| 发送验证码 | 倒计时（60s） |
| OAuth 跳转 | 整页 loading |

### 5.3 安全机制

| 机制 | 参数 |
|------|------|
| 最大尝试次数 | 5 次 |
| 锁定时长 | 15 分钟 |
| Token 过期追踪 | 时间戳 |
| 自动刷新阈值 | 60 秒 |

## 六、性能优化规范

### 6.1 加载性能

- 路由懒加载：所有路由使用动态 `import()`
- 代码分割：Vite `manualChunks`

### 6.2 运行时性能

- GPU 加速：`will-change: transform`
- 渲染隔离：`contain: layout style paint`
- 动画属性：仅使用 `transform` 和 `opacity`

## 八、安全设计规范

### 8.1 Token 安全

- 双存储策略：记住我 → localStorage，否则 → sessionStorage
- Token 过期追踪：`tokenExpiry` 时间戳
- 自动刷新：过期前 60 秒

### 8.2 登录安全

- 失败计数：5 次后锁定 15 分钟
- 锁定状态持久化：localStorage
- 过期锁自动释放：启动时检查

### 8.3 密码安全

- 最小长度：8 字符
- 强度评分：6 维度评估
- 传输：HTTPS 加密
