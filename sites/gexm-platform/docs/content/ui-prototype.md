## 设计系统规范

### 颜色规范

基于 `variables.scss` 定义的核心颜色系统：

| 分类 | 颜色变量 | 颜色值 | 使用场景 |
|------|---------|--------|---------|
| **品牌色** | `$brand-primary` | `#2563eb` | 主按钮、链接、品牌强调 |
| | `$brand-primary-light` | `#3b82f6` | 悬浮状态、渐变终点 |
| | `$brand-primary-dark` | `#1d4ed8` | 激活状态、渐变起点 |
| **功能色** | `$color-success` | `#10b981` | 成功状态、确认按钮 |
| | `$color-warning` | `#f59e0b` | 待处理状态、警告提示 |
| | `$color-danger` | `#ef4444` | 价格显示、删除操作 |
| | `$color-info` | `#6366f1` | 信息提示、辅助链接 |
| **中性色** | `$gray-50` | `#f9fafb` | 页面背景 |
| | `$gray-100` | `#f3f4f6` | 卡片背景、分割线 |
| | `$gray-200` | `#e5e7eb` | 边框颜色 |
| | `$gray-600` | `#4b5563` | 次级文字 |
| | `$gray-900` | `#111827` | 主文字 |

### 字体规范

| 分类 | 变量名 | 尺寸 (rpx) | 使用场景 |
|------|--------|-----------|---------|
| **小号字体** | `$font-size-xs` | `20rpx` | 辅助信息、标签文字 |
| | `$font-size-sm` | `24rpx` | 次级信息、商品规格 |
| **标准字体** | `$font-size-base` | `28rpx` | 商品名称、正文内容 |
| | `$font-size-md` | `32rpx` | 标题文字、价格显示 |
| **大号字体** | `$font-size-lg` | `36rpx` | 区块标题、重要价格 |
| | `$font-size-xl` | `40rpx` | 合计金额、Banner标题 |
| | `$font-size-2xl` | `48rpx` | 大标题、营销文案 |

### 间距规范

基于 8px 基准的间距系统：

| 变量名 | 尺寸 (rpx) | 使用场景 |
|--------|-----------|---------|
| `$spacing-2` | `8rpx` | 图标与文字间距 |
| `$spacing-4` | `16rpx` | 组件内部间距 |
| `$spacing-6` | `24rpx` | 页面内边距 |
| `$spacing-8` | `32rpx` | 区块间距 |
| `$spacing-12` | `48rpx` | 大间距、卡片间距 |
| `$spacing-16` | `64rpx` | 区块外边距 |

### 圆角规范

| 变量名 | 尺寸 (rpx) | 使用场景 |
|--------|-----------|---------|
| `$radius-sm` | `4rpx` | 小按钮、标签 |
| `$radius-base` | `8rpx` | 输入框、小卡片 |
| `$radius-md` | `12rpx` | 商品图片 |
| `$radius-lg` | `16rpx` | 卡片、按钮 |
| `$radius-xl` | `20rpx` | Banner、大卡片 |
| `$radius-full` | `9999rpx` | 圆形按钮、头像 |

| **分类点击** | `transform: scale(0.95)` `opacity: 0.7` | 用户点击分类图标 |

## 关键用户流程

### 1. 商品浏览流程

```
用户进入首页 → 查看Banner推荐 → 点击分类图标 → 进入分类页 →
浏览商品列表 → 点击商品卡片 → 进入商品详情页 → 查看商品信息 →
选择SKU规格 → 加入购物车/立即购买
```

**关键节点：**
- **首页加载**：显示加载状态，加载失败时显示空状态
- **分类切换**：左侧栏点击切换，右侧商品列表实时更新
- **商品详情**：懒加载图片，SKU选择器交互

### 2. 购物车操作流程

```
进入购物车页 → 加载购物车商品 → 选择商品（勾选） →
调整数量（增减按钮） → 滑动删除商品 → 查看合计金额 →
点击结算按钮 → 进入订单确认页
```

**关键节点：**
- **商品选择**：单选/全选操作，实时更新合计金额
- **数量调整**：最小数量提示删除确认，最大数量库存限制
- **滑动删除**：左滑显示删除按钮，点击确认删除
- **编辑模式**：切换为批量删除模式

### 3. 下单支付流程

```
订单确认页 → 选择收货地址 → 确认商品清单 → 填写订单备注 →
查看金额明细 → 点击提交订单 → 创建订单成功 →
跳转支付页面 → 选择支付方式 → 完成支付 →
跳转订单详情页
```

**关键节点：**
- **地址选择**：未选择时显示空状态提示，点击进入地址选择页
- **订单提交**：提交按钮禁用状态（无地址/无商品），加载状态显示
- **支付跳转**：支付成功后跳转订单详情，支付失败提示重新支付

### 4. 订单管理流程

```
进入订单列表页 → Tab筛选订单状态 → 点击订单卡片 →
进入订单详情页 → 查看物流信息 → 确认收货操作 →
申请退款/评价商品
```

**关键节点：**
- **状态筛选**：Tab切换加载对应状态订单，空状态显示
- **订单操作**：不同状态显示不同操作按钮（取消/支付/确认收货等）
- **物流跟踪**：时间线样式展示物流节点
- **评价商品**：已完成订单可进入评价页面

## 交互状态定义

### 通用交互状态

| 状态类型 | 视觉表现 | 实现方式 | 适用场景 |
|---------|---------|---------|---------|
| **加载状态** | 加载动画+文字提示 | `<gexm-loading text="加载中..." />` | 数据请求、页面初始化 |
| **空状态** | 图标+描述+操作按钮 | `<gexm-empty description="暂无数据" show-button />` | 列表为空、购物车为空 |
| **错误状态** | 错误提示Toast | `uni.showToast({ title: '操作失败', icon: 'none' })` | 请求失败、操作异常 |
| **成功状态** | 成功提示Toast | `uni.showToast({ title: '操作成功', icon: 'success' })` | 操作完成、提交成功 |

### 组件交互状态

| **禁用** | 灰色背景+不可点击 | `background: $gray-300` `opacity: 0.6` `cursor: not-allowed` |

### 设计原则

1. **一致性原则**：相同功能的组件在不同页面保持视觉和交互一致
2. **可访问性原则**：确保色彩对比度、可点击区域大小符合无障碍标准
3. **响应式原则**：所有页面需适配XS到LG+所有屏幕尺寸
4. **性能原则**：优先使用CSS动画，避免复杂JavaScript交互
5. **简洁原则**：避免过度设计，保持界面简洁清晰
