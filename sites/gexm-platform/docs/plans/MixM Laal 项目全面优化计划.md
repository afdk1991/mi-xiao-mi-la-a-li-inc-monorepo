# MixM Laal 项目全面优化计划

## 1. 目录结构整理

### 1.1 根目录清理
- 删除不必要的压缩文件（*.tar.gz）
- 清理临时脚本和测试文件
- 将文档文件统一整理到docs目录
- 移除重复的项目文件

### 1.2 主题目录优化
- 保留主要主题mixm-laal，删除重复或未使用的主题
- 统一主题命名和结构
- 清理主题中的冗余文件

### 1.3 代码目录结构
- 优化frontend目录结构
- 统一backend和backend-new目录，保留最新版本
- 整理api-gateway目录

## 2. WordPress优化

### 2.1 核心优化
- 更新WordPress核心到最新版本
- 优化wp-config.php配置
- 清理未使用的数据库表

### 2.2 主题优化
- 修复已知错误（mixm_laal_get_posts()函数、MixM_Laal_Shop类、未定义的$post变量）
- 优化主题函数，提高代码质量
- 清理未使用的主题文件和函数
- 优化主题资源加载

### 2.3 插件优化
- 更新所有插件到最新版本
- 清理未使用的插件
- 优化插件设置
- 确保插件之间的兼容性
