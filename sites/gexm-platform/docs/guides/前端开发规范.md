# MixM Laal 主题前端开发规范

本文档为前端工程师提供MixM Laal WordPress主题的前端开发规范和最佳实践，确保代码质量和一致性。

## 目录结构

所有前端开发文件应按照以下结构组织并上传至服务器：

```
/www/wwwroot/api.laal.top/static/
├── html/       # 静态HTML页面
├── css/        # CSS样式文件
├── js/         # JavaScript脚本
├── images/     # 图片资源
└── fonts/      # 字体文件
```

## HTML规范

### 语义化标签

使用HTML5语义化标签，提高可访问性和SEO：

```html
<!-- 推荐 -->
<header>头部内容</header>
<nav>导航菜单</nav>
<main>主要内容</main>
<article>文章内容</article>
<aside>侧边栏</aside>
<footer>页脚内容</footer>

<!-- 避免 -->
<div class="header">头部内容</div>
<div class="nav">导航菜单</div>
```

### 代码格式

- 使用2个空格进行缩进
- 标签名使用小写
- 属性值使用双引号
- 自闭合标签不需要斜杠（HTML5）

```html
<!-- 推荐 -->
<div class="container">
  <img src="image.jpg" alt="描述文字">
  <input type="text" placeholder="请输入">
</div>
```

### WordPress集成

将静态HTML转换为WordPress模板时，使用以下结构：

```php
<?php get_header(); ?>

<main id="main" class="site-main">
  <!-- 主内容 -->
</main><!-- #main -->

<?php get_sidebar(); ?>
<?php get_footer(); ?>
```

## CSS规范

### BEM命名规范

使用BEM（Block, Element, Modifier）命名规范：

```css
/* Block - 独立的功能块 */
.header {}

/* Element - 块内的子元素 */
.header__logo {}
.header__nav {}

/* Modifier - 元素的状态或变体 */
.header--fixed {}
.header__button--primary {}
```

### CSS组织

按照以下顺序组织CSS规则：

1. 变量声明
2. 重置样式
3. 基础样式
4. 布局样式
5. 组件样式
6. 页面特定样式
7. 媒体查询

```css
/* 变量 */
:root {
  --color-primary: #1a73e8;
  --color-text: #333333;
}

/* 重置样式 */
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

/* 基础样式 */
body {
  font-family: 'Inter', sans-serif;
  color: var(--color-text);
}

/* 组件样式 */
.button {
  padding: 10px 20px;
  border: none;
  border-radius: 4px;
}

.button--primary {
  background-color: var(--color-primary);
  color: white;
}
```

### WordPress样式集成

在WordPress中，使用`wp_enqueue_style()`加载样式：

```php
function mixm_laal_enqueue_styles() {
  wp_enqueue_style( 'mixm-laal-style', get_stylesheet_uri() );
  wp_enqueue_style( 'mixm-laal-responsive', get_template_directory_uri() . '/css/responsive.css' );
}
add_action( 'wp_enqueue_scripts', 'mixm_laal_enqueue_styles' );
```

## JavaScript规范

### ES6+标准

使用ES6+语法：

```javascript
// 推荐使用const/let
const header = document.querySelector('.header');
let count = 0;

// 箭头函数
const toggleMenu = () => {
  menu.classList.toggle('is-open');
};

// 模板字符串
const message = `欢迎，${username}`;

// 解构赋值
const { width, height } = dimensions;
```

### 代码组织

- 使用模块化结构
- 避免全局变量污染
- 遵循单一职责原则

```javascript
// 模块化示例
const Navigation = {
  init() {
    this.menuToggle = document.querySelector('.menu-toggle');
    this.menu = document.querySelector('.nav-menu');
    this.bindEvents();
  },
  
  bindEvents() {
    this.menuToggle.addEventListener('click', () => this.toggleMenu());
  },
  
  toggleMenu() {
    this.menu.classList.toggle('is-open');
    this.menuToggle.classList.toggle('is-active');
  }
};

// 初始化
document.addEventListener('DOMContentLoaded', () => {
  Navigation.init();
});
```

### WordPress JavaScript集成

使用WordPress的`wp_enqueue_script()`加载JavaScript，并正确处理依赖：

```php
function mixm_laal_enqueue_scripts() {
  // 加载jQuery（WordPress内置）
  wp_enqueue_script( 'jquery' );
  
  // 加载主题JS，依赖jQuery
  wp_enqueue_script( 
    'mixm-laal-script', 
    get_template_directory_uri() . '/js/main.js', 
    array( 'jquery' ), 
    '1.0.0', 
    true // 在footer中加载
  );
  
  // 传递数据到JavaScript
  wp_localize_script( 
    'mixm-laal-script', 
    'mixmLaal', 
    array( 
      'ajax_url' => admin_url( 'admin-ajax.php' ),
      'nonce' => wp_create_nonce( 'mixm-laal-nonce' )
    ) 
  );
}
add_action( 'wp_enqueue_scripts', 'mixm_laal_enqueue_scripts' );
```

## 响应式设计实现

### 媒体查询

使用移动优先的响应式设计方法：

```css
/* 移动设备默认样式 */
.container {
  width: 100%;
  padding: 0 15px;
}

/* 平板设备 */
@media (min-width: 768px) {
  .container {
    max-width: 720px;
    margin: 0 auto;
  }
}

/* 桌面设备 */
@media (min-width: 1025px) {
  .container {
    max-width: 1000px;
  }
}

/* 大屏设备 */
@media (min-width: 1280px) {
  .container {
    max-width: 1200px;
  }
}
```

### 弹性布局

使用Flexbox和Grid进行布局：

```css
/* Flexbox示例 */
.header__nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

/* Grid示例 */
.posts-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(300px, 1fr));
  gap: 20px;
}
```

## 性能优化

### 图片优化

- 使用适当的图片格式（JPG、PNG、WebP）
- 压缩图片
- 使用响应式图片

```html
<picture>
  <source media="(max-width: 768px)" srcset="small-image.webp" type="image/webp">
  <source media="(max-width: 768px)" srcset="small-image.jpg">
  <source srcset="large-image.webp" type="image/webp">
  <img src="large-image.jpg" alt="描述文字" loading="lazy">
</picture>
```

### 资源加载优化

- 延迟加载非关键资源
- 预加载关键资源
- 最小化CSS和JavaScript

```html
<!-- 预加载字体 -->
<link rel="preload" href="fonts/inter-regular.woff2" as="font" type="font/woff2" crossorigin>

<!-- 延迟加载脚本 -->
<script src="script.js" defer></script>
```

## WordPress模板开发

### 核心模板文件

按照WordPress模板层次结构创建以下文件：

1. `header.php` - 网站头部
2. `footer.php` - 网站底部
3. `index.php` - 首页默认模板
4. `single.php` - 文章详情页
5. `page.php` - 页面模板
6. `archive.php` - 归档页面
7. `search.php` - 搜索结果页
8. `404.php` - 404页面
9. `sidebar.php` - 侧边栏

### 模板标签使用

使用WordPress标准模板标签获取内容：

```php
<!-- 文章标题 -->
<h1 class="entry-title"><?php the_title(); ?></h1>

<!-- 文章内容 -->
<div class="entry-content">
  <?php the_content(); ?>
</div>

<!-- 文章元信息 -->
<div class="entry-meta">
  <span class="author"><?php the_author(); ?></span>
  <span class="date"><?php the_date(); ?></span>
  <span class="categories"><?php the_category(', '); ?></span>
</div>

<!-- 导航菜单 -->
<?php wp_nav_menu( array( 'theme_location' => 'primary' ) ); ?>
```
