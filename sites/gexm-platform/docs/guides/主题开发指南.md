# WordPress主题开发指南

本文档根据项目需求，为`MixM Laal`主题的开发团队提供详细的开发规范和工作流程指南。

## 项目概述

- **项目名称**：MixM Laal WordPress主题
- **项目版本**：当前v1.0.1
- **项目路径**：`/www/wwwroot/api.laal.top/wp-content/themes/mixm-laal/`
- **开发环境**：宝塔Linux面板 + OpenCloudOS 9

## 角色职责与工作流程

### 1. UI/UX设计师

#### 核心职责
1. 输出主题视觉设计稿（首页、文章页、列表页、侧边栏、评论区等）
2. 确定响应式适配规则（移动端/平板/PC端布局差异）
3. 规范设计资产（图标、配色方案、字体文件）

#### 工作流程
1. **设计稿上传**：将设计稿（Figma/Sketch导出的PNG/PSD）上传至服务器`站点目录/design`文件夹
   - 路径：`/www/wwwroot/api.laal.top/design/`
   - 上传方式：宝塔"文件管理"或FTP

2. **设计稿可实现性确认**：与前端工程师同步设计稿可实现性
   - 重点关注复杂动画是否适配Nginx服务器的静态资源加载
   - 考虑响应式设计在不同设备上的兼容性

3. **远程预览**：通过服务器绑定的测试域名直接访问页面，查看前端还原效果
   - 测试域名：`https://api.laal.top`

#### 必备工具
- 设计工具：Figma/Sketch/PS
- 文件传输：宝塔"文件管理"/FileZilla(FTP)
- 预览工具：浏览器

### 2. 前端工程师

#### 核心职责
1. 将设计稿转化为静态HTML/CSS/JS页面
2. 实现响应式布局（适配不同设备）
3. 兼容主流浏览器（Chrome/Safari/Edge/Firefox）

#### 工作流程
1. **静态页面开发**：在本地完成静态页面开发

2. **静态文件上传**：通过FTP将文件（HTML/CSS/JS/图片）上传至服务器
   - 路径：`/www/wwwroot/api.laal.top/static/`

3. **WordPress模板文件转换**：
   - 登录宝塔"文件管理"
   - 进入主题目录：`/www/wwwroot/api.laal.top/wp-content/themes/mixm-laal/`
   - 将静态文件改写为WP模板文件：
     - header.php - 网站头部
     - footer.php - 网站底部
     - single.php - 文章详情页
     - page.php - 页面模板
     - index.php - 首页模板
     - archive.php - 归档页面
     - sidebar.php - 侧边栏
     - comments.php - 评论区

4. **性能优化**：
   - 通过宝塔"站点"→"速度测试"检查加载速度
   - 优化大图片（压缩处理）
   - JS/CSS合并压缩

5. **WordPress集成**：
   - 集成WP模板标签（如调用文章列表`wp_list_posts()`）
   - 在服务器上实时预览效果（刷新测试域名页面）

#### 必备工具
- 开发工具：VS Code（推荐安装"WordPress Snippets"插件）
- 服务器连接：FinalShell/Xshell（远程终端）、FileZilla（FTP）
- 调试工具：浏览器开发者工具（F12）、宝塔"站点日志"

#### 主题结构参考
当前主题已包含以下关键文件：
- style.css - 主题样式文件
- functions.php - 主题功能实现
- header.php - 头部模板
- footer.php - 底部模板
- index.php - 首页模板
- single.php - 文章页模板
- page.php - 页面模板
- sidebar.php - 侧边栏模板
- comments.php - 评论模板
- 各种HTML预览文件（可作为参考）

### 3. WordPress后端工程师

#### 核心职责
1. 开发主题动态功能（自定义字段、侧边栏、主题设置面板）
2. 调用WP API（文章查询、用户权限、评论管理）
3. 确保主题兼容WP最新版本，修复BUG

#### 工作流程
1. **主题文件编辑**：
   - 登录宝塔"文件管理"，直接编辑主题核心文件
   - 或通过远程终端用vim命令编辑
   - 核心文件：functions.php、style.css、page.php等

2. **数据库管理**：
   - 在宝塔"数据库"模块管理WP数据库
   - 新增自定义字段所需的表
   - 定期导出数据库备份

3. **主题设置面板开发**：
   - 通过redux framework等框架配置主题后台
   - 实时测试功能（如自定义LOGO上传是否存储到wp-content/uploads目录）

4. **插件适配**：
   - 在服务器上安装常用插件（如Yoast SEO/Contact Form 7）
   - 测试主题与插件的兼容性

5. **BUG修复与排查**：
   - 通过宝塔"PHP错误日志"（/www/wwwlogs/php_error.log）排查functions.php的语法错误
   - 通过"Nginx日志"排查动态页面500错误

#### 必备工具
- 开发工具：VS Code（远程连接服务器目录）、FinalShell（终端操作）
- WP工具：WordPress Codex（在线文档）、Redux Framework（主题设置框架）
- 数据库工具：宝塔"phpMyAdmin"（管理MySQL）
- 日志排查：宝塔"日志"模块

## 开发规范

### 文件命名规范
- 使用小写字母和连字符(-)，不使用下划线(_)或驼峰命名
- 模板文件使用WordPress标准命名（如single.php、page.php）
- 静态资源按功能模块分类存放

### 代码规范
- 遵循WordPress Coding Standards
- PHP代码使用PSR-2规范
- CSS代码使用BEM命名规范
- JavaScript代码使用ES6+标准
- 添加适当的注释说明

### 协作规则
- 文件权限：主题目录权限为755，文件权限为644
- 代码同步：使用Git+远程仓库（如Gitee/GitHub）进行版本控制
- 变更记录：重要更改需在README.md中记录

## 测试与部署

### 测试流程
1. 功能测试：确保所有主题功能正常工作
2. 响应式测试：在不同设备上测试页面显示
3. 浏览器兼容性测试：测试主流浏览器
4. 性能测试：检查页面加载速度和资源占用

### 部署流程
1. 测试环境验证无误后，进行最终部署
2. 更新主题版本号
3. 备份当前主题文件
4. 上传新主题文件
5. 清除缓存并刷新网站
