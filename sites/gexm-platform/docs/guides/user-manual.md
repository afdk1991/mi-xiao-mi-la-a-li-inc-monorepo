# Gexm 应用用户操作手册

## 1. 概述

### 1.1 应用简介

Gexm 是一款基于 HarmonyOS 的全平台电商应用，支持手机、平板等多种设备形态，提供商品浏览、购物车、订单管理、支付等完整的电商购物体验。

### 1.2 主要功能

- **商品浏览**：浏览推荐商品、分类商品，支持搜索功能
- **购物车**：添加商品、管理商品数量、删除商品
- **订单管理**：创建订单、查看订单、取消订单
- **地址管理**：添加、编辑、删除收货地址
- **优惠券**：领取和使用优惠券
- **支付功能**：支持微信支付、支付宝支付
- **个人中心**：查看和修改个人信息

### 1.3 系统要求

| 设备类型 | 最低版本要求 |
|----------|--------------|
| HarmonyOS 手机 | HarmonyOS 4.0+ |
| HarmonyOS 平板 | HarmonyOS 4.0+ |
| 微信小程序 | 微信 8.0+ |
| H5 浏览器 | Chrome 120+、Safari 17+、Firefox 120+ |

## 3. 功能使用指南

### 3.1 首页

首页是应用的主入口，包含以下内容：

1. **顶部导航**：显示应用名称和搜索按钮
2. **轮播图**：展示促销活动和热门商品
3. **分类导航**：快速访问商品分类
4. **推荐商品**：根据用户偏好推荐商品

**操作说明**：
- 点击搜索按钮：进入搜索页面
- 点击轮播图：查看活动详情或商品详情
- 点击分类图标：进入对应分类商品列表
- 点击商品卡片：进入商品详情页面

### 3.2 商品搜索

**搜索商品**：
1. 点击首页搜索按钮或底部导航"搜索"
2. 在搜索框输入关键词
3. 点击搜索按钮或回车
4. 查看搜索结果

**筛选条件**：
- 分类筛选：选择商品分类
- 排序方式：综合排序、价格排序、销量排序
- 价格区间：设置价格范围

### 3.3 商品详情

商品详情页展示商品的详细信息：

1. **商品图片**：展示商品主图和详情图
2. **商品信息**：名称、价格、销量、评分
3. **SKU 选择**：选择商品规格（颜色、尺码等）
4. **商品描述**：商品详细介绍
5. **用户评价**：查看其他用户的评价

**操作说明**：
- 点击"加入购物车"：将商品添加到购物车
- 点击"立即购买"：直接下单购买
- 点击收藏按钮：收藏该商品
- 点击分享按钮：分享商品给好友

### 3.4 购物车

购物车管理用户添加的商品：

1. **商品列表**：显示已添加的商品
2. **数量调整**：调整商品购买数量
3. **商品删除**：删除不需要的商品
4. **全选/取消全选**：批量选择商品
5. **商品价格**：显示商品单价和总价

**操作说明**：
- 点击商品数量：调整购买数量
- 点击删除按钮：删除该商品
- 点击全选按钮：选择所有商品
- 点击"结算"按钮：进入订单确认页面

### 3.5 订单管理

#### 3.5.1 创建订单

1. 在购物车点击"结算"
2. 选择收货地址（如需添加新地址，点击"添加地址"）
3. 选择优惠券（如有可用优惠券）
4. 确认订单信息（商品、数量、价格）
5. 选择支付方式（微信支付/支付宝）
6. 点击"提交订单"

#### 3.5.2 订单状态

| 状态 | 说明 |
|------|------|
| 待付款 | 订单已创建，等待付款 |
| 已付款 | 付款成功，等待发货 |
| 已发货 | 商家已发货，等待收货 |
| 已完成 | 用户已确认收货 |
| 已取消 | 订单已取消 |

#### 3.5.3 订单操作

- **待付款订单**：可以付款或取消订单
- **已付款订单**：可以查看物流信息
- **已发货订单**：可以确认收货
- **已完成订单**：可以申请售后

### 3.6 地址管理

#### 3.6.1 添加地址

1. 在个人中心点击"收货地址"
2. 点击"添加地址"
3. 填写地址信息：
   - 收货人姓名
   - 手机号码
   - 省/市/区
   - 详细地址
4. 可选：设置为默认地址
5. 点击"保存"

#### 3.6.2 管理地址

- **编辑地址**：点击地址进入编辑页面
- **删除地址**：在地址列表滑动删除
- **设置默认地址**：点击默认地址开关

### 3.7 优惠券

#### 3.7.1 领取优惠券

1. 在个人中心点击"优惠券"
2. 浏览可用优惠券
3. 点击"领取"按钮领取优惠券

#### 3.7.2 使用优惠券

1. 在结算页面选择优惠券
2. 系统自动计算优惠后的价格
3. 提交订单即可使用

### 3.8 支付功能

#### 3.8.1 微信支付

1. 在订单页面点击"去付款"
2. 选择"微信支付"
3. 跳转到微信支付页面
4. 完成支付

#### 3.8.2 支付宝支付

1. 在订单页面点击"去付款"
2. 选择"支付宝"
3. 跳转到支付宝支付页面
4. 完成支付

### 3.9 个人中心

个人中心包含以下功能：

1. **用户信息**：头像、昵称、等级、积分
2. **订单管理**：查看所有订单
3. **收货地址**：管理收货地址
4. **优惠券**：查看和领取优惠券
5. **我的收藏**：查看收藏的商品
6. **通知中心**：查看系统通知
7. **设置**：修改个人信息、退出登录等

## 4. 常见问题

### 4.1 登录问题

**Q: 忘记密码怎么办？**

A: 在登录页面点击"忘记密码"，按照提示重置密码。

**Q: 登录失败怎么办？**

A: 请检查网络连接，确认用户名和密码是否正确。

### 4.2 购物车问题

**Q: 购物车商品不见了？**

A: 购物车商品会在登录状态下同步，切换账号可能导致商品消失。

**Q: 无法添加商品到购物车？**

A: 请检查商品库存是否充足，或尝试重新登录。

### 4.3 订单问题

**Q: 订单创建失败？**

A: 请检查收货地址是否填写完整，商品库存是否充足。

**Q: 如何取消订单？**

A: 在订单详情页面，待付款订单可以直接取消。

**Q: 如何退款？**

A: 在订单详情页面，已付款未发货订单可以申请退款。

### 4.4 支付问题

**Q: 支付失败怎么办？**

A: 请检查支付账户余额是否充足，网络是否稳定，或更换支付方式。

**Q: 支付成功但订单显示待付款？**

A: 可能是网络延迟，请稍等片刻后刷新页面。

### 4.5 权限问题

**Q: 无法访问相机/相册？**

A: 在手机设置中找到 Gexm 应用，开启相机/相册权限。

**Q: 无法获取位置信息？**

A: 在手机设置中找到 Gexm 应用，开启定位权限。
