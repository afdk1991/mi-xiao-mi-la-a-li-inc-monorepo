> 生成时间:2026-07-21

> 用户要求:不需要备份和测试等等,解决各类存在的问题

## 一、执行摘要

经 3 个并行智能体分析,根目录现有 **200+ 个文件/文件夹**,混杂了:
- 25 个临时调试脚本(JS/PHP/BAT/PS1/log/tmp)
- 19 个截图与二进制文件(PNG/JPG/DOC/TAR.GZ)
- 67+ 个根目录 MD 文档(报告/计划/规范,部分重复)
- 8 个历史遗留/测试目录(_legacy_root, _responsive_test, responsive-test, preview, screenshots, test-results, .snapshots, documentation)
- 7 个服务器配置冗余目录(Apache, IIS, Haproxy, Nginx, Tomcat8_4, Tomcat8_5+, PEM_Privatekey)— 全部是 `certs/` 的子集副本
- 1 个备份目录(backups/,19 个文件)— 用户明确说不需要

**清理目标**:根目录从 200+ 条目精简到 ~30 条目,MD 文档从 85 份精简到 10 份。

## 五、风险评估与回滚方案

### 5.1 低风险操作

- 删除临时调试脚本(25 个):无业务影响,功能已由 lint-guarded.js 等替代
- 删除重复 MD(3 份):已验证前 50 行完全相同
- 删除 backups/(用户明确授权)
- 删除 7 个服务器配置冗余目录(原版在 certs/)

### 5.2 中风险操作

- 删除 `dist/`(构建产物):需确认构建命令可重新生成
- 归档 `_legacy_root/`:含旧版主题 PHP/JS,删除前需确认 wp-content/themes/mixm-laal/ 未引用
- 归档 `documentation/`:与 docs/ 重复,需逐项比对

### 5.3 回滚方案

1. 所有归档操作均移到 `_archive/`(不直接删除),可随时恢复
2. 直接删除的文件(临时脚本、重复 MD、backups/、dist/、7 个冗余目录)需从 git 历史恢复
3. 建议执行前先 `git status` 确认工作区干净,执行后 `git add -A && git commit -m "chore: cleanup project root structure"`

## 七、关键提醒

1. **`enable-debug.php` 已修改 wp-config.php 启用 WP_DEBUG**:生产环境需确认是否已还原为 `false`,否则会暴露敏感错误信息
