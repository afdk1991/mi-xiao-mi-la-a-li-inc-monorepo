WordPress 静态站点

注意事项：

这是一个WordPress网站的静态版本，适用于部署到Tencent EdgeOne Pages等静态托管平台。

要完成部署，您需要：

  1. 使用WordPress插件（如Simply Static或WP2Static）将动态内容转换为静态HTML
  2. 将生成的静态文件上传到Tencent EdgeOne Pages
  3. 配置自定义域名（如需）

Tencent EdgeOne Pages 部署指南

根据您的需求，以下是部署到Tencent EdgeOne Pages的基本步骤：

1. 准备静态文件

使用WordPress静态化插件将您的整个网站转换为静态HTML文件。推荐使用：

  • Simply Static
  • WP2Static
  • StaticPress

2. 注册Tencent EdgeOne Pages账号

访问 Tencent EdgeOne Pages官网 注册账号。

3. 创建项目并部署

有三种部署方式：

  1. 导入Git仓库：将静态导出后的代码提交到GitHub仓库，然后从EdgeOne Pages导入
  2. 直接上传：将静态导出的文件直接上传到EdgeOne Pages
  3. 从模板开始：选择适合的模板快速创建

4. 访问您的站点

部署完成后，EdgeOne Pages会提供一个临时域名供您访问站点。

5. 配置自定义域名（可选）

如果您有自己的域名，可以在EdgeOne Pages控制台中配置自定义域名。

WordPress项目结构

当前WordPress项目包含以下主要目录和文件：

wp-admin/        # WordPress管理后台
wp-content/      # 主题、插件和上传文件
wp-includes/     # WordPress核心文件
index.php        # 网站入口文件
wp-config-sample.php # 数据库配置示例
