# 隐私政策

**生效日期**：2026-10-01
**适用产品**：配送定位与路径优化系统（Web 版、Windows 桌面版、Android 版）

> 本政策说明本应用收集哪些信息、如何使用与存储、以及你对这些信息拥有的控制权。
> 核心原则：**数据优先保存在你自己的设备上，不上传我们的服务器；位置信息属于敏感个人信息，仅在你需要时、经你同意后才采集。**

---

## 一、我们收集的信息

### 1. 位置信息（敏感个人信息，仅在你主动开启时采集）

当你点击「实时位置」或「开始导航」时，我们会通过设备的定位能力（GPS / 网络定位）获取你的实时坐标，用于：

- 在地图上显示你的当前位置；
- 实时导航的偏航判定、转向播报与剩余里程计算；
- 「以我的位置为中心搜索附近商户」。

**特点**：

- **默认关闭**：不点击开启就不会采集；
- **可随时关闭**：关闭后应用立即停止定位，不再获取新坐标；
- **不上传**：位置数据仅在本机用于计算与显示，不会发送到我们的服务器（本应用无自有服务端账号体系）。

### 2. 你录入的业务数据

为完成配送管理，你会录入或导入客户信息（如姓名/称呼、联系电话、配送地址、备注）。

- **存储位置**：保存在你设备的本地数据库（浏览器 IndexedDB / 应用本地存储）中；
- **用途**：仅用于地址解析、路线排序、地图打点、导出配送单；
- **默认不上传**：除非你主动使用「云同步」（见第三节），否则不会离开你的设备，也不用于任何分析或商业用途。

### 3. 设备与日志信息

我们**不采集**设备标识符（IMEI / MAC / OAID）、**不做**用户画像、**不嵌入**第三方统计或广告 SDK。

应用仅在你的设备本地保存必要的偏好设置（如地图服务选择、路线策略、是否已阅读本政策），存储于浏览器/应用本地存储中。

## 二、我们向第三方发送的数据

为实现地址解析与路径规划，应用在**你主动发起相关操作**时，会向以下服务商发送数据：

| 服务方 | 用途 | 发送的数据 |
|---|---|---|
| 高德地图 | 地理编码、路径规划、POI 搜索 | 地址文本、起终点坐标 |
| 腾讯位置服务 | 同上 | 同上 |
| 百度地图 | 同上 | 同上 |
| Photon（komoot，OpenStreetMap 生态） | 免 Key 时的地址解析与 POI 搜索 | 地址文本、坐标 |
| OSRM（OpenStreetMap 生态） | 免 Key 时的路径规划 | 起终点坐标 |
| OpenStreetMap | 地图底图瓦片 | 地图视野范围（由地图控件发起） |

**重要说明**：

- 发送给上述服务的内容**仅为地址文本与坐标**，**不含**客户姓名、电话等身份信息；
- 若你在「设置」中填写了自己的地图服务密钥（Key），请求将由你的浏览器/应用直接发往对应服务商，适用该服务商的隐私政策；
- 若未填写密钥，应用将自动使用 OpenStreetMap 生态的公开服务（Photon / OSRM）。

## 三、云同步（可选功能，默认不使用）

「备份 → 云同步」提供跨设备搬运数据的能力，**完全由你主动触发**：

- **工作方式**：你设置一个「同步码」（6-16 位字母数字），点击「上传」时，当前备份（客户信息、配送起点、轨迹记录）会以该同步码为键，加密传输（HTTPS）后存放在腾讯云 EdgeOne 边缘 KV 存储中；在另一台设备输入同一同步码即可「恢复」。
- **同步码即密钥**：我们不做账号体系，任何拿到同步码的人都能读取该数据。请自行妥善保管，勿使用简单码，也不要分享给无关人员。
- **数据边界**：上传内容**不含**任何地图服务密钥；你可在应用内随时「删除云端」数据。
- **不使用即无影响**：若你从不点击「上传」，业务数据始终只在本机。
- **开通前提**：该功能依赖 EdgeOne KV 存储；未开通时应用会明确提示「云同步未开通」，其余功能不受影响。

## 四、Android 权限说明

Android 版本申请以下权限，用途如下：

| 权限 | 用途 | 是否必需 |
|---|---|---|
| `INTERNET` | 加载地图瓦片、调用地理编码与路径规划服务 | 必需 |
| `ACCESS_FINE_LOCATION` | 实时导航所需的米级精度定位 | 仅导航/实时位置功能需要 |
| `ACCESS_COARSE_LOCATION` | 附近商户搜索、粗略定位 | 仅相关功能需要 |

你可以在系统设置中随时撤销定位授权；撤销后应用仍可正常使用地址管理与路线规划（不含实时定位与导航）。

iOS 版本对应使用「使用应用期间」定位权限（`NSLocationWhenInUseUsageDescription`），用途与上述一致。

## 五、信息存储与安全

- **本地优先**：业务数据与偏好设置均保存在你的设备本地；
- **无账号体系**：本应用不提供云端账号，也不做用户画像；仅在你主动使用「云同步」时，业务数据才会存放于腾讯云 EdgeOne 边缘 KV（境内节点），详见第三节；
- **导出可控**：你可以随时导出为 Excel（CSV）或打印配送单，导出文件由你自己保管；
- **清除方式**：清除浏览器数据（Web）、卸载应用（桌面/移动端）即可删除全部本地数据；应用内也提供清空数据的能力。

请你妥善保管导出的文件与设备访问权限，避免他人接触你的客户信息。

## 六、你的权利

你拥有以下控制权，均可在应用内直接操作：

1. **开启/关闭定位**：随时开启或停止实时位置跟踪；
2. **查看与编辑数据**：查看、修改、删除已录入的客户地址；
3. **导出与删除**：导出全部数据，或清空本地数据；
4. **撤销系统授权**：在系统设置中撤销定位权限；
5. **拒绝提供**：不录入客户信息、不开启定位，应用的基础地址管理功能仍可使用。
