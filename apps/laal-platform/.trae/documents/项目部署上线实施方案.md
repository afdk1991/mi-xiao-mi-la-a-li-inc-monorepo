# Mi-Xiao-Mi-La-A-Li-Inc 完整部署上线实施方案

## Context

项目 `D:\网站全栈项目\项目01\Mi-Xiao-Mi-La-A-Li-Inc` 是一个微服务全栈平台,包含6个前端应用、7个后端微服务、9个卫星产品。之前已删除所有Docker配置,用户明确不使用Docker,要求用项目现有的部署方式(PM2、EdgeOne、IGA Pages、WordPress+LAMP、GitHub Actions、本地脚本、Capacitor)实现全部项目部署上线。域名、SSL、API地址后续配置,当前先把所有服务跑起来。

## 环境现状(实测)

**已安装**: Node.js v24.18.1, npm 11.16.0, PHP 8.1.34, IGA CLI 1.1.2
**未安装(需安装)**: PM2, Nginx, pnpm, Java JDK 21, Maven, Composer, MySQL, PostgreSQL

## 部署架构

```
外部用户 → Nginx(80/443) → 前端静态站点 + API反代 + PHP-FPM
                              ↓
        ┌─────────────────────┼─────────────────────┐
        ↓                     ↓                     ↓
   PM2 Node.js集群       PHP-FPM进程          Java JVM
   mixmlaal-backend:3001  wordpress-saas:8088   java-springcloud:8080
   ai-saas-backend:3004   daijia:8089           (H2内存数据库)
   unified-gateway:8000   gexm:8090
   node-nest-gateway:3002
   routenav:5000
   enterprise-admin:3000
   zhinenglux:3003
        ↓
   SQLite文件 / MySQL(WordPress) / PostgreSQL(RouteNav/enterprise-admin)
```

## 实施步骤

### 阶段0:环境准备

安装缺失工具(PowerShell管理员执行):
```powershell
npm install -g pm2 pnpm
winget install nginx.nginx
winget install Microsoft.OpenJDK.21
winget install Apache.Maven
winget install Composer.Composer
winget install Oracle.MySQL
winget install PostgreSQL.PostgreSQL.15
```

验证: `node -v; pm2 -v; nginx -v; php -v; java -version; mvn -v; composer -V; mysql --version`

### 阶段1:创建配置文件(核心交付物)

**1.1 PM2配置** — `D:\网站全栈项目\项目01\Mi-Xiao-Mi-La-A-Li-Inc\ecosystem.config.cjs`

管理所有Node.js服务:
- mixmlaal-backend (cwd: 02-后端微服务集群/mixmlaal-backend, script: dist/server.js, PORT:3001, SQLite)
- ai-saas-backend (script: src/app.js, PORT:3004)
- unified-api-gateway (script: src/app.js, PORT:8000)
- node-nest-gateway (script: dist/main.js, PORT:3002)
- java-springcloud (interpreter: java, script: target/ecommerce-app-1.0.0.jar)
- routenav-server (cwd: 08-卫星产品/RouteNav/server, script: dist/index.js, PORT:5000)
- enterprise-admin-server (cwd: 08-卫星产品/enterprise-admin-platform/server, script: dist/server.js, PORT:3000)
- zhinenglux-server (cwd: 08-卫星产品/zhinenglux/server, script: dist/main.js, PORT:3003)
- php-fpm (script: php-cgi, args: -b 127.0.0.1:9000)

日志统一到 `D:/网站全栈项目/项目01/Mi-Xiao-Mi-La-A-Li-Inc/logs/`

参考模板: [ecosystem.config.js](file:///D:/网站全栈项目/项目01/Mi-Xiao-Mi-La-A-Li-Inc/08-卫星产品/gexm/packages/mixmlaal/mixmlaal-apps/mixmlaal-api-node/ecosystem.config.js)

**1.2 Nginx配置** — `C:\nginx\conf\nginx.conf` 或 `conf.d\mixmlaal.conf`

server块配置:
- 主站(web-vue-pc): listen 80, root → web-vue-pc/dist, /api/ → proxy_pass 127.0.0.1:3001
- ai-saas: listen 80, server_name ai-saas.local, root → ai-saas-frontend/dist, /api/ → 3004
- page-builder: root → page-builder-frontend/dist
- web-h5-mobile: root → web-h5-mobile/dist
- enterprise-admin: root → enterprise-admin-platform/client/dist, /api/ → 3000
- wordpress-saas: listen 8088, PHP-FPM 127.0.0.1:9000, root → wordpress-saas
- gexm: listen 8090, PHP-FPM, root → gexm
- daijia: listen 8089, PHP-FPM, root → daijia

参考: [enterprise-admin.conf](file:///D:/网站全栈项目/项目01/Mi-Xiao-Mi-La-A-Li-Inc/08-卫星产品/enterprise-admin-platform/nginx/enterprise-admin.conf)

**1.3 部署脚本** — `D:\网站全栈项目\项目01\Mi-Xiao-Mi-La-A-Li-Inc\deploy\deploy-all.ps1`

参数化脚本,支持 -Phase 1|2|3|4|all, -Build, -Start, -CheckOnly:
- 阶段1: 构建并启动核心服务(mixmlaal-backend + web-vue-pc)
- 阶段2: 构建其他前端(ai-saas/page-builder/web-h5-mobile),EdgeOne/IGA部署
- 阶段3: 后端微服务(ai-saas-backend/unified-gateway/node-nest-gateway/java-springcloud)
- 阶段4: 卫星产品(RouteNav/enterprise-admin/zhinenglux/WordPress/gexm/daijia)

辅助脚本:
- `deploy\stop-all.ps1` — 停止所有PM2服务
- `deploy\status.ps1` — 检查端口监听和API健康

**1.4 修改前端API地址** — [api.ts](file:///D:/网站全栈项目/项目01/Mi-Xiao-Mi-La-A-Li-Inc/01-前端集群/web-vue-pc/src/services/api.ts)

第10行: `const API_BASE_URL = 'http://localhost:3001/api'` → `'/api'`(由Nginx反代)

## 注意事项

1. **better-sqlite3原生编译**: Node.js v24较新,可能需 `npm install -g node-gyp` + VS Build Tools
2. **PM2 Windows持久化**: `npm install -g pm2-windows-startup` + `pm2-startup install` 实现开机自启
3. **PHP扩展**: 确保php.ini启用 mysqli、pdo_mysql、gd、curl(WordPress必需)
4. **Java H2**: springcloud默认用H2内存数据库,重启丢数据,后续可改MySQL profile
5. **mixmlaal-microservices**: 不完整(仅user/order-service),依赖Consul+PostgreSQL,标记待确认不部署
6. **portal**: 仅有dev脚本无build,跳过生产部署
7. **unified-api-gateway**: 60+代理目标大部分不存在,需修改app.js仅保留3001/3002/3004
