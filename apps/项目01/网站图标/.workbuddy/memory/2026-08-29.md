### 实现要点

- **后端实时接入（两套真实 API）**：
  - `/api/platform`（nginx 新增 `location = /api/platform` → node-api 根路由）→ 34 行业模块，能力矩阵网格
  - `/api/modules` → 8 功能模块（id/name/path/status），卡片带「已上线/开发中」徽章
  - 均 6s 超时 + 内置清单降级，页面永不全空。
- **部署**：`mixm-nginx`（nginx:1.27-alpine，restart=unless-stopped）挂载 `sites\mixm.top\public` 只读 + `nginx\mixm.local.conf`（覆盖镜像默认 conf）。`/api/` 与 `/api/platform` 经 extra_hosts host-gateway 反代宿主 node-api:3001。
- **端口事实**：node-api 容器内部监听 **3001**（8000 不监听）——实测 netstat+wget 确认，修正了设计资产里生产 conf 的 `node-api:8000` 缺陷。

### 关键经验
- PowerShell 调 wsl+docker 多层引号必炸 → 一律 .sh 脚本文件 + `sed -i 's/\r$//'` 再执行。
- **两个不同目录的 docker-compose 若默认项目名相同（都是 deploy），容器会被混淆** → 顶层加唯一 `name:`。
- PowerShell `Copy-Item 源目录 目标已存在目录` 会嵌套成 `目标\源目录名\...` → 需确认层级。
- **WSL DrvFs 与 Windows 侧对 /mnt/d 的删除/复制在极端情况下元数据不一致** → 关键操作后双侧（Get-ChildItem + find）核对。
- nginx 反代保留前缀 = `proxy_pass http://host:port;`（无尾斜杠）；改写根 = 带尾斜杠。
- 静态站点根 `/` 命中 SPA 文件，后端数据必须走独立 `/api/*` 路径。
- PowerShell 控制台对 UTF-8 中文匹配不可靠（-match 返回 False），验证中文内容用 Grep/Read 或字节级处理。
