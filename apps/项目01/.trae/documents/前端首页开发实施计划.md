# 前端首页开发实施计划（zibstyle 主题）

## 背景与目标

四组件系统已完成端到端验证，演示数据已清空。现按需求规格完成**前端网站首页**的正式开发：

- 视觉风格：**沿用现有 zibll 仿站风格**（不推翻配色与布局语言），在此基础上补齐现代 UI/UX 细节
- 导航：改为 **WP 菜单驱动**（主导航 `primary` + 次级导航顶部工具条），后台可视化可管理
- 板块：**完整版**——Hero、搜索、商品展示、站点实时数据、最新文章、CTA 行动区、完整页脚；所有数据板块设计**优雅空状态**（当前文章/商品/订单为 0）
- 图片：**AI 生成配图**（文生图 API 下载到主题 assets/img/，本地引用，零运行时外链）
- 响应式三档：桌面 ≥1200px / 平板 768–1199px / 移动 ≤767px；全中文；首屏 ≤3s

## 关键文件

| 文件 | 动作 |
|---|---|
| `wp-content/themes/zibstyle/header.php` | 重构：顶部工具条（次级导航）+ wp_nav_menu 主导航 + 移动端抽屉 |
| `wp-content/themes/zibstyle/footer.php` | 完善：快速链接（wp_nav_menu）+ 版权（动态年份）+ 联系方式（QQ/微信/邮箱） |
| `wp-content/themes/zibstyle/front-page.php` | 重构各板块 + 空状态分支 |
| `wp-content/themes/zibstyle/functions.php` | 默认菜单自动创建、菜单回退回调、图片尺寸注册、hero 图预加载 |
| `wp-content/themes/zibstyle/assets/css/home.css` | 新增：空状态、次级导航、CTA、三档响应式样式（沿用 zibll 风格变量） |
| `wp-content/themes/zibstyle/assets/img/` | 新增：AI 生成配图（hero 插画、空状态插画、CTA 背景、栏目默认图） |
| `wp-content/themes/zibstyle/template-parts/` | 新增：`empty-state.php` 复用空状态组件 |

现有复用项：`home-stats.css/js`（实时数据板块，保持不动）、`template-parts/article-card-grid.php`（文章卡片）、`SAAS_Console_Cache`、匿名页面 Nginx 微缓存（60s）。

## 实施步骤

1. **AI 配图生成与落盘**（先行，供后续引用）
   - 通过 `https://trae-api-cn.mchost.guru/api/idea/v1/text_to_image?prompt={urlencoded}&image_size={size}` 生成：
     - Hero 主插画（科技服务平台，landscape_16_9）
     - 空状态插画（简洁线性风，square）
     - CTA 背景横幅（landscape_16_9）
   - curl 下载至 `assets/img/`，文件名语义化（hero.svg.png 等）；单图下载失败则该位置回退 CSS 渐变，不阻塞

2. **导航菜单系统**（functions.php + header.php）
   - functions.php：一次性自动创建默认主导航（首页/商城/文章中心/关于我们/联系我们）与页脚菜单，写入 option 标记防重复
   - header.php：次级导航（顶部工具条：欢迎语、登录/注册、用户中心、后台入口）+ `wp_nav_menu(primary)` + 移动端汉堡抽屉；`wp_nav_menu` 回退回调保证无菜单时不空白

3. **首页板块重构**（front-page.php，保持仿站风骨架）
   - Hero：保留文案结构，主视觉换 AI 配图 + `fetchpriority=high` 预加载
   - 搜索板块：保留（硬编码表单），补热词快捷标签
   - 商品展示：`WP_Query(post_type=product)` 图文卡片栅格；空数据显示空状态插画 + "商城暂未上架商品"引导
   - 站点实时数据：沿用 home-stats 不动
   - 最新文章：`WP_Query(post)` + article-card-grid；空状态 + "发布第一篇文章"引导链接
   - CTA 行动区：注册引导 + 联系我们，AI 配图背景
   - 分类入口：无文章分类时整块隐藏

4. **空状态组件**（template-parts/empty-state.php）
   - 参数：插画、标题、描述、按钮（文字+链接）；各数据板块复用

5. **页脚完善**（footer.php）
   - 三列：关于本站+联系方式（QQ/微信/邮箱）、快速链接（wp_nav_menu footer）、友情链接
   - 底部：© 年份动态 + 中文版权 + 备案占位

6. **响应式与性能**
   - home.css 三档断点：≤767 单列/汉堡菜单、768–1199 双列栅格、≥1200 三列满宽容器
   - 图片统一 `loading=lazy`（hero 除外）+ 显式宽高防 CLS
   - 验证首屏：冷缓存 ≤3s、热缓存命中（Nginx 60s 微缓存）

## 验证方案

1. `docker compose restart`（无需，PHP 卷挂载即时生效）；清 Nginx 页面缓存后 curl 首页确认 200
2. curl 计时：冷/热首屏耗时 ≤3s
3. 浏览器自动化三档视口（1366×768 / 900×1100 / 375×800）截图检查：导航、板块布局、空状态、页脚、中文呈现、汉堡菜单交互
4. 后台确认：外观→菜单 可视化管理生效；发布 1 篇测试文章验证数据板块从空状态切换为真实卡片（验证后删除）
