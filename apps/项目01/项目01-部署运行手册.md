## 二、四套机制取舍建议

1. **静态前端 → EdgeOne Pages**：已验证可用，后续前端构建后 `npx edgeone pages deploy <dist>` 即可。
2. **后端 → 自托管 PM2 + python-fastapi（推荐）**：废弃 Node 版 `mixmlaal-backend` 重复进程。
3. **Render**：当前 `render.yaml` 缺 `buildCommand`/`startCommand` 且根无 `package.json`，**不可用**；如需保留，按第四节补正。
4. **Docker**：仓库内未发现 `Dockerfile`，`start-docker.sh` 按容器内 `/app` 编排，需补 Dockerfile 且沙箱 Docker 离线，暂不可行。

## 三、生产机执行清单（自托管）

```bash
# 1) 恢复 PM2 进程（已 pm2 save 的前提下）
pm2 resurrect
# 或显式启动（确认 ROOT 指向正确盘符后）
pm2 start ecosystem.config.cjs --env production

# 2) 启动 Nginx（端口见 nginx-mixmlaal.conf，当前主站 8080）
nginx -c "F:/网站全栈项目/项目01/Mi-Xiao-Mi-La-A-Li-Inc/deploy/nginx.conf"

# 3) 健康检查
curl http://localhost:8080/
curl http://localhost:3001/api/health   # 若后端归口到 python-fastapi，则改为 :8000

# 4) SSL（laal.top 已用 Let's Encrypt，crontab 自动续期）
# 确认 certbot 续期任务存在：crontab -l | grep certbot
```

⚠️ **后端归口决策未定前，请勿直接 pm2 start**：当前 ecosystem 拉起的是 Node 版，与 `python-fastapi` 可能不一致。

## 四、render.yaml 补正示例（如需保留 Render）

```yaml
services:
  - type: web
    name: mi-xiao-backend
    env: python
    buildCommand: pip install -r python-fastapi/requirements.txt
    startCommand: uvicorn app.main:app --host 0.0.0.0 --port 8000
    healthCheckPath: /api/health
    envVars:
      - key: JWT_SECRET
        generateValue: true
```
> 注：以上将 Render 指向 `python-fastapi`，需确保 `python-fastapi/` 为仓库根可识别路径，并与 Nginx 代理端口对齐。
