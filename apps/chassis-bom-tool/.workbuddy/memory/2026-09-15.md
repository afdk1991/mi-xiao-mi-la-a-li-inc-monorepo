### 项目真实内容
- 这是「三层卧式模块化机箱」工业设计交付包项目，非软件工程项目。
- 产出方式：4 个 Python 脚本用 pylibs 内的 reportlab / openpyxl 生成 PDF + XLSX。
- pylibs/ 是便携式依赖目录（PIL、openpyxl、pymupdf/fitz、reportlab），非业务代码。

### 两代脚本（v1 已被 v2 覆盖）
- `generate_bom.py` / `generate_pdfs.py` = **V1 大尺寸版**（450×360×400，12盘位+双30×30主板+双ATX冗余，成本 2700~3770 元）
- `generate_bom_v2.py` / `generate_pdfs_v2.py` = **V2 紧凑型**（200×350×350，2×3.5"+2×2.5"+ITX单板+单ATX，成本 1400~2020 元）
- ⚠️ 两代脚本写入**完全相同的输出路径**，V2 运行后已覆盖 V1 产物。交付包内现有 PDF/XLSX 已全部核验为 V2（副标题 V2.0 / 200×350×350）。V1 产物已丢失，仅存源码。

### 发现的 4 个问题（已向用户报告，待确认是否修复）
1. **成本数据自相矛盾**：xlsx 逐项累加 = 1394.4 元 + 表面处理 180~320 → 合计 1574~1714 元；但同表"成本对比汇总"页与 4 份 PDF 均写 1400~1540 元，差 174.4 元。汇总页的分类数字（通用件320/功能模块620/接口电气280）是手写估算，与明细表（371.2 / 765.2 / 258）不符。
2. **9 张".png"实为 JPEG**（magic = ffd8），扩展名错误，部分排版/印刷软件会报错。
3. **渲染图与设计文档形态冲突**：03_量产版整机外观图 等图片呈立式+侧透+RGB 电竞风，而文档定义的是"三层卧式"内藏式抽屉结构 + 全金属标准版为哑光黑喷塑。图片为 AI 生成渲染图，非工程渲染。
4. **v1/v2 输出路径未隔离**，导致版本覆盖；`Database1.accdb` 为空库（仅系统表 MSysACEs 等，无业务表）；`新建 Microsoft Word 文档.docx` 为 0 字节空文件。
