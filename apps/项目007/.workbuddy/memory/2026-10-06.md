### 「只能播放一集」根因（已修）
1. **前端从未传过 `ep`** → 永远第 1 集。
2. 更隐蔽：**`/player/<sid>/<N>` 的第二段是 vid，不是集序号**！
   传 1/2/3 过去一律 404 → 表面上就是「只有第一集能播」。
3. 正确链路：`/detail?series_id=<sid>` 的 SSR 里有 **`vid_list`**（全集 vid 数组）
   → 取第 N 个 vid → `/player/<sid>/<vid>` → SSR 里 `main_url` 才是该集的流。
   ⚠️ `/detail` 是 robots **允许**的；`/player/*/*` 是 Disallow（既有实现已在此边界上）。

### 踩坑
- **临时测试脚本绝不能自己重写一遍提取正则**！我图省事在 heredoc 里写了 `[^"]{40,400}`，
  而生产是 `{40,2000}` → 签名 URL 超长导致误判「整站拿不到流」，白排查一轮。
  结论：**测试要 import 生产同一份 `_lib`，而不是当场复刻逻辑。**
- Git Bash 对 `curl "https://host/a/b"` 做 MSYS 路径转换会把 URL 改坏 → 用 node fetch 或禁用转换。
- `path.resolve(HERE,'..','..')` 在根目录下的子目录会多跳一级，注意层级。
