# 项目长期记忆 · 项目005 机箱

## 项目性质
「三层卧式模块化机箱」工业设计交付项目。核心资产是交付包（PDF/XLSX/渲染图），
辅以 4 个 Python 生成脚本（reportlab 出 PDF、openpyxl 出 XLSX）。

## 关键约定
- 脚本依赖放在 `pylibs/`，脚本头部用 `sys.path.insert(0, .../pylibs)` 加载，不依赖全局 pip 环境。
- 输出根目录硬编码在脚本里的 `BASE_DIR = D:\网站全栈项目\项目005机箱\三层卧式模块化机箱_项目完整交付包`。
- 生成脚本一律用「相对子目录 + 文件名」拼接写入，如 `create_pdf(r'01_设计文档\xxx.pdf', ...)`。

## 版本演进（重要）
- **V1 大尺寸版**（`generate_*.py`，450×360×400，12盘热插拔+双主板+双ATX冗余，2700~3770元）→ 已废弃
- **V2 紧凑型**（`generate_*_v2.py`，200×350×350，2×3.5"+2×2.5"+ITX+单ATX，1400~2020元）→ 当前有效
- ⚠️ 新旧脚本共用同一输出路径，运行 V2 会静默覆盖 V1 产物。后续如需保留多版本，必须先把 BASE_DIR 参数化。

## 数据一致性红线
BOM 明细表逐项累加必须与「成本对比汇总」页、以及 PDF 报价文档三处对齐。
现状存在 174.4 元偏差（明细 1574~1714 vs 汇总 1400~1540），属于待修复缺陷。

## 用户偏好（本项目内）
- 中文沟通、要绝对路径、要结构化输出 + 可视化。
- 破坏性操作（文件移动/合并/覆盖）必须先出计划清单再执行。
- 每次开发成果要详细解释：新功能、修改逻辑、注意事项。
