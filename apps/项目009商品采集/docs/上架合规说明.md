# 上架合规说明（各平台提审用）

配套文件：`docs/隐私政策.md`（上架时必须提供可访问的隐私政策链接）

---

## 一、Android 权限用途说明（商店填写直接用）

| 权限 | 用途说明（可直接复制到商店后台） |
|---|---|
| `INTERNET` | 用于加载地图底图、调用地址解析与路径规划服务，是地图与导航功能的基础网络能力。 |
| `ACCESS_FINE_LOCATION` | 用于在配送导航中显示您的实时位置、进行偏航提醒与转向播报。仅在您主动开启「实时位置」或「开始导航」时采集，关闭后不再获取。 |
| `ACCESS_COARSE_LOCATION` | 用于在「附近商户搜索」中按您所在位置排序结果。仅在您使用搜索附近功能时使用。 |

**数据安全表单（Google Play / 国内商店）关键项**

- 收集的位置信息：**是**，用途＝应用功能（导航），**仅在应用使用时采集**
- 是否与第三方共享：是，仅向地图服务商共享「地址文本与坐标」用于算路，不共享姓名/电话
- 数据是否加密传输：是（全部走 HTTPS）
- 是否提供删除请求通道：是（应用内可清空本地数据；卸载即删除全部数据）
- 应用是否面向儿童：否

## 二、iOS 配置（如需上架 App Store）

在 `Info.plist` 中加入定位用途说明（文案已备好）：

```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>用于在配送导航中显示您的实时位置，提供转向播报与偏航提醒。仅在您开启定位时使用，数据不会上传服务器。</string>
```

> 当前工程为 Capacitor 生成的 Android 工程；iOS 平台需另行执行 `npx cap add ios`，并同步上述配置。

## 三、桌面版（Windows / macOS Electron）

- Electron 桌面版使用系统定位能力（经 `navigator.geolocation`），首次定位时由应用内弹窗说明用途并征求同意；
- 未做代码签名时 Windows SmartScreen 会提示「未知发布者」，属正常现象；正式分发建议购买代码签名证书。
