## 用真实浏览器（Edge）验证所有上线网址 — 关键发现

**背景**：用户要求"使用编辑器中内置的浏览器验证整个项目所有上线网站网址"。此前用 curl 验证全部 200，但本次用真实浏览器渲染发现了 curl 完全暴露不出的问题。

**验证方式**：
- agent-browser CLI 尝试失败：其期望的 chrome-155 下载超时（googleapis 198MB 断流），缓存里只有 chrome-154；复制 154→155 目录名冒充后，chrome.exe 报 `Sandbox cannot access executable ... 拒绝访问 (0x5)`，即便 `--no-sandbox` 也启动卡死（chrome-for-testing 二进制在本机环境不可用）。
- 最终方案：`npm i -g playwright-core`（15s 装好）+ **本机系统 Edge**（`C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe`），自写 Node 脚本 `chromium.launch({ executablePath: msedge, args: ['--no-sandbox','--disable-dev-shm-usage','--disable-gpu'] })`，逐个打开 8 个网址截图+提取 title/text。脚本存 `C:/Users/Admin/verify_sites.js`、`verify_click.js`，截图/结果存 `C:/Users/Admin/ab_shots/`。

**核心发现：CloudBase 测试域名确认墙（curl 验证盲区）**
- 除 API 网关外，所有 `*.webapps.tcloudbase.com` / `*.tcloudbaseapp.com` 测试域名，**浏览器访问都被 CloudBase 强制插入「页面访问提示」风险拦截页（HTTP 404）**："测试域名仅供开发测试使用…请勿泄露个人信息"，带 **「确定访问 (3s)」倒计时按钮**。
- **3 秒后点击「确定访问」即可正常进入**：实测点击后成功加载「优选商城」完整首页（搜索框/8 分类 emoji 导航/商品卡片 ¥89~¥399/tabBar 全部正常渲染，title="优选商城"）。
- curl 当初测到 200 是因为非浏览器请求直接拿到真实内容；浏览器请求被识别先展示拦截页。**"HTTP 200 在线" ≠ "用户浏览器能直接看到站点"**。
- API 网关（tcloudbasegateway.com）不受确认墙影响：浏览器实测 401 MISSING_CREDENTIALS 真实错误页，符合预期。

**结论与待办**：
- 站点本身 100% 正常（确认墙后完整可用）；唯一体验障碍是测试域名确认墙 + 404 状态码（对 SEO/分享预览极不友好）。
- **根治方案**：给 CloudBase 静态托管绑定自定义域名（用户有已备案的 laal.top / mixm-top），绑定后拦截页消失、状态码正常。待用户确认后操作。

## 遗留待办闭环：c84c0cb 推送上库 + credential.helper 弹窗根治（19:56-20:10）
- **推送成功**：后台跑 `GIT_TERMINAL_PROMPT=0 git push origin main`（沙盒关闭让 GCM 弹窗），用户点掉授权窗后
  自动完成 `2a73983..c84c0cb main -> main`；核验 `origin/main...HEAD = 0/0`，android-shell 三处编译修复正式上库。
- **ghu_ 令牌复测仍 403**：`git push https://x-access-token:<ghu_>@github.com/afdk1991/appsp.git` →
  `Permission to afdk1991/appsp.git denied`，App 集成令牌确认无写权限，PAT 通路死路（已记长期记忆）。
- **CredentialHelperSelector 反复弹窗根因**：系统级 `PortableGit/etc/gitconfig` 配了 `credential.helper=helper-selector`
  （就是那个选择框），与全局 `~/.gitconfig` 的 GCM 路径冲突，git 依次调用故每次都先弹选择框。
  系统文件在 Program Files 无写权限（顺带清掉了残留 `gitconfig.lock`）；
  **修复**：全局配置 GCM 条目前加空值 `helper =`（git 官方语义：空值清空累积 helper 列表）→ 现在仅剩 GCM 生效，弹窗根治。
- **OAuth 令牌不持久化**：推送成功后 wincred / `~/.git-credentials` / `%LOCALAPPDATA%/GitCredentialManager` 均无缓存
  → 下次推送仍需一次浏览器授权（后台跑 push + 用户点窗即可，勿前台挂死）。
