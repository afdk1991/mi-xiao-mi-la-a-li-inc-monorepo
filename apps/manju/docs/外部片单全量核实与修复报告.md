## 四、修正前后差异（before / after）

**数据层（每条目）**

| 维度 | 修复前 | 修复后 |
|------|--------|--------|
| 可播集数 | 仅显示标称全集（如「全 1000 集」），与真实可看不符 | `playable_text =「免费 3 集 / 全 1000 集」`，并保留标称字段作对账证据 |
| 逐集明细 | 无（选集按钮点开即 404） | `episode_list` 含 3 条真实可播集（index / vid / 标题） |
| 标题 | 列表卡片 alt，偶含乱码/占位符（如「我大华第​一逍遥王」） | 以源站 `/detail` 为准（→「我大华第一逍遥王」），共 30+ 条被校正 |
| 更新状态 | 无 | `update_status`（updating / completed）+ `update_status_text`（如「更新至第 623 集」） |
| 失效条目 | 无标记 | 14 条源站 404 标记 `unavailable`，前端明确提示「来源站已下架」 |

**代码层（多集播放）**

- Before：`ext/play?ep=2` → 源站 `/player/<sid>/2` → 404 → 只能播第 1 集。
- After：客户端选第 2 集 → `ext/play?ep=1`（0 起）→ 按 `episode_list[1].vid` 构造 `/player/<sid>/<真实vid>` → 取回该集直链。三集各取**不同**真实流，序号对应正确。

**展示层（选集条）**

- Before：按标称全集渲染几十个按钮，点开即 404。
- After：按已核实清单渲染「共可选 3 集」+ 更新状态 + 「来源站登记全 X 集，前 3 集可看，其余为付费内容」声明。

**根因 4（回填回归）**

- Before：正则误选 `enrich-cache.json`（裸数组、无 `rows`）→ `report.rows` 为空 → 回填 0 条，且**无任何报错**。
- After：正则只认带时间戳的正式快照 → 回填 1996 条存活条目。
